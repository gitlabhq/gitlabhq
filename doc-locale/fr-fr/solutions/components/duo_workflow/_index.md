Cette section de documentation couvre une variété de composants de solution développés et fournis par GitLab. Pour télécharger et exécuter ces composants de solution, contactez votre équipe de compte pour obtenir un code d'invitation.

L'utilisation de tout composant de solution est soumise au [GitLab Subscription Agreement](https://handbook.gitlab.com/handbook/legal/subscription-agreement/) (l'« Accord ») et constitue un logiciel libre tel que défini dans l'Accord.

## GitLab Duo Workflow {#gitlab-duo-workflow}

GitLab Duo Workflow vous aide à accomplir vos tâches de développement. La base de code GitLab, les tickets, les merge requests et les pipelines peuvent constituer le contexte dans lequel le workflow agentique peut être exécuté à partir de l'invite, via l'environnement de développement intégré (IDE) VS Code.

Pour obtenir des informations détaillées sur GitLab Duo Workflow, consultez [le document ici](../../../user/duo_agent_platform/_index.md).

## Duo Workflow Solution {#duo-workflow-solution}

La Duo Workflow Solution fournit une bibliothèque d'invites et de contextes pour différents cas d'utilisation du développement logiciel. Chaque cas d'utilisation de la solution, avec la bibliothèque d'invites et de contextes, prend en charge le workflow autonome souhaité pour automatiser les tâches de développement, notamment les tâches allant des modifications de code, à la correction de problèmes et à la revue de code basée sur le plan de workflow défini.
