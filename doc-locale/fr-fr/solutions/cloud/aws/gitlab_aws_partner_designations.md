Les certifications et désignations présentées ici peuvent être validées sur la [page partenaire de GitLab chez AWS](https://partners.amazonaws.com/partners/001E0000018YWFfIAO/GitLab,%20Inc.).

Toutes les qualifications de partenaire AWS nécessitent la soumission et la validation de listes de contrôle exhaustives, ainsi que la fourniture de preuves justificatives qu'AWS utilise pour déterminer l'octroi de la qualification.

## DevOps Software / ISV Competency {#devops-software--isv-competency}

Cette compétence valide que GitLab fournit des solutions DevOps qui fonctionnent avec et sur AWS. [AWS Program Information](https://aws.amazon.com/devops/partner-solutions/)

## DevSecOps Specialty Category {#devsecops-specialty-category}

La qualification DevSecOps est une catégorie de la compétence DevOps Software qui démontre que GitLab constitue une solution de premier plan pour aider les organisations à atteindre leurs objectifs de maturité DevSecOps. GitLab a fait l'objet d'une évaluation portant sur le respect de ces qualifications supplémentaires avant que cette désignation lui soit accordée. [AWS Program Information](https://aws.amazon.com/blogs/apn/aws-devops-competency-expands-to-include-devsecops-category/) [GitLab Announcement](https://about.gitlab.com/blog/aws-devsecops-competency-partner/)

## Public Sector Partner {#public-sector-partner}

Cette désignation indique que GitLab a été jugé qualifié pour travailler avec les clients du secteur public AWS. GitLab dispose d'une organisation dédiée pour répondre aux besoins spécifiques du secteur public. [AWS Program Information](https://aws.amazon.com/partners/programs/public-sector/)

## AWS Graviton {#aws-graviton}

Les instances et runners GitLab ont été testés et fonctionnent sur AWS Graviton. Pour Amazon Linux, nous maintenons des packages YUM pour l'architecture ARM. [AWS Program Information](https://aws.amazon.com/ec2/graviton/partners/)

## Amazon Linux Ready {#amazon-linux-ready}

Les instances et le runner GitLab ont été validés sur Amazon Linux 2 et 2023\. Cela inclut les packages YUM et les dépôts de packages pour les deux, ainsi que plus de 2 300 tests CI pour les deux avant le packaging. [AWS Program Information](https://aws.amazon.com/amazon-linux/partners/)

## AWS Marketplace Seller {#aws-marketplace-seller}

GitLab est un vendeur sur la marketplace et vous pouvez l'acheter et le déployer via AWS Marketplace [AWS Program Information](https://aws.amazon.com/marketplace/partners/management-tour)
