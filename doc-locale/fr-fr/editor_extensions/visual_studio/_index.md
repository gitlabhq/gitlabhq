L'[extension GitLab pour Visual Studio](https://marketplace.visualstudio.com/items?itemName=GitLab.GitLabExtensionForVisualStudio) intègre GitLab à Visual Studio pour Windows.

GitLab pour Visual Studio prend en charge :

- [GitLab Duo Agent Platform](../../user/duo_agent_platform/_index.md), notamment GitLab Duo Agentic Chat, le flow Software Development et GitLab Duo Code Suggestions.
- [GitLab Duo](../../user/gitlab_duo/feature_summary.md), notamment GitLab Duo Non-Agentic Chat et Code Suggestions.

Pour installer et configurer l'extension, consultez [Installer et configurer](setup.md).

Signalez tout problème, bug ou demande de fonctionnalité dans le [suivi des tickets `gitlab-visual-studio-extension`](https://gitlab.com/gitlab-org/editor-extensions/gitlab-visual-studio-extension/-/issues).

## Mettre à jour l'extension {#update-the-extension}

Pour mettre à jour votre extension vers la dernière version :

1. Dans Visual Studio, accédez à **Extensions** > **Manage Extensions...**.
1. Sélectionnez l'onglet **Updates**.
1. Recherchez **GitLab for Visual Studio** publié par **GitLab (`gitlab.com`)**.
1. Sélectionnez **Mise à jour** sur l'extension pour passer à la dernière version.
