Vous pouvez installer GitLab sur la plupart des distributions GNU/Linux, sur plusieurs fournisseurs cloud et dans des clusters Kubernetes. Pour une expérience optimale, vous devez trouver le bon équilibre entre les performances, la fiabilité, la facilité d'administration (sauvegardes, mises à niveau et dépannage) et le coût de l'hébergement.
