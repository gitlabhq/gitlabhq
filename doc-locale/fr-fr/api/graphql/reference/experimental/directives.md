Une directive fournit un moyen de décrire un comportement alternatif d'exécution au moment de l'exécution et de validation des types dans un document GraphQL. Pour plus d'informations, consultez la [documentation sur les directives GraphQL](https://graphql.org/learn/queries/#directives).

AVERTISSEMENT :  les éléments dépréciés sont marqués avec {{< icon name="warning" >}}. Ils seront supprimés lors d'une prochaine release conformément au [processus de dépréciation](../../_index.md#deprecation-and-removal-process) de GitLab. Les éléments qui sont des [versions expérimentales](../../../../policy/development_stages_support.md#experiment) sont marqués avec {{< icon name="work-item-test-case" >}}. Les éléments expérimentaux peuvent changer à tout moment et ne sont pas recommandés pour une utilisation en production.
