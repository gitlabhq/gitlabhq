Un scalaire est un type GraphQL simple sans champs.

GraphQL dispose d'un ensemble standard de scalaires : [`Boolean`](#boolean), [`Float`](#float), [`ID`](#id), [`Int`](#int) et [`String`](#string).

GitLab étend l'ensemble par défaut avec des scalaires personnalisés. Beaucoup d'entre eux sont des [ID globaux](https://graphql.org/learn/global-object-identification), c'est-à-dire un identifiant d'objet au format `"gid://gitlab/Issue/123"`. D'autres, comme [`Time`](#time), fournissent un format strict pour la façon dont notre API GraphQL affiche et accepte les valeurs temporelles.
