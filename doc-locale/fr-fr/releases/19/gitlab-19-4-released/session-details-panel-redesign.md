Trouver les informations essentielles sur une session d'agent nécessitait auparavant de parcourir un panneau encombré. Désormais, le panneau de détails de session affiche en un coup d'œil ce dont vous avez besoin : le statut, les horodatages et l'utilisateur déclencheur apparaissent dans une barre de synthèse, tandis que le rail de droite organise les informations d'identité, d'exécution et les détails complémentaires en groupes clairement étiquetés.

Une nouvelle section **Éléments liés** distingue ce qui a démarré la session de ce qu'elle a produit, notamment les merge requests, les éléments de travail, les jobs et les commentaires. Dans le panneau latéral GitLab Duo, les détails de session se trouvent désormais dans une barre réductible épinglée en bas, afin de rester accessibles sans vous gêner.
