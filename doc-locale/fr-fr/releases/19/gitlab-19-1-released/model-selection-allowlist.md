Pour GitLab Duo Agentic Chat, vous pouvez désormais configurer une liste d'autorisation de modèles approuvés et définir un modèle par défaut à l'échelle de l'organisation, si vous êtes :

- Sur GitLab.com, en tant que [Propriétaire du groupe principal](../../../user/duo_agent_platform/model_selection.md#select-a-model-for-agentic-chat).
- Sur GitLab Self-Managed, en tant qu'[administrateur de l'instance](../../../administration/gitlab_duo/model_selection.md#select-a-model-for-agentic-chat).

Cela donne aux organisations le contrôle sur les modèles que les utilisateurs peuvent sélectionner lors de l'utilisation d'Agentic Chat.
