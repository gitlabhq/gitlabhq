Les revues automatiques dans le flow Code Review sont désormais activées par défaut pour les nouveaux clients en période d'essai de GitLab Duo sur GitLab.com, afin que vous puissiez commencer à recevoir des retours alimentés par l'IA sur vos merge requests dès le premier jour, sans aucune configuration manuelle.

Grâce à un nouveau modèle de tarification forfaitaire, vous bénéficiez d'une valeur immédiate grâce à des revues de code plus intelligentes et plus rapides, prêtes à l'emploi. Si nécessaire, vous pouvez vous désabonner dans les paramètres de votre groupe.
