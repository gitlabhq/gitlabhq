Les améliorations apportées à l'interface dans cette release incluent :

- Vous pouvez appuyer sur <kbd>Esc</kbd> pour annuler le déplacement d'un élément de liste dans la description d'un ticket, d'un élément de travail ou d'un epic, au lieu de devoir terminer le déplacement.
- Les colonnes du résumé du rapport de test de pipeline sont désormais triables, avec par défaut les échecs les plus nombreux en premier.
- Les labels archivés affichent **Archivées** dans leur infobulle, ce qui permet d'identifier en un coup d'œil pourquoi l'un d'eux semble différent.
