GitLab suit les ressources que votre espace de nommage consomme sur GitLab.com, afin que vous puissiez surveiller et gérer l'utilisation et le stockage avant d'atteindre une limite.

L'utilisation désigne les ressources qu'un espace de nommage et ses projets consomment, comme le stockage.

Le stockage désigne l'espace disque qu'un projet utilise. Chaque projet dispose d'une limite de stockage qui dépend de votre édition d'abonnement.

Lorsque vous surveillez votre utilisation, vous pouvez :

- Éviter des restrictions inattendues sur vos projets.
- Planifier des achats de stockage avant d'atteindre une limite.
- Vous assurer que votre équipe peut continuer à pousser du code sans interruption.
