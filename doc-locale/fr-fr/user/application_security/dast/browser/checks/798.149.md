## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton d'e-mail entrant GitLab identifié. Votre jeton d'e-mail entrant vous authentifie lorsque vous créez un nouveau ticket par e-mail et est inclus dans vos adresses e-mail personnelles spécifiques au projet. Il ne peut pas être utilisé pour accéder à d'autres données. Un acteur malveillant ayant accès à ce jeton peut créer des tickets comme s'il était vous. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité concernant les clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants à Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour régénérer un jeton de flux :

- Connectez-vous à votre compte GitLab et accédez au menu latéral gauche [Paramètres utilisateur](../../../../profile/_index.md#access-your-user-settings), puis sélectionnez « Jetons d'accès »
- Dans la section « Jeton d'e-mail entrant », sélectionnez le lien « réinitialiser ce jeton »
- Lorsque vous y êtes invité, sélectionnez « OK »

Pour plus d'informations, veuillez consulter [la documentation GitLab sur les jetons de flux](../../../../../security/tokens/_index.md#feed-token).
