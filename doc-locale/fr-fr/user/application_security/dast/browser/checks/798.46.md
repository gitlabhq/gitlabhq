## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'une clé secrète de test Flutterwave identifiée. Les clés secrètes disposent du niveau de privilèges le plus élevé et peuvent autoriser toute action sur votre compte. Cependant, il s'agit d'une clé de test, elle ne peut donc être utilisée que pour des transactions fictives. Un acteur malveillant ayant accès à cette clé peut envoyer des événements webhook et de messagerie. L'exposition de cette valeur pourrait permettre à des personnes malveillantes d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour renouveler votre clé :

- Connectez-vous et accédez à <https://app.flutterwave.com/dashboard/home>
- Sélectionnez « Settings » dans le menu de gauche
- Sélectionnez « API Keys » sous « Developers » dans le menu de gauche
- Assurez-vous que le « Test mode » est activé
- Sélectionnez « Generate secret key » pour renouveler la clé publique, secrète et de chiffrement

Pour plus d'informations, veuillez consulter la [documentation Flutterwave sur l'authentification](https://developer.flutterwave.com/docs/authentication).
