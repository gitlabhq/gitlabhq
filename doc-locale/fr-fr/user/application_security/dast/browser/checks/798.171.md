## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton d'API de test Shippo identifié. Les jetons d'API peuvent être utilisés pour accéder à l'API Shippo, qui est utilisée pour les services d'expédition. Un acteur malveillant ayant accès à ce jeton peut accéder aux informations de facturation et de commande, et modifier les données d'expédition. L'exposition de cette valeur pourrait permettre à des personnes malveillantes d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité concernant les clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour révoquer un jeton d'API :

- Connectez-vous à votre compte Shippo et accédez à <https://apps.goshippo.com/>
- En haut à droite, sélectionnez l'icône « engrenage » pour accéder à la page « Settings »
- Faites défiler le menu de gauche jusqu'à « Advanced » et sélectionnez « API »
- Dans la section « Token », sélectionnez « Manage your token »
- Trouvez le jeton identifié et sélectionnez l'icône de corbeille
- Lorsque vous y êtes invité, sélectionnez « Yes, remove token » dans la boîte de dialogue « Manage Your Tokens »

Pour plus d'informations, veuillez consulter [la documentation de Shippo sur les clés d'API](https://portal.goshippo.com/api-config/api).
