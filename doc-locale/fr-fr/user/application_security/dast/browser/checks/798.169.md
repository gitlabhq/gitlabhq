## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton d'API publique Segment qui a été identifié. L'API publique Segment est utilisée pour gérer vos workspaces Segment et leurs ressources. Deux types de jetons correspondent à ce modèle : un jeton de propriétaire de workspace et un jeton à rôle limité. En général, ces jetons permettent aux appelants de l'API d'effectuer des opérations de lecture, d'écriture et de suppression. Un acteur malveillant ayant accès à un jeton de propriétaire de workspace peut accéder à toutes les données du workspace. Un jeton à rôle limité peut accéder aux données pour lesquelles l'accès lui a été accordé lors de sa création. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour faire tourner un jeton d'API publique :

- Connectez-vous à votre compte Segment et accédez à votre workspace depuis <https://app.segment.com/>
- Dans le menu de gauche, sélectionnez « Settings » et accédez à « Workspace settings »
- Sélectionnez l'onglet « Access Management » dans la page « Workspace settings »
- Sélectionnez l'onglet « Tokens » sous « Access Management »
- Trouvez la clé identifiée et sélectionnez-la
- Sur le côté droit, sélectionnez « Edit token » dans la section « Token Permissions »
- Sélectionnez « Remove token » dans le coin supérieur droit
- Lorsque vous y êtes invité, sélectionnez « Remove Token » dans la boîte de dialogue

Pour plus d'informations, veuillez consulter [la documentation de Segment sur leur API publique](https://segment.com/docs/api/public-api/).
