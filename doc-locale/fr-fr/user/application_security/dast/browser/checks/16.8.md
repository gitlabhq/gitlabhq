## Description {#description}

Une `Content-Security-Policy` (CSP) manquante ou invalide a été identifiée sur le site cible. La CSP peut contribuer à renforcer un site web contre diverses attaques côté client, telles que les attaques Cross-Site Scripting (XSS).

## Remédiation {#remediation}

Si le site cible ne dispose pas d'une CSP, examinez les URL pertinentes pour activer la CSP. Sinon, suivez les recommandations pour déterminer si des actions sont nécessaires.
