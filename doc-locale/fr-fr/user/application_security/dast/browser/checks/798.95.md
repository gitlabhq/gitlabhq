## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton API Pulumi identifié. Les jetons d'accès personnels correspondent aux permissions d'un utilisateur. Un acteur malveillant ayant accès à ce jeton peut supprimer des stacks, des tags, des mises à jour et des webhooks en tant que propriétaire du jeton d'accès. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour obtenir des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet). Pour révoquer le jeton API :

- Connectez-vous à votre compte Pulumi et accédez à <https://app.pulumi.com/>
- Dans le coin supérieur droit, sélectionnez la photo de profil et sélectionnez « Personal access tokens »
- Trouvez le jeton identifié et sélectionnez les points de suspension dans la colonne « Actions » de la clé, puis sélectionnez « Delete token »
- Lorsque vous y êtes invité, sélectionnez « Delete token » dans la boîte de dialogue « Delete token »

Pour plus d'informations, veuillez consulter [la documentation de Pulumi sur les jetons d'accès personnels](https://www.pulumi.com/docs/pulumi-cloud/access-management/access-tokens/#personal-access-tokens).
