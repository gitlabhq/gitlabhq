## Description {#description}

Il est possible d'exécuter des instructions Expression Language (EL) arbitraires sur le serveur d'application cible. L'injection EL est une vulnérabilité de gravité critique pouvant conduire à une compromission totale du système. L'injection EL peut survenir lorsque des données contrôlées par un attaquant sont utilisées pour construire des instructions EL sans neutralisation des caractères spéciaux. Ces caractères spéciaux pourraient modifier l'instruction EL prévue avant son exécution par un interpréteur.

## Remédiation {#remediation}

Les données contrôlées par l'utilisateur doivent toujours faire l'objet d'une neutralisation des éléments spéciaux lorsqu'elles sont utilisées dans la construction d'instructions Expression Language. Veuillez consulter la documentation de l'interpréteur EL utilisé pour savoir comment neutraliser correctement les données contrôlées par l'utilisateur.
