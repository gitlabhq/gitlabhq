## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un secret d'application GitLab OAuth qui a été identifié. Les secrets OAuth sont utilisés pour permettre aux utilisateurs de se connecter à votre application. Selon les portées attribuées, un acteur malveillant pourrait usurper l'identité du service pour accéder à des dépôts ou des données. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour régénérer un secret OAuth :

- Connectez-vous à votre compte GitLab et accédez au menu latéral gauche [Paramètres utilisateur](../../../../profile/_index.md#access-your-user-settings), puis sélectionnez « Applications »
- Trouvez l'application qui utilise le jeton identifié et sélectionnez le lien du nom dans la colonne « Name » - Sélectionnez « Renew secret » dans la page de détails de l'application
- Lorsque vous y êtes invité, sélectionnez « Renew secret »

Pour plus d'informations, veuillez consulter [la documentation GitLab sur la configuration d'un fournisseur OAuth 2.0](../../../../../integration/oauth_provider.md)
