## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un GitLab feed token identifié. Votre feed token vous authentifie lorsque votre lecteur RSS charge un flux RSS personnalisé ou lorsque votre application de calendrier charge un calendrier personnalisé. Il est visible dans ces URL de flux. Il ne peut pas être utilisé pour accéder à d'autres données. Un acteur malveillant ayant accès à ce jeton peut lire votre flux RSS personnalisé et envoyer des flux RSS à votre calendrier comme s'il s'agissait de vous. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour régénérer un feed token :

- Connectez-vous à votre compte GitLab et accédez au menu latéral gauche [Paramètres utilisateur](../../../../profile/_index.md#access-your-user-settings), puis sélectionnez « Access tokens »
- Dans la section « Feed token », sélectionnez le lien « reset this token »
- Lorsque vous y êtes invité, sélectionnez « OK »

Pour plus d'informations, veuillez consulter [la documentation GitLab sur les feed tokens](../../../../../security/tokens/_index.md#feed-token).
