## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un secret client OAuth Twitch qui a été identifié. Les secrets clients OAuth sont utilisés pour permettre au service d'exécuter des fonctionnalités au nom des utilisateurs Twitch. Un acteur malveillant ayant accès à ce secret client peut usurper l'identité du service et exécuter des fonctionnalités au nom de ses utilisateurs. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour obtenir des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour effectuer la rotation du secret client OAuth :

- Connectez-vous à votre compte Twitch et accédez à <https://dev.twitch.tv/console>
- Trouvez l'extension qui utilise la clé identifiée
- Sélectionnez « Manage » à côté du nom de l'extension dans la section « Extensions »
- Dans le coin supérieur droit, sélectionnez « Extension Settings »
- Dans la section « Twitch API Client Configuration », sélectionnez « Generate Secret » sous « Twitch API Client Secret »
- Lorsque vous y êtes invité, sélectionnez « OK » dans la boîte de dialogue

Pour plus d'informations, veuillez consulter [la documentation développeur de Twitch sur OAuth](https://dev.twitch.tv/docs/authentication/getting-tokens-oauth/#authorization-code-grant-flow).
