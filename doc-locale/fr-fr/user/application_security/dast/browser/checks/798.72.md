## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'une clé API Mailchimp identifiée. Les clés API peuvent être utilisées pour envoyer des e-mails, créer et envoyer des campagnes marketing, ainsi qu'accéder aux listes de clients et aux adresses e-mail. Un acteur malveillant ayant accès à cette clé peut effectuer n'importe quelle requête API vers Mailchimp sans restriction. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité concernant les clés exposées, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour révoquer une clé API :

- Connectez-vous à votre compte Mailchimp sur <https://login.mailchimp.com/>
- Sélectionnez votre icône de profil, puis sélectionnez Profile
- Sélectionnez la liste déroulante Extras, puis choisissez « API keys »
- Trouvez la clé identifiée et sélectionnez « Revoke »
- Lorsque vous y êtes invité, saisissez « REVOKE » pour confirmer et sélectionnez « Revoke » dans la boîte de dialogue « Revoke API Key »

Pour plus d'informations, veuillez consulter [la documentation de Mailchimp sur la sécurité des clés API](https://mailchimp.com/help/about-api-keys/#api+key+security).
