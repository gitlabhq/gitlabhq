## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un secret client LinkedIn identifié. Les secrets clients sont utilisés pour permettre aux utilisateurs de se connecter à votre application. Selon les portées demandées, un acteur malveillant pourrait usurper l'identité du service pour accéder aux informations des utilisateurs. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés divulguées, consultez la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour régénérer votre secret client :

- Connectez-vous à votre compte LinkedIn et rendez-vous sur <https://www.linkedin.com/developers/apps/>
- Trouvez l'application contenant le secret identifié et sélectionnez son nom
- Sélectionnez l'onglet « Auth »
- Sélectionnez « Generate a new Client Secret » dans la section « Application credentials »
- Si « Generate a new Client Secret » n'existe pas, vous avez probablement deux secrets actifs ; supprimez-en un et l'option devrait apparaître
- Sélectionnez le « X » à côté du secret identifié pour le supprimer
- Lorsque vous y êtes invité, sélectionnez « Confirm » dans la boîte de dialogue « Remove the Primary Client Secret »

Pour plus d'informations, consultez [la documentation LinkedIn sur l'accès à l'API](https://learn.microsoft.com/en-us/linkedin/learning/getting-started/request-access).
