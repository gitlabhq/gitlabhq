## Description {#description}

Ce site a été identifié comme autorisant les redirections ouvertes à partir des entrées fournies par l'utilisateur. Les redirections ouvertes sont couramment exploitées dans les attaques de phishing où le domaine ou l'URL d'origine ressemble à un lien légitime, mais redirige ensuite l'utilisateur vers un site malveillant. Par exemple, `https://example.com/redirect?url=https://%62%61%64%2e%63%6f%6d%2f%66%61%6b%65%6c%6f%67%69%6e` qui, une fois décodé, devient `bad.com/fakelogin`.

## Remédiation {#remediation}

Ne jamais rediriger un client en fonction des entrées utilisateur trouvées dans une requête `GET`. Il est recommandé que la liste des liens cibles vers lesquels rediriger un utilisateur soit conservée côté serveur, et récupérée à l'aide d'une valeur numérique utilisée comme index pour retourner le lien de redirection. Par exemple, `/redirect?id=1` amènerait l'application à rechercher l'index `1` et à retourner une URL telle que `https://example.com`. Cette URL serait ensuite utilisée pour rediriger l'utilisateur, en utilisant le code de réponse 301 et l'en-tête `Location`.
