## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton d'API de livraison Contentful qui a été identifié. L'API de livraison Contentful (CDA) est une API en lecture seule permettant de diffuser du contenu de Contentful vers des applications, des sites web et d'autres médias. Le contenu est livré sous forme de données JSON, et les images, vidéos et autres médias sous forme de fichiers. Un acteur malveillant ayant accès à ce jeton dispose uniquement d'un accès en lecture aux entrées. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour révoquer le jeton d'API de livraison :

- Connectez-vous et visitez <https://app.contentful.com/>
- Sélectionnez l'icône en forme d'engrenage dans le coin supérieur droit, puis sélectionnez « API Keys »
- Trouvez la clé d'API détectée et sélectionnez son nom dans le tableau des clés d'API
- Sélectionnez « Delete » dans le coin supérieur droit
- Lorsque vous y êtes invité, sélectionnez « Delete ». Notez que cela supprime également le jeton d'API de prévisualisation. La génération d'un nouvel ensemble de clés d'API est requise.

Pour plus d'informations, veuillez consulter la [documentation sur l'authentification](https://www.contentful.com/developers/docs/references/authentication/#the-content-delivery-and-preview-api) destinée aux développeurs.
