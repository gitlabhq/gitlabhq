## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'une clé privée SSH identifiée. Les clés SSH privées sont utilisées pour l'authentification et l'échange de clés symétriques. Un acteur malveillant ayant accès à cette clé peut l'utiliser pour usurper l'identité d'une application ou d'un service. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour obtenir des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour générer :

- Une nouvelle clé ed25519 (recommandée), utilisez l'outil `ssh-keygen` :

  ```shell
  ssh-keygen -t ed25519
  ```

- Une nouvelle clé ECDSA, utilisez l'outil `ssh-keygen` :

  ```shell
  ssh-keygen -t ecdsa
  ```

- Pour générer une nouvelle clé DSA, utilisez l'outil `ssh-keygen` :

  ```shell
  ssh-keygen -t dsa
  ```

Pour plus d'informations, veuillez consulter la [documentation `ssh-keygen`](https://linux.die.net/man/1/ssh-keygen).
