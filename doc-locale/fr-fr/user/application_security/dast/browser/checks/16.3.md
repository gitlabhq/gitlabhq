## Description {#description}

Le site web cible renvoie l'en-tête `X-Powered-By` ainsi que des informations de version de ce site web. En exposant ces valeurs, des attaquants peuvent tenter de déterminer si le logiciel cible est vulnérable à des vulnérabilités connues, ou répertorier les sites connus utilisant des versions particulières afin de les exploiter ultérieurement lorsqu'une vulnérabilité est identifiée dans cette version spécifique.

## Remédiation {#remediation}

Nous recommandons de supprimer les informations de version de l'en-tête `X-Powered-By`.

PHP : pour les sites web basés sur PHP, définissez l'option `expose_php` sur `off` dans le fichier de configuration `php.ini`.

Pour tous les autres types de serveurs, consultez la documentation de votre produit pour savoir comment supprimer les informations de version de l'en-tête `X-Powered-By`.
