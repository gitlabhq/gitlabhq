## Description {#description}

L'application cible s'est révélée vulnérable à l'injection de code. Un acteur malveillant pourrait injecter du code JavaScript arbitraire à exécuter sur le serveur. Cela pourrait entraîner une compromission totale du système en accédant à des secrets stockés, en injectant du code pour prendre le contrôle de comptes ou en exécutant des commandes du système d'exploitation.

## Remédiation {#remediation}

Ne transmettez jamais directement les données saisies par l'utilisateur aux fonctions qui évaluent des données de type chaîne en tant que code, telles que `eval`, `setTimeout` ou `setInterval`. Il n'y a pratiquement aucun avantage à transmettre des valeurs de chaîne à ces méthodes ; la meilleure recommandation est donc de remplacer la logique actuelle par des implémentations plus sûres permettant d'évaluer dynamiquement la logique avec les données saisies par l'utilisateur. Une alternative consiste à stocker des fonctions ou des méthodes dans une Map qui peut être consultée à l'aide d'une clé. Si la clé existe, la fonction peut être exécutée.

```javascript
const function_map = new Map();

function_map.set('fn', function() {
    console.log('hello world');
})

const input = 'fn2';

const fn = function_map.get(input)

if (fn) {
    fn();
} else {
    console.log('invalid input');
}
```
