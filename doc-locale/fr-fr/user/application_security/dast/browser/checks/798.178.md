## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'une clé de test restreinte Stripe identifiée. Les clés de test restreintes offrent une sécurité accrue en n'autorisant que l'accès en lecture ou en écriture à des ressources API spécifiques. Un acteur malveillant ayant accès à cette clé est limité par la portée définie et ne peut accéder qu'aux données de test. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour obtenir des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour faire pivoter votre clé de test restreinte Stripe :

- Connectez-vous à votre compte Stripe et accédez à <https://dashboard.stripe.com/apikeys>
- Assurez-vous que le « Test mode » est activé en sélectionnant le bouton bascule dans le menu supérieur
- Dans la section « Restricted keys », trouvez la clé identifiée et sélectionnez les points de suspension sur le côté droit
- Sélectionnez « Roll key... »
- Dans la boîte de dialogue « Roll API key », sélectionnez une date d'expiration, par exemple « now »
- Sélectionnez « Roll API Key »

Pour plus d'informations, veuillez consulter [la documentation Stripe sur la rotation des clés API](https://docs.stripe.com/keys#rolling-keys).
