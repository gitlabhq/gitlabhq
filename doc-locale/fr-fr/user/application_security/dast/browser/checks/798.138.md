## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un secret client GCP OAuth identifié. Les secrets clients sont utilisés pour permettre aux utilisateurs de se connecter à votre application. Selon les portées demandées, un acteur malveillant ayant accès au secret peut usurper l'identité du service pour accéder aux informations des utilisateurs. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour obtenir des conseils généraux sur la gestion des incidents de sécurité liés aux clés divulguées, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour révoquer le secret client OAuth :

- Connectez-vous à votre compte GCP et accédez à <https://console.cloud.google.com/apis/credentials>
- Dans la colonne « Name » du tableau « OAuth 2.0 Client IDs », sélectionnez le nom du client de la clé identifiée
- Dans la section « Client secrets », vous devez d'abord ajouter un nouveau secret, puis sélectionnez « Add Secret »
- Pour la clé identifiée, sélectionnez « Disable »
- Lorsque vous y êtes invité, sélectionnez « Disable » dans la boîte de dialogue « Disable this secret? »
- Vous pouvez maintenant sélectionner l'icône de la corbeille pour supprimer la clé désactivée

Pour plus d'informations, veuillez consulter [la documentation d'authentification de Google sur la configuration d'OAuth 2.0](https://support.google.com/cloud/answer/6158849?hl=en)
