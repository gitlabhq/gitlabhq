## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'une clé API Artifactory identifiée. Une clé API Artifactory permet d'effectuer des actions telles que le déploiement d'artefacts, la gestion de dépôts, la configuration des autorisations et la récupération d'artefacts depuis les dépôts JFrog Artifactory. En cas de fuite, un acteur malveillant pourrait l'utiliser pour exfiltrer du code propriétaire sensible, injecter des packages malveillants dans le pipeline de build, ou supprimer des artefacts critiques susceptibles de perturber les capacités de livraison logicielle d'une organisation. L'exposition de cette valeur pourrait permettre à des personnes malveillantes d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).
