## Description {#description}

Un `Content-Security-Policy-Report-Only` (CSPRO) a été identifié sur le site cible. Les en-têtes CSP-Report-Only aident à déterminer comment implémenter un `Content-Security-Policy` sans perturber l'utilisation normale du site cible.

## Remédiation {#remediation}

Suivez les recommandations pour déterminer si des actions sont nécessaires pour renforcer ce `Content-Security-Policy-Report-Only`. Une fois toutes les alertes résolues, remplacez cet en-tête par `Content-Security-Policy`.
