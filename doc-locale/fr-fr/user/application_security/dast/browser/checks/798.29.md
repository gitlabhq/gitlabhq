## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton d'accès personnel Doppler qui a été détecté. L'exposition de cette valeur pourrait permettre à des personnes malveillantes d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des informations d'identification sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour révoquer le jeton d'accès personnel Doppler :

- Ouvrez et connectez-vous à <https://dashboard.doppler.com/>
- Sélectionnez « Tokens » dans le menu de droite
- Sélectionnez l'onglet « Personal »
- Trouvez le jeton personnel et sélectionnez « Roll » dans la colonne Action
- Une fois la boîte de dialogue « Roll Personal Token » affichée, sélectionnez « Roll »
- Copiez la valeur du nouveau jeton

Pour plus d'informations, veuillez consulter leur documentation : <https://docs.doppler.com/docs/start>
