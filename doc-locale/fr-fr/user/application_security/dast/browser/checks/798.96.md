## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton d'importation PyPi qui a été identifié. Les jetons d'importation sont utilisés pour importer des packages lors de la publication de packages Python. Un acteur malveillant ayant accès à ce jeton peut importer des artefacts potentiellement malveillants. L'exposition de cette valeur pourrait permettre à des personnes malveillantes d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés à des clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet). Il est fortement recommandé de passer à OIDC Connect plutôt que d'utiliser des jetons d'importation PyPi. Veuillez consulter [la documentation PyPi sur les éditeurs de confiance](https://docs.pypi.org/trusted-publishers/).

Pour supprimer un jeton d'importation PyPi :

- Connectez-vous à votre compte PyPi et consultez <https://pypi.org/manage/account/>
- Faites défiler jusqu'à la section « API tokens »
- Trouvez le jeton identifié et sélectionnez la liste déroulante « Options »
- Sélectionnez « Remove token »
- Lorsque vous y êtes invité, saisissez votre mot de passe et sélectionnez « Remove API Token »

Pour plus d'informations, veuillez consulter [la documentation PyPi sur les jetons d'importation](https://pypi.org/help/#apitoken).
