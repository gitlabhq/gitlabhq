## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton API RubyGems identifié. Les jetons RubyGems sont utilisés pour accéder à l'API ou publier des packages. Les jetons RubyGems peuvent être créés avec des permissions ou des portées spécifiques. Selon les permissions et la portée, un acteur malveillant ayant accès à ce jeton peut ajouter ou supprimer des packages, ajouter ou supprimer des propriétaires, ou consulter le tableau de bord. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour révoquer le jeton API :

- Connectez-vous à votre compte RubyGems et accédez à <https://rubygems.org/settings/edit>
- Faites défiler vers le bas et sélectionnez « API Keys » ou rendez-vous sur <https://rubygems.org/profile/api_keys>
- Trouvez le jeton identifié et sélectionnez « Delete »
- Lorsque vous y êtes invité, sélectionnez « OK » dans la boîte de dialogue.

Pour plus d'informations, veuillez consulter la [documentation RubyGems sur les jetons API](https://guides.rubygems.org/api-key-scopes/).
