## Description {#description}

L'en-tête `Content-Type` garantit que les agents utilisateurs interprètent correctement les données reçues. Sans cet en-tête, le navigateur peut mal interpréter les données, ce qui peut conduire à des attaques par confusion MIME. Si un attaquant parvenait à téléverser des fichiers accessibles via un navigateur, il pourrait téléverser des fichiers susceptibles d'être interprétés comme du HTML et ainsi exécuter des attaques de type Cross-Site Scripting (XSS).

## Remédiation {#remediation}

Assurez-vous que toutes les ressources renvoient un en-tête `Content-Type` approprié correspondant à leur format. Par exemple, lors du renvoi de fichiers JavaScript, l'en-tête de réponse doit être : `Content-Type: application/javascript`

Pour une protection accrue, toutes les ressources doivent renvoyer l'en-tête `X-Content-Type-Options: nosniff` afin d'empêcher les agents utilisateurs de mal interpréter les ressources.
