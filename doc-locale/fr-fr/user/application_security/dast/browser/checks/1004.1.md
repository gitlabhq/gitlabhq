## Description {#description}

Le cookie a été transmis dans un en-tête `Set-Cookie` sans que l'attribut `HttpOnly` soit défini. Pour empêcher JavaScript d'accéder à la valeur du cookie, généralement via `document.cookies`, tous les cookies utilisés à des fins d'autorisation doivent avoir l'attribut `HttpOnly` défini.

## Remédiation {#remediation}

La plupart des frameworks d'applications web permettent de configurer la façon dont les cookies sont envoyés aux agents utilisateurs. Consultez la documentation de votre framework pour plus d'informations sur la façon d'activer les différentes directives de sécurité lors de l'attribution de cookies aux clients.

Si l'application attribue des cookies en écrivant directement dans les en-têtes de réponse, assurez-vous que toutes les réponses incluent l'attribut `HttpOnly`. En activant cette protection, l'application est en mesure d'atténuer l'impact de certaines attaques de type Cross-Site Scripting (XSS).

Exemple :

```http
Set-Cookie: {cookie_name}=<random secure value>; HttpOnly
```
