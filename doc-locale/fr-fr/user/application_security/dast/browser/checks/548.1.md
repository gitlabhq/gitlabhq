## Description {#description}

Le serveur web cible est configuré pour lister le contenu des répertoires ne contenant pas de fichier d'index tel que `index.html`. Cela pourrait entraîner une exposition accidentelle d'informations sensibles, ou fournir à un attaquant des détails sur la structure et le stockage des noms de fichiers et des répertoires.

## Remédiation {#remediation}

L'indexation des répertoires doit être désactivée.

Apache : pour les sites web basés sur Apache, assurez-vous que toutes les définitions `<Directory>` ont `Options -Indexes` configuré dans le fichier de configuration `apache2.conf` ou `httpd.conf`.

NGINX : pour les sites web basés sur NGINX, assurez-vous que toutes les définitions `location` ont la directive `autoindex off` définie dans le fichier `nginx.conf`.

IIS : pour les sites web basés sur IIS version 7.0 et ultérieures, vous pouvez utiliser l'élément `<directoryBrowse enabled="false" />` dans les fichiers `applicationHost.config` ou `Web.config`.

Pour tous les autres types de serveurs, consultez la documentation de votre produit pour savoir comment désactiver l'indexation des répertoires.
