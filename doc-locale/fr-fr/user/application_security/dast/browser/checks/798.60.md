## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton API d'application privée HubSpot identifié. Les applications privées vous permettent d'utiliser les API HubSpot pour accéder à des données spécifiques de votre compte HubSpot et peuvent être restreintes en définissant des portées spécifiques. Un acteur malveillant ayant accès à ce jeton peut appeler des points de terminaison API avec les mêmes niveaux que ceux définis dans la portée de l'application. Cela peut aller de la simple lecture de campagnes marketing à l'accès aux informations des utilisateurs et des comptes, en passant par l'envoi d'e-mails. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour faire pivoter un jeton API d'application privée :

- Connectez-vous à votre compte HubSpot à l'adresse <https://app.hubspot.com/>
- Dans le menu de gauche, survolez l'icône de base de données et sélectionnez « Integrations »
- Trouvez l'application privée qui possède le jeton identifié et sélectionnez son nom
- Sélectionnez l'onglet « Auth » en haut de la page
- Dans la section « Access token » de la page, sélectionnez « Rotate »
- Sélectionnez « Rotate and expire this token now » lorsque vous y êtes invité
- Sélectionnez « Rotate now » dans la boîte de dialogue « Rotate access token now? »

Pour plus d'informations, veuillez consulter [la documentation HubSpot sur les applications privées](https://developers.hubspot.com/beta-docs/guides/apps/private-apps/overview)
