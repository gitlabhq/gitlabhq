## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton OAuth d'utilisateur bot Slack identifié. Les capacités et les autorisations d'une application Slack sont régies par les portées qu'elle demande. Une liste complète des autorisations est disponible [dans la documentation sur les portées de Slack](https://api.slack.com/scopes). Un acteur malveillant ayant accès à ce jeton peut exécuter les fonctionnalités qui lui ont été attribuées. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour révoquer un jeton OAuth d'utilisateur bot Slack (Remarque : cette opération nécessite que tous les utilisateurs autorisent à nouveau votre application) :

- Connectez-vous à Slack et accédez à <https://api.slack.com/apps>
- Trouvez l'application avec le jeton identifié et sélectionnez le nom
- Dans le menu de gauche, sélectionnez « OAuth & Permissions »
- Faites défiler vers le bas jusqu'à « Revoke All OAuth Tokens » et sélectionnez « Revoke tokens »
- Lorsque vous y êtes invité, sélectionnez « Yes, I'm sure » dans la boîte de dialogue « Are you sure? »
- Après un certain temps, faites défiler vers le haut jusqu'à la section « OAuth Tokens » et sélectionnez « Reinstall to XXX », où XXX est le nom de votre workspace

Pour plus d'informations, veuillez consulter [la documentation de Slack sur OAuth](https://api.slack.com/authentication/oauth-v2)
