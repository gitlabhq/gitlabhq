## Description {#description}

La vulnérabilité peut être exploitée en insérant un payload dans un paramètre du point de terminaison URL, ce qui permet de lire des fichiers arbitraires. Cela peut être utilisé pour lire des fichiers sensibles, accéder aux données d'autres utilisateurs ou faciliter l'exploitation afin d'obtenir un accès système plus étendu.

## Remédiation {#remediation}

Les données saisies par les utilisateurs ne doivent jamais être utilisées pour construire des chemins ou des fichiers destinés à interagir avec le système de fichiers. Cela inclut les noms de fichiers fournis lors des téléchargements ou des téléversements par les utilisateurs.

Si possible, envisagez de hacher les noms de fichiers et de référencer les noms de fichiers hachés dans une base de données ou un datastore, plutôt que de tenter d'accéder directement aux noms de fichiers fournis par les utilisateurs ou d'autres composants du système.

Dans les rares cas où l'application doit travailler avec des noms de fichiers, utilisez la fonctionnalité fournie par le langage pour extraire uniquement la partie nom de fichier de la valeur fournie. Ne tentez jamais d'utiliser les informations de chemin ou de répertoire provenant des données saisies par les utilisateurs.
