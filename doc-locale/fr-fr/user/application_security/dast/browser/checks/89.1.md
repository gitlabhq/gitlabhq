## Description {#description}

Il est possible d'exécuter des commandes SQL arbitraires sur la base de données backend du serveur d'application cible. L'injection SQL est une vulnérabilité critique pouvant conduire à une compromission des données ou du système.

## Remédiation {#remediation}

Utilisez toujours des requêtes paramétrées lorsque vous émettez des requêtes vers des systèmes de bases de données backend. Dans les situations où des requêtes dynamiques doivent être créées, n'utilisez jamais directement les données saisies par l'utilisateur, mais utilisez plutôt une carte ou un dictionnaire de valeurs valides et résolvez-les à l'aide d'une clé fournie par l'utilisateur.

Par exemple, certains pilotes de base de données n'autorisent pas les requêtes paramétrées pour les opérateurs de comparaison `>` ou `<`. Dans ces cas, n'utilisez pas une valeur `>` ou `<` fournie par l'utilisateur, mais demandez plutôt à l'utilisateur de fournir une valeur `gt` ou `lt`. Les valeurs alphabétiques sont ensuite utilisées pour rechercher les valeurs `>` et `<` à utiliser dans la construction de la requête dynamique. Il en va de même pour les autres requêtes où des noms de colonnes ou de tables sont requis mais ne peuvent pas être paramétrés.
