## Description {#description}

Il est possible d'exécuter des commandes OS arbitraires sur le serveur d'applications cible. L'injection de commande OS est une vulnérabilité critique qui peut mener à une compromission totale du système.

## Remédiation {#remediation}

Les données saisies par l'utilisateur ne doivent jamais être utilisées pour construire des commandes ou des arguments de commandes destinés aux fonctions qui exécutent des commandes OS. Cela inclut les noms de fichiers fournis lors de chargements ou de téléchargements par l'utilisateur.

Assurez-vous que votre application :

- N'utilise pas les informations fournies par l'utilisateur dans le nom du processus à exécuter.
- N'utilise pas les informations fournies par l'utilisateur dans une fonction d'exécution de commande OS qui n'échappe pas les métacaractères shell.
- N'utilise pas les informations fournies par l'utilisateur dans les arguments des commandes OS.

L'application doit disposer d'un ensemble d'arguments codés en dur à transmettre aux commandes OS. Si des noms de fichiers sont transmis à ces fonctions, il est recommandé d'utiliser à la place un hash du nom de fichier, ou tout autre identifiant unique. Il est fortement recommandé d'utiliser une bibliothèque native implémentant les mêmes fonctionnalités plutôt que des commandes système OS, en raison du risque d'attaques inconnues contre des commandes tierces.
