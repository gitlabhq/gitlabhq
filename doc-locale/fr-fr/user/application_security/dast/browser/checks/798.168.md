## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'une clé privée RSA identifiée. Les clés RSA privées peuvent être utilisées dans de nombreux types d'applications, mais sont généralement utilisées pour l'authentification et l'échange de clés symétriques. Un acteur malveillant ayant accès à cette clé peut l'utiliser pour usurper l'identité d'une application ou d'un service. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des informations d'identification sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour générer une nouvelle clé RSA, utilisez l'outil `ssh-keygen` :

```shell
ssh-keygen -m PEM -t rsa -b 4096 -C "email@company.com"
```

Pour plus d'informations, veuillez consulter la [documentation `ssh-keygen`](https://linux.die.net/man/1/ssh-keygen).
