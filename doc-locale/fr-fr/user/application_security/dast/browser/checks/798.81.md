## Description {#description}

Le corps de la réponse contient du contenu correspondant au schéma d'une clé API utilisateur New Relic identifiée. Les clés utilisateur servent à interroger des données et à gérer des configurations (Alertes, Synthetics, tableaux de bord, etc.). Un acteur malveillant ayant accès à cette clé peut exécuter des requêtes API en tant qu'utilisateur qui l'a créée. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour obtenir des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des informations d'identification sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet). Pour plus d'informations, veuillez consulter [la documentation de New Relic sur la rotation des clés API](https://docs.newrelic.com/docs/apis/intro-apis/new-relic-api-keys/#rotate-keys).
