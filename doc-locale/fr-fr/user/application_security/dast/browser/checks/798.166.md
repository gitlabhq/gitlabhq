## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'une clé privée PGP identifiée. Les clés privées PGP sont utilisées pour chiffrer et déchiffrer des messages. Un acteur malveillant ayant accès à cette clé peut chiffrer et déchiffrer tous les messages passés et futurs. Notez que les messages passés chiffrés à l'aide de cette clé doivent être considérés comme compromis, et les nouveaux messages ne peuvent pas être considérés comme fiables. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés divulguées, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet). Les clés PGP ne peuvent pas être renouvelées, une nouvelle clé doit être créée. Pour plus d'informations, veuillez consulter [la documentation de GnuPG sur la génération de clés](https://gnupg.org/gph/en/manual.html#AEN26)
