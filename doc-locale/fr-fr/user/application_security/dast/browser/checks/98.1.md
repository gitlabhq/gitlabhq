## Description {#description}

Le serveur est vulnérable à l'inclusion de fichier distant PHP (RFI), ce qui permet aux attaquants de charger des fichiers distants et de les faire exécuter en tant que scripts PHP côté serveur. Cette vulnérabilité se produit lorsque des données saisies par un utilisateur non fiable sont directement utilisées dans l'inclusion de scripts sans validation appropriée. Les attaquants peuvent exploiter cette vulnérabilité pour inclure et exécuter des fichiers distants arbitraires, compromettant potentiellement l'intégrité et la confidentialité du système.

## Remédiation {#remediation}

Évitez d'utiliser des données contrôlées par l'utilisateur directement dans les instructions `include` et `require` et envisagez plutôt une approche par liste d'autorisation pour l'inclusion dynamique de scripts.

Si possible, envisagez également de définir `allow_url_include=Off` dans la configuration PHP du serveur pour vous assurer que les URL ne peuvent pas être utilisées dans les instructions `include` et `require`.
