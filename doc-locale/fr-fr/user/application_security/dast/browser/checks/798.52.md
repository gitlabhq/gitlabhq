## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton d'accès personnel GitHub (classique) qui a été identifié. Les jetons d'accès personnels peuvent être utilisés pour accéder aux services GitHub en tant qu'utilisateur qui les a créés. Dans la plupart des cas, ces jetons se voient accorder un accès en lecture-écriture à tous les dépôts. Un acteur malveillant ayant accès à ce jeton peut exécuter des fonctionnalités au nom de l'utilisateur avec les autorisations définies pour le jeton. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour obtenir des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour régénérer un jeton d'accès personnel :

- Connectez-vous à votre compte GitHub et accédez à <https://github.com/settings/tokens>
- Trouvez le jeton qui a été identifié et sélectionnez son nom
- Sélectionnez « Regenerate token » en haut de la page. Vous pouvez également sélectionner « Delete this token » en bas de la page et en créer un nouveau. Assurez-vous de noter les portées et les autorisations définies avant d'effectuer cette action.

Pour plus d'informations, veuillez consulter [la documentation de GitHub sur les jetons d'accès personnels](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens).
