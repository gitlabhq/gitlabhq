## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton de déploiement Clojars. Un jeton de déploiement est utilisé à la place d'un mot de passe lors du déploiement et ne peut pas être utilisé pour se connecter. Les jetons peuvent avoir une portée limitée à :

- N'importe quel artefact auquel vous avez accès (« \* »)
- N'importe quel artefact dans un groupe auquel vous avez accès (« group-name/\* »)
- Un artefact particulier auquel vous avez accès (« group-name/artifact-name »). Un acteur malveillant ayant accès à ce jeton peut déployer des JARs Clojure malveillants en utilisant ce compte.

L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour révoquer un jeton de déploiement :

1. Visitez <https://clojars.org/tokens> après vous être connecté.
1. Sous « Existing Deploy Tokens », trouvez le jeton qui a été détecté.
1. Sélectionnez « Disable token ».

   > [!note]
   > Il n'est pas possible de réactiver le jeton après l'avoir désactivé.

Pour créer un nouveau jeton de déploiement :

1. Visitez <https://clojars.org/tokens> après vous être connecté.
1. Remplissez le champ Token name 1. Sélectionnez la portée de jeton appropriée.
1. Si le jeton est à usage unique, cochez la case « Single use? », sinon laissez-la vide.
1. Définissez une date d'expiration (90 jours est recommandé).
1. Sélectionnez « Create Token ». Pour plus d'informations sur les jetons, veuillez consulter le [site web de Clojars](https://github.com/clojars/clojars-web/wiki/Deploy-Tokens).
