## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un secret client Adobe détecté. Les secrets clients Adobe sont utilisés pour se connecter à diverses API ou à des services basés sur des événements webhook. Selon le type de service défini pour un projet, un acteur malveillant ayant accès au secret peut l'utiliser pour accéder à diverses API ou événements susceptibles de contenir des informations sensibles. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité concernant les clés divulguées, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet). Les étapes de remédiation dépendent du type de secret client qui a été divulgué. Veuillez consulter les types d'étapes de remédiation ci-dessous et utiliser celle qui s'applique au secret détecté.

OAuth (Serveur à serveur) :

- Connectez-vous à votre compte sur <https://developer.adobe.com/console>.
- Sélectionnez le projet ou « All projects » pour trouver le projet concerné. Sur le côté gauche, sous « Credentials », sélectionnez « OAuth Server-to-Server ».
- Sous « Client Secret », sélectionnez « Retrieve client secret ».
- Une fois le tableau des secrets visible, sous le tableau, sélectionnez « Add new client secret ».
- Une fois le nouveau secret créé, trouvez la valeur du jeton divulgué et sélectionnez l'icône de corbeille pour le supprimer.
- Copiez la valeur du secret et mettez à jour tous les services avec le nouveau secret client.

OAuth Web App (projet basé sur des événements) :

- Sélectionnez le projet ou sélectionnez « All projects » pour trouver le projet concerné.
- Sur le côté gauche, sous « Credentials », sélectionnez « OAuth Web App ».
- Sélectionnez « Retrieve client secret ».
- Vérifiez qu'il s'agit bien du secret divulgué.
- Si ce projet est configuré pour des événements, copiez tous les détails de l'événement avant de le supprimer. Vous pouvez le faire en trouvant l'événement répertorié sur le côté droit et en le sélectionnant. Vous devriez être redirigé vers un tableau de bord affichant ses détails, tels que les méthodes de livraison des événements, les fournisseurs, les événements auxquels vous êtes abonné et les identifiants connectés.
- Pour supprimer l'événement, sélectionnez « ... » dans l'événement, qui se trouve sur le côté droit de la page du projet, au-dessus de « Connect another service ».
- Sélectionnez « remove ».
- Lorsque vous y êtes invité, saisissez le nom du projet et sélectionnez « Delete Events Registration ».
- Dans le coin supérieur droit, sélectionnez « Delete credential ».
- Lorsque vous y êtes invité, saisissez le nom du projet et sélectionnez « Delete Credential ».
- Rajoutez l'événement avec les mêmes détails qu'auparavant.
- Lorsque vous êtes invité à rajouter les identifiants, assurez-vous d'utiliser le OAuth « User Authentication ».
- Sélectionnez « Web App » pour l'authentification et l'autorisation OAuth 2.0.
- Une fois l'événement rajouté, sous « Credentials » sur le côté gauche, sélectionnez « OAuth Web App ».
- Sélectionnez « Retrieve client secret ».
- Copiez la valeur du secret et mettez à jour tous les services avec le nouveau secret client.

OAuth Web App (projet basé sur un service API) :

- Connectez-vous à votre compte sur <https://developer.adobe.com/console>.
- Sélectionnez le projet ou sélectionnez « All projects » pour trouver le projet concerné.
- Sur le côté gauche, sous « Credentials », sélectionnez « OAuth Web App »
- Sélectionnez « Retrieve client secret ».
- Si ce projet est configuré pour une API, sélectionnez l'icône de corbeille « Remove » pour supprimer le produit et le service connectés.
- Lorsque vous y êtes invité, saisissez le nom du projet et sélectionnez « Remove API ».
- Dans le coin supérieur droit, sélectionnez « Delete credential ».
- Lorsque vous y êtes invité, saisissez le nom du projet et sélectionnez « Delete Credential ».
- Rajoutez l'API avec les mêmes détails qu'auparavant.
- Sélectionnez « Web App » pour l'authentification et l'autorisation OAuth 2.0.
- Une fois le service rajouté, sur le côté gauche, sous « Credentials », sélectionnez « OAuth Web App ».
- Sélectionnez « Retrieve client secret ».
- Copiez la valeur du secret et mettez à jour tous les services avec le nouveau secret client.
