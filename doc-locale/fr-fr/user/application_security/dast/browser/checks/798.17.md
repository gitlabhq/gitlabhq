## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton d'API Beamer qui a été détecté. Les jetons d'API Beamer peuvent être utilisés pour lire, écrire et supprimer des publications et des « idées », ainsi que pour consulter des rapports analytiques NPS. Ce service est utilisé pour informer les utilisateurs des modifications apportées à votre logiciel par e-mail ou par d'autres méthodes. Un acteur malveillant ayant accès à ce jeton peut appeler des points de terminaison d'API et créer ou supprimer des publications et des idées, ou consulter des rapports. L'exposition de cette valeur pourrait permettre à des personnes malveillantes d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet). Pour supprimer votre jeton d'API Beamer : connectez-vous à votre compte Beamer à l'adresse : <https://app.getbeamer.com/auth/login> ; sélectionnez l'icône en forme d'engrenage (« Settings ») dans le coin inférieur gauche, puis sélectionnez « API » dans le menu de gauche, ou accédez à <https://app.getbeamer.com/settings#api> ; trouvez la clé détectée et sélectionnez l'icône en forme de crayon « Edit » ; notez toutes les autorisations et leurs paramètres ; sélectionnez « Delete Key » ; sélectionnez « Create New API Key » ; appliquez les mêmes paramètres que ceux de la clé détectée
