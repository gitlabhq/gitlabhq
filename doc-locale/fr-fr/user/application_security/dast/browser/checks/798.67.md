## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un secret client ou ID OAuth 2.0 Linear identifié. Les secrets clients sont utilisés pour permettre aux utilisateurs de se connecter à votre application. Selon les portées demandées, un acteur malveillant pourrait usurper l'identité du service pour accéder aux informations d'un utilisateur. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés exposées, consultez la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour révoquer un secret client Linear OAuth 2.0 :

- Connectez-vous à votre compte sur <https://linear.app/>
- Sélectionnez votre organisation dans le coin supérieur gauche et sélectionnez « Preferences »
- Dans le menu de gauche, sélectionnez « API » sous « My Account »
- Dans la section « OAuth Applications » de la page, trouvez l'application qui contient la clé identifiée
- Sélectionnez les points de suspension à droite du nom de l'application, puis sélectionnez « Manage application ». À côté des « Admin Actions », sélectionnez « Rotate secret »
- Lorsque vous y êtes invité, sélectionnez « Rotate » dans la boîte de dialogue « Rotate your client secret? »

Pour plus d'informations, consultez [la documentation de Linear sur l'authentification OAuth 2.0](https://developers.linear.app/docs/oauth/authentication).
