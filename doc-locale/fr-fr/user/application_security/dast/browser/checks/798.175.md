## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'une clé restreinte Stripe en production. Les clés restreintes offrent une sécurité accrue en n'autorisant que l'accès en lecture ou en écriture à des ressources API spécifiques. Un acteur malveillant ayant accès à cette clé est limité par la portée définie pour celle-ci. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des informations d'identification sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour faire pivoter votre clé restreinte Stripe en production :

- Connectez-vous à votre compte Stripe et accédez à <https://dashboard.stripe.com/apikeys>
- Vérifiez que le « Mode Test » est désactivé
- Dans la section « Restricted keys », trouvez la clé identifiée et sélectionnez les points de suspension sur le côté droit
- Sélectionnez « Roll key... »
- Dans la boîte de dialogue « Roll API key », sélectionnez une date d'expiration, par exemple « now »
- Sélectionnez « Roll API Key »

Pour plus d'informations, veuillez consulter [la documentation Stripe sur la rotation des clés API](https://docs.stripe.com/keys#rolling-keys).
