## Description {#description}

Le site web cible renvoie l'en-tête `X-Backend-Server` qui inclut des adresses IP ou des noms d'hôte potentiellement internes/cachés. En exposant ces valeurs, des personnes malveillantes peuvent tenter de contourner les proxies de sécurité et d'accéder directement à ces hôtes.

## Remédiation {#remediation}

Consultez la documentation ou le fournisseur de votre proxy/équilibreur de charge pour savoir comment désactiver la divulgation de la valeur de l'en-tête `X-Backend-Server`.
