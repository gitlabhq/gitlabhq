## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton d'API HashiCorp Terraform identifié. Les jetons d'API peuvent être utilisés pour accéder à l'API HCP Terraform. Un acteur malveillant ayant accès à ce jeton peut effectuer toutes les actions auxquelles le compte utilisateur a droit. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour révoquer un jeton d'API :

- Connectez-vous à la console Terraform HCP et accédez à <https://app.terraform.io/app/settings/tokens>
- Trouvez le jeton qui a été identifié
- Sélectionnez l'icône de corbeille sur le côté droit du jeton
- Lorsque vous y êtes invité, sélectionnez « Confirm » dans la boîte de dialogue « Deleting token ... »

Pour plus d'informations, veuillez consulter [la documentation de Terraform sur les jetons d'API](https://app.terraform.io/app/settings/tokens).
