## Description {#description}

Le site web cible renvoie l'en-tête `Server` ainsi que des informations de version de ce site web. En exposant ces valeurs, des attaquants peuvent tenter de déterminer si le logiciel cible est vulnérable à des vulnérabilités connues, ou de répertorier les sites connus exécutant des versions particulières afin de les exploiter ultérieurement lorsqu'une vulnérabilité est identifiée dans la version concernée.

## Remédiation {#remediation}

Nous recommandons de supprimer les informations de version de l'en-tête `Server`.

Apache : pour les sites web basés sur Apache, définissez `ServerTokens` sur `Prod` dans le fichier de configuration `httpd.conf`.

NGINX : pour les sites web basés sur NGINX, définissez la valeur de configuration `server_tokens` sur `off` dans le fichier `nginx.conf`.

IIS : pour les sites web basés sur IIS en version 10 et ultérieure, vous pouvez utiliser l'élément `removeServerHeader` dans la section `requestFiltering` du fichier `Web.config`.

Pour tous les autres types de serveurs, consultez la documentation de votre produit pour savoir comment supprimer les informations de version de l'en-tête `Server`.
