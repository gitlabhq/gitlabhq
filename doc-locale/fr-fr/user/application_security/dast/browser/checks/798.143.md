## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton d'enregistrement GitLab Runner obsolète qui a été identifié. Ces jetons permettent aux utilisateurs d'enregistrer un runner auprès du projet sélectionné. Un acteur malveillant ayant accès à ce jeton peut ajouter un runner personnalisé au pipeline et potentiellement compromettre le dépôt si le runner était utilisé. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour faire pivoter un jeton d'enregistrement de runner :

- Connectez-vous à votre compte GitLab et accédez au projet qui a créé le jeton d'enregistrement du runner
- Dans le menu de gauche, sélectionnez « Settings »
- Sous les options « Settings », sélectionnez « CI/CD »
- Dans la section « Runners », sélectionnez le menu kebab (ellipse verticale) situé à côté de « New project runner »
- Sélectionnez « Reset registration token » dans la liste déroulante
- Lorsque vous y êtes invité, sélectionnez « Reset token » dans la boîte de dialogue « Reset registration token »

Pour plus d'informations, veuillez consulter [la documentation GitLab sur l'utilisation des jetons d'authentification de runner](https://docs.gitlab.com/runner/register/#register-with-a-runner-authentication-token).
