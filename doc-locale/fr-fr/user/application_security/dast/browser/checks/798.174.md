## Description {#description}

Le corps de la réponse contient un contenu correspondant au modèle d'une clé privée SSH identifiée. Les clés SSH privées sont utilisées pour l'authentification et l'échange de clés symétriques. Un acteur malveillant ayant accès à cette clé peut l'utiliser pour usurper l'identité d'une application ou d'un service. L'exposition de cette valeur pourrait permettre à des personnes malveillantes d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, consultez la documentation GitLab sur [l'exposition des informations d'identification sur internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour générer une nouvelle clé ECDSA, utilisez l'outil `ssh-keygen` :

```shell
ssh-keygen -t ecdsa
```

Les versions plus récentes de SSH peuvent produire `-----BEGIN OPENSSH PRIVATE KEY-----` à la place de `-----BEGIN EC PRIVATE KEY-----`

Pour plus d'informations, consultez la [documentation `ssh-keygen`](https://linux.die.net/man/1/ssh-keygen).
