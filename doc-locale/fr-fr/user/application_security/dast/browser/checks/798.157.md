## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton d'accès personnel Ionic identifié. Les jetons d'accès personnels peuvent être utilisés pour authentifier l'interface CLI Ionic, l'interface CLI Appflow ou toute application tierce. Un acteur malveillant ayant accès à ce jeton peut obtenir un accès complet aux dépôts et aux pipelines associés. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés à des clés divulguées, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour révoquer votre jeton API :

- Connectez-vous à votre compte Ionic et rendez-vous sur <https://dashboard.ionicframework.com/settings/personal-access-tokens>
- Trouvez le jeton API qui a été identifié
- Sélectionnez « Delete »
- Lorsque vous y êtes invité, sélectionnez « I'm sure, delete this personal access token » dans la boîte de dialogue « Are you sure? »

Pour plus d'informations, veuillez consulter [la documentation Ionic sur les jetons d'accès](https://ionic.io/docs/appflow/personal-access-tokens).
