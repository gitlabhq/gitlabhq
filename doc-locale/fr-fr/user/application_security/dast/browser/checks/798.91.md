## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton de service d'API PlanetScale identifié. Les jetons de service sont créés et dotés d'autorisations en fonction de la portée autorisée. Un acteur malveillant ayant accès au jeton de service se voit accorder les mêmes autorisations que celles attribuées à ce jeton de service. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité concernant les clés divulguées, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour révoquer un jeton de service :

- Connectez-vous à votre compte PlanetScale et accédez à <https://app.planetscale.com/>.
- Dans le menu de gauche, sélectionnez « Settings »
- Sous « Settings », sélectionnez « Service tokens »
- Trouvez le jeton de sécurité identifié et sélectionnez son nom
- Notez l'accès à l'organisation, les autorisations et la portée associés
- Sélectionnez « Delete service token » dans le coin supérieur droit
- Lorsque vous y êtes invité, sélectionnez « Delete » dans la boîte de dialogue « Delete service token »

Pour plus d'informations, veuillez consulter [la documentation PlanetScale sur les jetons de service](https://planetscale.com/docs/concepts/service-tokens).
