## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton d'accès personnel Shopify identifié. Les jetons d'accès peuvent se voir attribuer des portées restreintes ou un accès complet à toutes les données de la boutique. Un acteur malveillant ayant obtenu l'accès à ce jeton pourrait être en mesure de lire ou de modifier les données de la boutique. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité concernant les clés exposées, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet). Les jetons d'accès ne peuvent pas être révoqués ; vous devez désinstaller puis réinstaller l'application. Veuillez consulter [la documentation Shopify pour plus de détails](https://shopify.dev/docs/apps/build/authentication-authorization/access-tokens/generate-app-access-tokens-admin#rotating-api-credentials-for-admin-created-apps).
