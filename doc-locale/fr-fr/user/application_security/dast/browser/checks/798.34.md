## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton API Duffel qui a été détecté. Les jetons API Duffel peuvent être en lecture-écriture ou en lecture seule, selon la manière dont ils ont été créés. Un acteur malveillant ayant accès à un jeton en lecture-écriture peut exécuter des commandes, réserver des vols ou des hôtels, ou consulter et modifier des listes de clients. Un jeton en lecture seule permet de consulter les listes de clients, les réservations et les informations sur les vols. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour régénérer un jeton :

- Ouvrez et connectez-vous à <https://app.duffel.com/>
- En haut de la page, sélectionnez la liste déroulante Developers, puis sélectionnez « Developers »
- Dans le menu de gauche, sélectionnez « Access tokens »
- Sélectionnez le jeton d'accès qui a été détecté
- Notez le type de jeton (« Read and Write » ou « Read Only »)
- Dans la « Danger Zone », sélectionnez « Delete token »
- Recréez un nouveau jeton avec les mêmes paramètres que le jeton détecté

Pour plus d'informations, consultez leur documentation : <https://duffel.com/docs/guides/getting-started-with-the-dashboard#access-tokens>
