## Description {#description}

L'application génère une requête destinée à interagir avec MongoDB, mais elle ne neutralise pas ou neutralise incorrectement les éléments spéciaux pouvant modifier la logique prévue de la requête.

## Remédiation {#remediation}

Refactorisez les requêtes de recherche pour utiliser des opérateurs de filtrage standard tels que `$gt` ou `$in` plutôt que des opérateurs généraux tels que `$where`. Si possible, désactivez entièrement l'interface JavaScript de MongoDB.
