## Description {#description}

Le site web cible renvoie des en-têtes AspNet accompagnés des informations de version de ce site. En exposant ces valeurs, des attaquants peuvent tenter de déterminer si le logiciel cible est vulnérable à des vulnérabilités connues. Ou répertorier les sites connus exécutant des versions particulières pour les exploiter ultérieurement lorsqu'une vulnérabilité est identifiée dans la version en question.

## Remédiation {#remediation}

Pour supprimer les informations `X-AspNetMvc-Version`, définissez `MvcHandler.DisableMvcResponseHeader = true;` dans le fichier `Global.asax.cs` dans la méthode `Application_Start()`.

```csharp
protected void Application_Start()
{
    MvcHandler.DisableMvcResponseHeader = true;
}
```
