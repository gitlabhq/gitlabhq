## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un mot de passe PlanetScale identifié. Les mots de passe PlanetScale sont utilisés pour se connecter aux instances de base de données. Un acteur malveillant ayant accès à ce mot de passe peut accéder aux bases de données gérées par PlanetScale. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet). Pour plus d'informations, veuillez consulter [la documentation de PlanetScale sur les chaînes de connexion aux bases de données](https://planetscale.com/docs/concepts/connection-strings).
