## Description {#description}

Le corps de la réponse contient du contenu correspondant au schéma d'un jeton API Postman qui a été identifié. Une clé API donne accès à toutes les données Postman pour lesquelles le compte dispose d'autorisations. Un acteur malveillant ayant accès à ce jeton peut accéder à toutes les données stockées dans le service Postman auxquelles l'utilisateur qui a créé la clé API a accès. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour obtenir des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, consultez la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour régénérer un jeton API :

- Connectez-vous à votre compte Postman sur <https://www.postman.com/>
- Sélectionnez la photo de profil en haut à droite, puis sélectionnez « Settings »
- Sélectionnez « API keys » dans le menu de gauche
- Trouvez la clé qui a été identifiée, puis sélectionnez les points de suspension à côté de la colonne de statut dans la section « API keys »
- Sélectionnez « Regenerate »
- Lorsque vous y êtes invité, sélectionnez « Regenerate API Key » dans la boîte de dialogue « Regenerate API key »

Pour plus d'informations, consultez [la documentation de Postman sur les clés API](https://learning.postman.com/docs/developer/postman-api/authentication/).
