## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton d'utilisateur ou d'automatisation de l'API Fastly identifié. Les jetons de l'API Fastly peuvent accorder un accès en lecture-écriture ou en lecture seule selon leur configuration. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés à des clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour révoquer un jeton d'API :

- Connectez-vous à l'interface web Fastly à l'adresse <https://manage.fastly.com/account>
- Accédez à « Account » puis à « API Tokens » dans le menu de gauche
- Trouvez le jeton que vous souhaitez supprimer et notez les détails relatifs à sa portée.
- Lorsque vous êtes prêt, sélectionnez l'icône de corbeille
- Lorsque vous y êtes invité, sélectionnez « Delete »

Pour plus d'informations, veuillez consulter [la documentation Fastly sur l'utilisation des jetons d'API](https://docs.fastly.com/en/guides/using-api-tokens).
