## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton d'accès personnel Typeform identifié. Les jetons d'accès personnels permettent d'accéder à l'API Typeform. Selon la portée et les autorisations attribuées, un acteur malveillant ayant accès à ce jeton peut lire, mettre à jour ou supprimer des données de formulaire. L'exposition de cette valeur pourrait permettre à des personnes malveillantes d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet). Pour régénérer le jeton API Typeform : connectez-vous à votre compte Typeform et accédez à <https://admin.typeform.com/> ; dans le coin supérieur droit, sélectionnez votre photo de profil, puis sélectionnez « Your settings » sous « Account » ; dans le menu de gauche, sélectionnez « Personal tokens » ; dans le tableau « token name », trouvez le jeton identifié, sélectionnez les points de suspension, puis sélectionnez « Regenerate token » Pour plus d'informations, veuillez consulter [la documentation de Typeform sur les jetons d'accès personnels](https://www.typeform.com/developers/get-started/personal-access-token/).
