## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'une clé API de test EasyPost identifiée. Les clés API de test sont utilisées pour les tests de fonctionnalité. Un acteur malveillant ayant accès à cette clé ne peut utiliser que les fonctionnalités limitées du service EasyPost. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés divulguées, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour révoquer le jeton API identifié :

- Connectez-vous à votre compte et accédez à la page des paramètres <https://www.easypost.com/account/settings>
- Sous « Test API Keys », cochez la case « Status » pour désactiver la clé
- Dans la boîte de dialogue « Are you sure you want to disable this key? », sélectionnez « Disable »
- Dans la zone de la case à cocher « Status », sélectionnez l'icône de corbeille pour supprimer la clé

Pour plus d'informations sur la révocation et la gestion des clés API, veuillez [consulter leur documentation](https://docs.easypost.com/docs/authentication#api-key-management).
