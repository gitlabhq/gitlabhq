## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton d'API Linear identifié. Les jetons d'API personnels peuvent être utilisés pour accéder à l'API GraphQL de Linear. Un acteur malveillant ayant accès à ce jeton peut lire ou écrire des tickets, des projets et des équipes dans Linear et dans tout système auquel le compte a été intégré. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, consultez la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour révoquer un jeton d'API Linear :

- Connectez-vous à votre compte sur <https://linear.app/>
- Sélectionnez votre organisation dans le coin supérieur gauche et sélectionnez « Preferences »
- Dans le menu de gauche, sélectionnez « API » sous « My Account »
- Trouvez la clé d'API identifiée dans la section « Personal API Keys » de la page
- Sélectionnez « Revoke » en regard de la clé identifiée
- Lorsque vous y êtes invité, sélectionnez « Revoke » dans la boîte de dialogue « Revoke access? »

Pour plus d'informations, consultez [la documentation de Linear sur l'utilisation des clés d'API personnelles](https://developers.linear.app/docs/graphql/working-with-the-graphql-api#personal-api-keys).
