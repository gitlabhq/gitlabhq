## Description {#description}

L'application cible a été identifiée comme authentifiant les utilisateurs via le schéma d'authentification de base (Basic Authentication) sur HTTP. L'authentification de base encode en base64 le nom d'utilisateur et le mot de passe, puis les envoie dans l'en-tête `Authentication`. Les personnes malveillantes qui se trouvent sur le chemin de communication (ou sur le même réseau local) entre le client et le serveur pourraient utiliser des renifleurs de paquets pour lire et décoder le nom d'utilisateur et le mot de passe.

## Remédiation {#remediation}

Si possible, passez à une méthode plus robuste pour authentifier les utilisateurs, telle qu'OAuth 2.0, ou stockez les noms d'utilisateur et les mots de passe dans un magasin de données protégé par l'algorithme Argon2id. Si l'authentification de base doit être utilisée, assurez-vous que les identifiants ne sont transmis que via des canaux sécurisés tels que HTTPS/TLS.
