## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton de build (job) GitLab CI et a été identifié. Les jetons de job sont utilisés pour exécuter des fonctionnalités dans le contexte d'un job de pipeline. Dans la plupart des cas, les jetons de job disposent de privilèges limités et ne peuvent être utilisés que pour lire depuis le dépôt où le pipeline s'exécute. Les projets externes peuvent accorder l'accès aux jetons de job provenant d'autres projets. Un acteur malveillant dispose d'une fenêtre de temps limitée pour utiliser ce jeton et tenter d'accéder au dépôt. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet). Les jetons de job étant de courte durée, il n'existe pas de processus de révocation ; le jeton n'est plus disponible une fois que le job qui l'a créé est terminé. Pour plus de détails sur ce à quoi un jeton de job est autorisé à accéder, veuillez consulter [la documentation GitLab sur les jetons de job](../../../../../ci/jobs/ci_job_token.md).
