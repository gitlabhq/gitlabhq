## Description {#description}

Le corps de la réponse contient du contenu correspondant au schéma d'une clé API Heroku ou d'un jeton d'autorisation d'application identifié. Les clés API et les jetons d'autorisation peuvent être utilisés pour effectuer des appels API au nom d'un utilisateur ou d'un compte. Un acteur malveillant ayant accès à ces jetons peut accéder à la plateforme API Heroku et à toutes les applications déployées. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour obtenir des conseils généraux sur la gestion des incidents de sécurité liés aux clés exposées, consultez la documentation GitLab sur [l'exposition des informations d'identification sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour régénérer une clé API pour l'utilisateur identifié :

- Connectez-vous à votre compte et visitez <https://dashboard.heroku.com/account>
- Dans la section « API Key », sélectionnez « Regenerate API Key »
- Lorsque vous y êtes invité, sélectionnez « Regenerate API Key » dans la boîte de dialogue « Regenerate API Key »

Pour régénérer un jeton d'autorisation d'application :

- Connectez-vous à votre compte et visitez <https://dashboard.heroku.com/account/applications>
- Dans la section « Authorizations », recherchez l'autorisation enregistrée qui contient le jeton identifié
- Sélectionnez l'icône en forme de crayon
- Sélectionnez « Regenerate token »

Pour plus d'informations sur les clés API, consultez [leur FAQ sur la génération des clés API](https://help.heroku.com/PBGP6IDE/how-should-i-generate-an-api-key-that-allows-me-to-use-the-heroku-platform-api). Heroku ne dispose d'aucune documentation sur les jetons d'autorisation d'application.
