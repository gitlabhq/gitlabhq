## Description {#description}

L'en-tête `Strict-Transport-Security` a été détecté comme manquant ou invalide. L'en-tête `Strict-Transport-Security` permet aux opérateurs de sites web de forcer les communications à s'effectuer via une connexion TLS. En activant cet en-tête, les sites web peuvent protéger leurs utilisateurs contre diverses formes d'écoute clandestine ou d'attaques par interception sur le réseau. Bien que la plupart des navigateurs empêchent le contenu mixte (chargement de ressources via HTTP lors de la navigation depuis un site HTTPS), cet en-tête garantit également que toutes les requêtes de ressources sont uniquement initiées via un transport sécurisé.

## Remédiation {#remediation}

Seules trois directives sont applicables pour l'en-tête `Strict-Transport-Security`.

1. `max-age` : cette directive obligatoire spécifie la durée (en secondes) pendant laquelle, après réception de la réponse, les communications doivent s'effectuer uniquement via un transport sécurisé.
1. `includeSubDomains` : cette directive optionnelle, sans valeur, indique que la politique s'applique à cet hôte ainsi qu'à tous les sous-domaines trouvés sous le domaine de cet hôte.
1. `preload` : bien que ne faisant pas partie de la spécification, la définition de cette valeur optionnelle permet aux principales organisations de navigateurs d'ajouter ce site à l'ensemble préchargé de sites HTTPS du navigateur. Cela nécessite une action supplémentaire de la part de l'opérateur du site web pour soumettre son domaine à la liste de préchargement HSTS du navigateur. Consultez [hstspreload.org](https://hstspreload.org/) pour plus d'informations.

Les directives invalides, ou l'en-tête `Strict-Transport-Security` apparaissant plus d'une fois (si les valeurs sont différentes), sont considérés comme invalides.

Avant d'ajouter cette configuration de sécurité à votre site web, il est recommandé de consulter les [Deployment Recommendations](https://hstspreload.org/#deployment-recommendations) de hstspreload.org.
