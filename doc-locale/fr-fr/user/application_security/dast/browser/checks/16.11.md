## Description {#description}

La méthode TRACE de débogage a été détectée comme activée sur le serveur web cible. Cette méthode HTTP renvoie les données de la requête HTTP à l'utilisateur dans une réponse. Dans certaines circonstances, ces informations peuvent inclure des données sensibles appliquées par des proxies intermédiaires.

## Remédiation {#remediation}

La méthode HTTP TRACE est uniquement destinée au débogage et ne doit pas être activée sur les sites en production.

Pour les serveurs web basés sur Apache, assurez-vous que la directive `TraceEnable` est soit supprimée, soit définie sur `off`.

Pour les serveurs Microsoft, supprimez le paramètre de registre nommé « EnableTraceMethod » situé dans la clé de registre suivante :

- `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\W3SVC\Parameters`

Pour tous les autres types de serveurs, consultez la documentation de votre produit pour savoir comment désactiver la méthode TRACE.
