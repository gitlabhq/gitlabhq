## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton de flux GitLab. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés à des clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour régénérer un jeton de flux :

- Connectez-vous à votre compte GitLab et accédez au menu latéral gauche [Paramètres utilisateur](../../../../profile/_index.md#access-your-user-settings), puis sélectionnez « Access tokens »
- Dans la section « Feed token », sélectionnez le lien « reset this token »
- Lorsque vous y êtes invité, sélectionnez « OK ». Pour plus d'informations, veuillez consulter [la documentation GitLab sur les jetons de flux](../../../../../security/tokens/_index.md#feed-token).
