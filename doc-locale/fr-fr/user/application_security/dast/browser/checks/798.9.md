## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un ID client Asana détecté. Cet ID est utilisé conjointement avec le secret client. Un acteur malveillant ayant accès à cet ID peut usurper l'identité de l'application cliente s'il a également accès au secret client. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Un ID client Asana ne peut pas être renouvelé ; seule la création d'une nouvelle application cliente OAuth permet d'obtenir un nouvel ID client. Pour plus d'informations, veuillez [consulter leur documentation sur la configuration d'OAuth](https://developers.asana.com/docs/oauth).
