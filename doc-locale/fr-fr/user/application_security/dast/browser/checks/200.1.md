## Description {#description}

Une adresse RFC 1918/RFC 4193 privée a été identifiée dans l'application cible. Les sites web publics ne devraient pas émettre de requêtes vers des adresses IP privées. Les attaquants cherchant à exécuter des attaques ultérieures, telles que la falsification de requête côté serveur (SSRF), peuvent être en mesure d'utiliser ces informations pour identifier des cibles internes supplémentaires.

## Remédiation {#remediation}

Identifiez la ressource qui spécifie incorrectement une adresse IP interne et remplacez-la par sa version publique, ou supprimez la référence de l'application cible.
