## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton d'authentification GitLab Runner qui a été identifié. Ces jetons permettent aux utilisateurs de s'enregistrer ou de s'authentifier en tant que runner auprès du projet sélectionné. Un acteur malveillant ayant accès à ce jeton peut ajouter un runner personnalisé au pipeline et potentiellement compromettre le dépôt si le runner a été utilisé. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité concernant les clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour révoquer un jeton d'authentification de runner, le runner doit être supprimé et recréé :

- Connectez-vous à votre compte GitLab et accédez au projet qui a créé le jeton d'enregistrement du runner
- Dans le menu de gauche, sélectionnez « Settings »
- Sous les options « Settings », sélectionnez « CI/CD »
- Dans la section « Runners », trouvez le runner associé au jeton identifié (vous pouvez vérifier le runner `config.toml` si vous n'êtes pas sûr)
- Sélectionnez « Remove runner »
- Lorsque vous y êtes invité, sélectionnez « Remove »

Pour plus d'informations, veuillez consulter [la documentation GitLab sur l'enregistrement des runners](https://docs.gitlab.com/runner/register/).
