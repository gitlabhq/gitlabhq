## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un secret client ou d'un ID client Intercom qui a été identifié. Les secrets clients sont utilisés pour permettre aux utilisateurs de se connecter à votre application. En fonction des portées demandées, un acteur malveillant pourrait usurper l'identité du service pour accéder aux informations de l'utilisateur. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet). Il n'est pas possible de faire pivoter les secrets clients ou les ID clients. Vous devez supprimer votre application et la recréer. Pour plus d'informations, veuillez consulter [la documentation d'Intercom sur la configuration des applications](https://developers.intercom.com/docs/build-an-integration/getting-started/build-an-app-for-your-messenger/sheets-app#set-up).
