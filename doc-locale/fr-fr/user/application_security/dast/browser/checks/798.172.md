## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton de niveau application Slack qui a été identifié. Les jetons de niveau application sont destinés à être utilisés avec les applications Slack, mais uniquement avec des API spécifiques, liées à l'application dans toutes les organisations où elle est installée.

Trois niveaux de portée peuvent être attribués :

- `connections:write:` Acheminez les interactions et les charges utiles d'événements de votre application via WebSockets
- `authorizations:read:` Consultez les informations sur les autorisations de votre application dans les équipes où elle est installée
- `app_configurations:write:` Configurez votre application

Un acteur malveillant ayant accès à ce jeton se voit accorder une ou plusieurs des autorisations ci-dessus pour accéder à l'API pour une application spécifique.

L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés divulguées, consultez la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour révoquer un jeton de niveau application Slack :

- Connectez-vous à Slack et accédez à <https://api.slack.com/apps>
- Trouvez l'application avec le jeton identifié et sélectionnez le nom
- Dans le menu de gauche, sélectionnez « Basic Information »
- Faites défiler jusqu'à la section « App-Level Tokens » et sélectionnez le nom du jeton identifié
- Dans la boîte de dialogue du jeton, sélectionnez « Revoke »
- Lorsque vous y êtes invité, sélectionnez « Yes, I'm sure » dans la boîte de dialogue « Are you sure? »
