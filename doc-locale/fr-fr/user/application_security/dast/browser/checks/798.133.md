## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton d'API de prévisualisation Contentful qui a été identifié. Un jeton d'API de prévisualisation conserve le même comportement et les mêmes paramètres que l'API de diffusion de contenu (CDA), mais fournit les derniers brouillons pour les entrées et les ressources. L'API de prévisualisation de contenu est utilisée pour afficher la dernière version d'une entrée. Un acteur malveillant ayant accès à ce jeton peut consulter les entrées publiées et non publiées. Pour plus d'informations, veuillez consulter [la documentation de l'API de prévisualisation](https://www.contentful.com/developers/docs/references/content-preview-api/). L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour obtenir des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour révoquer le jeton d'API de prévisualisation :

- Connectez-vous et rendez-vous sur <https://app.contentful.com/>
- Sélectionnez l'icône d'engrenage dans le coin supérieur droit, puis sélectionnez « API Keys »
- Trouvez la clé API détectée et sélectionnez le nom dans le tableau des clés API
- Sélectionnez « Delete » dans le coin supérieur droit
- Lorsque vous y êtes invité(e), sélectionnez « Delete ». Notez que cette action supprime également le jeton d'API de diffusion.

La génération d'un nouvel ensemble de clés API est requise.

Pour plus d'informations, veuillez consulter la [documentation développeur sur l'authentification](https://www.contentful.com/developers/docs/references/authentication/#the-content-delivery-and-preview-api).
