## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton de l'agent GitLab pour Kubernetes qui a été identifié. Le jeton d'accès Kubernetes est utilisé pour authentifier l'agent GitLab pour Kubernetes auprès d'un cluster Kubernetes. Un acteur malveillant ayant accès à ce jeton peut accéder au code source dans le projet de configuration de l'agent, accéder au code source de n'importe quel projet public sur l'instance GitLab, ou même, dans des conditions très spécifiques, obtenir un manifeste Kubernetes. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des informations d'identification sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet). Pour plus d'informations, veuillez consulter [la documentation GitLab sur la rotation du jeton de l'agent Kubernetes](../../../../clusters/agent/work_with_agent.md#reset-the-agent-token).
