## Description {#description}

Le corps de la réponse contient du contenu qui correspond au modèle d'un secret client Discord. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour obtenir des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour renouveler un secret client Discord :

- Connectez-vous et rendez-vous sur <https://discord.com/developers/applications/>.
- Sélectionnez l'application à laquelle appartient le secret identifié.
- Sélectionnez l'élément de menu « OAuth 2 » dans le menu de gauche.
- Dans la section « Client information » de la page, sélectionnez « Reset Secret ».
- Lorsque vous y êtes invité, sélectionnez « Yes, do it! ».

Pour plus d'informations, veuillez consulter [la documentation de Discord sur OAuth](https://discord.com/developers/docs/topics/oauth2).
