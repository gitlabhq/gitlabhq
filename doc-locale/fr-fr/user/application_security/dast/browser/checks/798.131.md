## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton de projet CircleCI identifié. Les jetons de projet CircleCI peuvent se voir attribuer l'une des trois portées suivantes : Status, Read Only, Admin, selon le niveau d'accès de ce jeton détecté, un acteur malveillant ayant accès à ce jeton peut être en mesure d'obtenir un accès complet au projet et aux pipelines CI/CD. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour faire pivoter un jeton de projet :

- Dans l'application CircleCI, sélectionnez Projects dans la barre latérale, puis les points de suspension (...) à côté de votre projet, et sélectionnez « Project Settings ».
- Sélectionnez API Permissions.
- Sélectionnez le « X » dans la colonne Remove pour le jeton que vous souhaitez remplacer. Lorsque la fenêtre de confirmation apparaît, saisissez le texte DELETE dans le formulaire, puis sélectionnez « Delete API Token ».
- Sélectionnez « Create API Token ».
- Choisissez la même portée que celle utilisée pour l'ancien jeton dans la liste déroulante.
- Dans le champ Label, saisissez un label pour le jeton. Il peut s'agir du même nom que celui donné à l'ancien jeton.
- Sélectionnez « Add API Token ».

Pour plus d'informations, veuillez consulter leur [documentation sur la rotation des jetons de projet](https://circleci.com/docs/managing-api-tokens/#rotating-a-project-api-token).
