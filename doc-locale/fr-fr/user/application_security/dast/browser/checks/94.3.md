## Description {#description}

L'application cible s'est révélée vulnérable à l'injection de code. Un acteur malveillant pourrait injecter du code Python arbitraire à exécuter sur le serveur. Cela pourrait entraîner une compromission totale du système en accédant à des secrets stockés, en injectant du code pour prendre le contrôle de comptes, ou en exécutant des commandes système.

## Remédiation {#remediation}

Ne transmettez jamais directement des données saisies par l'utilisateur à des fonctions qui évaluent des chaînes de caractères en tant que code, telles que `eval` ou `exec`. Il n'y a presque aucun avantage à transmettre des valeurs de type chaîne à ces méthodes ; il est donc recommandé de remplacer la logique actuelle par des implémentations plus sûres permettant d'évaluer dynamiquement la logique avec les données saisies par l'utilisateur. Une alternative consiste à stocker des fonctions ou des méthodes dans une hashmap pouvant être recherchée à l'aide d'une clé. Si la clé existe, la fonction peut être exécutée.

```python
def func_to_run():
    print('hello world')

function_map = {'fn': func_to_run}

input = 'fn'

if input in function_map:
    function_map[input]()
else:
    print('invalid input')
```
