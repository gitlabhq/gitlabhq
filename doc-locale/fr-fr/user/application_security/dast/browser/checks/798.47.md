## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'une clé de chiffrement de test Flutterwave qui a été identifiée. Cette clé est uniquement utilisée avec le [point de terminaison de débit direct](https://developer.flutterwave.com/docs/direct-card-charge). Cette clé est utilisée pour chiffrer les charges utiles contenant les détails de carte avant leur envoi. Pour plus d'informations, consultez le [guide de chiffrement de Flutterwave](https://developer.flutterwave.com/docs/encryption). Un acteur malveillant ayant accès à cette clé peut potentiellement déchiffrer des transactions de test, lesquelles peuvent inclure des informations de carte de crédit. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, consultez la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour effectuer la rotation de votre clé :

- Connectez-vous et accédez à <https://app.flutterwave.com/dashboard/home>
- Sélectionnez « Settings » dans le menu de gauche
- Sélectionnez « API Keys » sous « Developers » dans le menu de gauche
- Vérifiez que le mode « Test mode » est activé
- Sélectionnez « Generate secret key » pour effectuer la rotation de la clé publique, secrète et de chiffrement

Pour plus d'informations, consultez la [documentation Flutterwave sur l'authentification](https://developer.flutterwave.com/docs/authentication).
