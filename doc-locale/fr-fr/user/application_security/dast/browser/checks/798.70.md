## Description {#description}

Le corps de la réponse contient du contenu correspondant au schéma d'une clé API Lob qui a été identifiée. Les clés API peuvent être utilisées pour vérifier des adresses, créer des campagnes, imprimer ou envoyer du courrier directement aux clients. Un acteur malveillant ayant accès à cette clé peut effectuer n'importe quelle requête API vers Lob sans restriction. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés divulguées, veuillez consulter la documentation GitLab sur [l'exposition des informations d'identification sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour faire pivoter une clé API :

- Connectez-vous à votre compte et accédez à <https://dashboard.lob.com/>
- Dans le coin inférieur gauche, sélectionnez l'icône d'engrenage / l'option de menu « Settings »
- Sous « Settings », sélectionnez l'onglet « API Keys »
- Sous « Live Environment » dans la section « Secret API Keys », sélectionnez l'icône de flèche de rotation
- Lorsque vous y êtes invité, sélectionnez « Yes » dans la boîte de dialogue « Rotate Secret Live API Key »

Pour plus d'informations, veuillez consulter [la documentation de Lob sur les clés API](https://docs.lob.com/#tag/Authentication/API-Keys).
