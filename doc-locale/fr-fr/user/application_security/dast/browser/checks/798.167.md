## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'une clé privée PKCS8 identifiée. PKCS #8 est une syntaxe standard pour le stockage des informations de clé privée. Un acteur malveillant ayant accès à cette clé peut chiffrer et déchiffrer l'ensemble des messages passés et futurs. Notez que les messages passés chiffrés à l'aide de cette clé doivent être considérés comme compromis, et les nouveaux messages ne peuvent pas être considérés comme fiables. L'exposition de cette valeur pourrait permettre à des personnes malveillantes d'accéder à toutes les ressources accordées par ce jeton d'accès personnel.

## Remédiation {#remediation}

Pour obtenir des conseils généraux sur la gestion des incidents de sécurité liés aux clés divulguées, consultez la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet). Une clé PKCS8 ne peut pas être renouvelée ; une nouvelle clé doit être générée. Pour plus d'informations, consultez [la documentation d'openssl.org sur des exemples de génération de clés](https://docs.openssl.org/3.4/man1/openssl-genpkey/#examples).
