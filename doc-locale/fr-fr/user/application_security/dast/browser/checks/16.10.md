## Description {#description}

Un `Content-Security-Policy` (CSP) a été identifié sur le site cible qui signale des violations lors de la tentative de chargement de la page dans un navigateur. Cela peut perturber vos utilisateurs lorsqu'ils tentent de visiter la page.

## Remédiation {#remediation}

Examinez les violations pour déterminer si une action est nécessaire.
