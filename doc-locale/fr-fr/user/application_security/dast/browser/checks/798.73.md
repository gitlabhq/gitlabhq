## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'une clé de vérification publique Mailgun qui a été identifiée. Ces clés sont obsolètes et vous devriez utiliser le service de vérification v4 à la place. Une entité malveillante ayant accès à cette clé peut l'utiliser pour valider des adresses e-mail. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés divulguées, consultez la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour faire pivoter votre clé de vérification publique :

- Connectez-vous à votre compte Mailgun et accédez au tableau de bord à l'adresse <https://app.mailgun.com/>
- En haut à droite, sélectionnez votre profil de compte, puis sélectionnez « API Security »
- Dans la section « Verification public key », sélectionnez l'icône de flèche de rotation sur le côté droit
- Lorsque vous y êtes invité, sélectionnez « Reset Key » dans la boîte de dialogue « Reset public verification key »

Pour plus d'informations, consultez [la documentation de Mailgun sur les clés API](https://mailchimp.com/help/about-api-keys).
