## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton de déclenchement de pipeline GitLab identifié. Les jetons de déclenchement de pipeline peuvent être utilisés pour exécuter des pipelines pour une branche ou un tag d'un projet. Le jeton usurpe l'accès au projet et les permissions d'un utilisateur. Un acteur malveillant ayant accès à ce jeton peut exécuter des pipelines avec des variables personnalisées, pouvant potentiellement compromettre le dépôt. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour obtenir des conseils généraux sur la gestion des incidents de sécurité concernant les clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour révoquer un jeton de déclenchement de pipeline :

- Connectez-vous à votre compte GitLab et accédez au projet qui a créé le jeton de déclenchement de pipeline
- Dans le menu de gauche, sélectionnez « Settings »
- Sous les options « Settings », sélectionnez « CI/CD »
- Dans la section « Pipeline trigger tokens », retrouvez le jeton identifié
- Sélectionnez l'icône de corbeille dans la colonne « Actions » du tableau « Active pipeline trigger tokens »
- Lorsque vous y êtes invité, sélectionnez « Revoke trigger »

Pour plus d'informations, veuillez consulter [la documentation GitLab sur les jetons de déclenchement de pipeline](../../../../../ci/triggers/_index.md#create-a-pipeline-trigger-token).
