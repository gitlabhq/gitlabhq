## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'une URL de webhook Slack détectée. Les URL de webhook Slack sont utilisées pour publier des messages provenant de sources externes dans Slack. Elles utilisent des requêtes HTTP avec une charge utile JSON, qui inclut le message et quelques autres détails facultatifs. Vous pouvez inclure des pièces jointes aux messages pour afficher des messages richement formatés. Un acteur malveillant ayant accès à cette URL peut publier des messages sur le canal Slack auquel elle est liée. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour obtenir des conseils généraux sur la gestion des incidents de sécurité concernant les clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des informations d'identification sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour faire pivoter l'URL du webhook Slack :

- Connectez-vous à Slack et accédez à <https://api.slack.com/apps>
- Trouvez l'application avec l'URL de webhook identifiée et sélectionnez le nom
- Dans le menu de gauche, sélectionnez « Incoming Webhooks »
- Dans le tableau « Webhook URL », sélectionnez l'icône de la corbeille à côté de l'URL de webhook identifiée.
- Lorsque vous y êtes invité, sélectionnez « Remove » dans la boîte de dialogue de confirmation

Pour plus d'informations, veuillez consulter [la documentation Slack sur les webhooks](https://api.slack.com/messaging/webhooks).
