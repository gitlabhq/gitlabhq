## Description {#description}

Il est possible de forcer l'analyseur XML de l'application à inclure des ressources externes. Cela peut inclure des fichiers ou, dans certaines circonstances, déclencher des requêtes vers des serveurs tiers.

## Remédiation {#remediation}

Consultez la documentation de l'analyseur XML utilisé par l'application cible pour obtenir des recommandations de sécurité et des étapes de renforcement. Il est recommandé que tous les analyseurs XML désactivent la résolution des entités externes et les fonctionnalités XML `xinclude`. La plupart des analyseurs XML basés sur `libxml` peuvent également être configurés pour désactiver l'accès au réseau.
