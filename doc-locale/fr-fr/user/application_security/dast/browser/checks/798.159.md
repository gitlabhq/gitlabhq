## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un Artifactory Identity Token identifié. Un Artifactory Identity Token permet l'authentification pour accéder aux dépôts, télécharger des artefacts, téléverser des artefacts et exécuter des opérations privilégiées dans JFrog Artifactory en fonction des permissions attribuées au jeton. En cas de fuite, un acteur malveillant pourrait utiliser ce jeton pour voler du code propriétaire, injecter des dépendances compromises dans la chaîne d'approvisionnement logicielle, ou potentiellement obtenir un accès non autorisé aux systèmes CI/CD connectés qui s'appuient sur Artifactory pour les builds. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité concernant les clés divulguées, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).
