## Description {#description}

Il est possible de fournir un modèle XSL à un processeur XSLT côté serveur. Les processeurs XSLT peuvent être détournés pour lire ou écrire des fichiers, initier des connexions sortantes et, dans certains cas, exécuter du code arbitraire.

## Remédiation {#remediation}

Les applications ne doivent jamais accepter des feuilles de style fournies par les utilisateurs. Les processeurs XSLT ne sont pas conçus pour traiter des fichiers de feuilles de style potentiellement malveillants. Cependant, certains processeurs implémentent ou proposent des fonctionnalités de sécurité qui peuvent être disponibles. Consultez la documentation du processeur XSLT utilisé par l'application cible pour obtenir des directives de sécurité et des étapes de renforcement. Il est recommandé que tous les analyseurs et processeurs XML désactivent au minimum la résolution des entités externes.
