## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton d'accès AWS détecté. Les jetons d'accès AWS sont généralement associés à leurs valeurs de clé secrète. Un acteur malveillant ayant accès à ce jeton peut accéder aux services AWS avec les mêmes autorisations que l'utilisateur qui a généré la clé, à condition d'avoir accès aux deux valeurs. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet). Pour supprimer une clé d'accès : dans la section « Access keys », trouvez la clé identifiée ; sélectionnez « Actions » ; sélectionnez « Delete » ; suivez les instructions dans la boîte de dialogue pour d'abord désactiver, puis confirmer la suppression. Pour plus d'informations sur la gestion et la révocation des clés d'accès pour AWS, veuillez consulter leur [documentation](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_credentials_access-keys.html#Using_CreateAccessKey).
