## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton de déploiement GitLab qui a été identifié. Un jeton de déploiement permet l'authentification des tâches de déploiement, indépendamment d'un compte utilisateur. Avec un jeton de déploiement, les tâches automatisées peuvent : cloner des dépôts Git ; effectuer des opérations pull et push vers un registre de conteneurs GitLab ; effectuer des opérations pull et push vers un registre de paquets GitLab. Un acteur malveillant ayant accès à ce jeton peut accéder aux dépôts Git ou compromettre les paquets ou conteneurs publiés. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité concernant les clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour plus d'informations, veuillez consulter [la documentation GitLab sur la révocation des jetons de déploiement](../../../../project/deploy_tokens/_index.md).
