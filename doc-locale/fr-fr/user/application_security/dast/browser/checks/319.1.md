## Description {#description}

L'application cible a été détectée comme effectuant des requêtes de ressources via des protocoles de transport non sécurisés (HTTP). Cela est généralement dû à des éléments HTML qui chargent des ressources en utilisant le schéma `http://` au lieu de `https://`. Il convient de noter que la plupart des navigateurs modernes bloquent automatiquement ces requêtes, ce qui limite le risque.

Certaines parties de l'application peuvent ne pas fonctionner correctement car ces fichiers ne sont pas chargés correctement.

## Remédiation {#remediation}

Assurez-vous que tous les éléments HTML qui chargent des ressources depuis une URL (JavaScript, feuilles de style, images, vidéos et autres médias) sont configurés pour utiliser le schéma `https://` au lieu de `http://`. Les développeurs peuvent également utiliser le schéma `//`, qui ne chargera les ressources que via le même protocole que celui utilisé pour charger la page d'origine.

Un navigateur visitant le site web `https://example.com` avec le HTML chargeant un fichier en utilisant `<script src="//example.com/cdn/bundle.js"></script>` garantirait que le fichier `example.com/cdn/bundle.js` est chargé via HTTPS.
