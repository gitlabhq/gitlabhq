## Description {#description}

L'application cible s'est révélée vulnérable à l'injection de code. Un acteur malveillant pourrait injecter du code PHP arbitraire à exécuter sur le serveur. Cela pourrait mener à une compromission totale du système en accédant à des secrets stockés, en injectant du code pour prendre le contrôle de comptes ou en exécutant des commandes OS.

## Remédiation {#remediation}

Ne transmettez jamais les données saisies par l'utilisateur directement dans des fonctions qui évaluent les données de chaîne en tant que code, comme `eval`. Il n'y a presque aucun avantage à passer des valeurs de chaîne à `eval` ; aussi, la meilleure recommandation est de remplacer la logique actuelle par des implémentations plus sûres pour évaluer dynamiquement la logique avec les données saisies par l'utilisateur. Une alternative consiste à utiliser un `array()`, en stockant les données saisies attendues par l'utilisateur dans une clé de tableau, et à utiliser cette clé comme référence pour exécuter des fonctions :

```php
$func_to_run = function()
{
    print('hello world');
};

$function_map = array();
$function_map["fn"] = $func_to_run; // store additional input to function mappings here

$input = "fn";

// lookup "fn" as the key
if (array_key_exists($input, $function_map)) {
    // run the $func_to_run that was stored in the "fn" array hash value.
    $func = $function_map[$input];
    $func();
} else {
    print('invalid input');
}
```
