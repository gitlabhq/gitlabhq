## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton d'API privé Mailgun qui a été identifié. Cette clé vous permet d'effectuer des opérations de lecture, d'écriture et de suppression via différents endpoints d'API et pour chacun de vos domaines d'envoi. Un acteur malveillant ayant accès à cette clé peut effectuer toute requête API vers Mailgun sans restriction. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour faire pivoter un jeton d'API privé :

- Connectez-vous à votre compte Mailgun et accédez au tableau de bord à l'adresse <https://app.mailgun.com/>
- En haut à droite, sélectionnez votre profil de compte, puis sélectionnez « API Security »
- Trouvez la clé identifiée et sélectionnez l'icône de corbeille
- Si vous ne pouvez pas sélectionner l'icône de corbeille, vous devez d'abord générer une nouvelle clé en sélectionnant « Add new key »
- Lorsque vous y êtes invité, sélectionnez « Delete » dans la boîte de dialogue « Delete API Key »

Pour plus d'informations, veuillez consulter [la documentation de Mailgun sur les clés API](https://documentation.mailgun.com/docs/mailgun/user-manual/get-started/#primary-account-api-key).
