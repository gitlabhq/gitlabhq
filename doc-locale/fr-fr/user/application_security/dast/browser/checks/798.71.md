## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'une clé API publiable Lob identifiée. Les clés API publiables sont uniquement utilisées pour les vérifications aux États-Unis, les vérifications internationales et les requêtes d'autocomplétion aux États-Unis. Un acteur malveillant ayant accès à cette clé peut exécuter des fonctions limitées sur votre compte. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour faire pivoter une clé API publiable :

- Connectez-vous à votre compte et accédez à <https://dashboard.lob.com/>
- Dans le coin inférieur gauche, sélectionnez l'icône d'engrenage/l'option de menu « Settings »
- Sous « Settings », sélectionnez l'onglet « API Keys »
- Identifiez si la clé était une clé d'environnement de production ou de test dans la section « Publishable API Keys »
- Sélectionnez l'icône de rotation de la clé identifiée
- Lorsque vous y êtes invité, sélectionnez « Yes » dans la boîte de dialogue « Rotate Publishable API Key »

Pour plus d'informations, veuillez consulter [la documentation de Lob sur les clés API](https://docs.lob.com/#tag/Authentication/API-Keys).
