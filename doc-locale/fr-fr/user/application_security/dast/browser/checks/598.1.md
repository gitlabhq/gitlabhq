---

## Description {#description}

Un ID de session a été identifié dans l'URL de la requête ainsi que dans une valeur de cookie. Les ID de session ne doivent pas être envoyés dans des requêtes GET, car ils peuvent être capturés par des systèmes proxy, stockés dans l'historique du navigateur ou dans des fichiers journaux. Si un attaquant venait à accéder à l'ID de session, il pourrait potentiellement obtenir l'accès au compte cible.

## Remédiation {#remediation}

Les en-têtes de requête étant rarement journalisés ou capturés par des systèmes tiers, assurez-vous que les valeurs d'ID de session ne sont envoyées que dans des cookies (assignés via les en-têtes de réponse `Set-Cookie`) et jamais dans l'URL de la requête.
