## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'une clé API Anthropic qui a été détectée. Les clés Anthropic sont utilisées pour accéder aux services d'IA générative. Des acteurs malveillants pourraient utiliser ces clés pour accumuler des frais excessifs sur votre compte. L'exposition de cette valeur pourrait permettre à des personnes malveillantes d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour obtenir des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour remédier à une clé Anthropic compromise, vous devez la supprimer de la liste des clés API de votre organisation.

- Connectez-vous à votre [compte Anthropic](https://console.anthropic.com/)
- Accédez aux « API settings » en sélectionnant l'icône de votre profil, puis en sélectionnant « API Keys » ou via l'onglet Settings
- Identifiez la clé API compromise et sélectionnez le menu meatball (trois points horizontaux) situé à côté de la clé que vous souhaitez supprimer
- Sélectionnez « Delete API Key »
- Remarque : la suppression d'une clé API est une action permanente et ne peut pas être annulée
- Générez une nouvelle clé en sélectionnant « Create Key » et donnez-lui un nom descriptif

Pour plus d'informations, veuillez consulter le site web d'Anthropic : <https://support.anthropic.com/en/articles/8384961-what-should-i-do-if-i-suspect-my-api-key-has-been-compromised>.
