## Description {#description}

Le corps de la réponse contient du contenu correspondant au schéma d'une clé de signature de webhook Mailgun identifiée. Cette clé est utilisée par Mailgun pour signer tous les payloads de messages webhook entrants. Un acteur malveillant ayant accès à cette clé peut potentiellement signer de faux événements webhook et les envoyer à votre service pour passer la validation et être traités. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés divulguées, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour faire pivoter votre clé de signature de webhook HTTP :

- Connectez-vous à votre compte Mailgun et accédez au tableau de bord à l'adresse <https://app.mailgun.com/>
- En haut à droite, sélectionnez votre profil de compte et sélectionnez « API Security »
- Dans la section « HTTP webhook signing key », sélectionnez l'icône de flèche de rotation sur le côté droit
- Lorsque vous y êtes invité, sélectionnez « Reset Key » dans la boîte de dialogue « Reset HTTP webhook signing key »

Pour plus d'informations, veuillez consulter [la documentation de Mailgun sur les webhooks](https://documentation.mailgun.com/docs/mailgun/user-manual/tracking-messages/#securing-webhooks).
