## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton d'accès Oculus identifié. Les jetons utilisateurs sont nécessaires chaque fois que votre application appelle une API pour lire, modifier ou écrire les données Oculus d'une personne spécifique en son nom. Un acteur malveillant ayant accès à ce jeton peut appeler l'API Oculus au nom d'un utilisateur spécifique du service. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des informations d'identification sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour effectuer la rotation d'un jeton d'accès Oculus :

- Connectez-vous à votre compte développeur Oculus à l'adresse <https://developer.oculus.com/>
- Sélectionnez « Development » dans le menu de gauche, puis sélectionnez « API »
- Sous « User Token », sélectionnez « Generate Token »

Pour plus d'informations, veuillez consulter [la documentation Meta sur la protection des jetons d'accès](https://developers.meta.com/horizon/resources/publish-sec-details#protecting-credentials-and-access-tokens)
