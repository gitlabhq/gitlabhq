## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton d'accès npm identifié. Les jetons d'accès peuvent être classiques ou granulaires, et permettent tous deux de personnaliser les autorisations. Selon les autorisations accordées, un acteur malveillant ayant accès à ce jeton peut lire des packages et des informations sur les packages, ou créer de nouveaux packages et les publier sous le compte qui les a créés. L'exposition de cette valeur pourrait permettre à des personnes malveillantes d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité concernant les clés divulguées, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour révoquer un jeton d'accès depuis l'interface utilisateur :

- Connectez-vous à votre compte npm à l'adresse <https://www.npmjs.com/login>
- Dans le coin supérieur droit, sélectionnez votre photo de profil, puis sélectionnez « Access Tokens »
- Trouvez le jeton identifié et sélectionnez « x » dans la colonne « Delete »
- Lorsque vous y êtes invité, sélectionnez « OK » dans la boîte de dialogue

Pour plus d'informations, veuillez consulter [la documentation npm sur la révocation des jetons d'accès](https://docs.npmjs.com/revoking-access-tokens).
