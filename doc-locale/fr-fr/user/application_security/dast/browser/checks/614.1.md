## Description {#description}

Le cookie a été transmis dans une réponse `Set-Cookie` sans l'attribut `Secure` défini. Pour éviter que des valeurs de cookies sensibles soient accidentellement transmises en clair via HTTP, déclarez les cookies avec l'attribut `Secure`.

## Remédiation {#remediation}

La plupart des frameworks d'applications web permettent de configurer la manière dont les cookies sont envoyés aux agents utilisateurs. Consultez la documentation de votre framework pour plus d'informations sur la façon d'activer différents attributs de sécurité lors de l'attribution de cookies aux clients.

Si l'application attribue des cookies en écrivant directement dans les en-têtes de réponse, veillez à ce que toutes les réponses incluent l'attribut `Secure`. En activant cette protection, l'application n'enverra plus de cookies sensibles via HTTP.

Exemple :

```http
Set-Cookie: {cookie_name}=<random secure value>; Secure
```
