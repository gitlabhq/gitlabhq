## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'une clé de test secrète Stripe. Les clés de test secrètes servent à accéder aux données et fonctionnalités de test et à les exécuter. Un acteur malveillant ayant accès à cette clé de test ne peut que simuler un accès ; les objets de compte ne renvoient pas de champs sensibles. L'exposition de cette valeur pourrait permettre à des personnes malveillantes d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour obtenir des conseils généraux sur la gestion des incidents de sécurité liés aux clés divulguées, consultez la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour effectuer la rotation de votre clé de test secrète Stripe :

- Connectez-vous à votre compte Stripe et accédez à <https://dashboard.stripe.com/apikeys>
- Assurez-vous que le mode « Test mode » est activé en sélectionnant le bouton bascule dans le menu supérieur
- Dans la section « Standard keys », repérez la clé identifiée et sélectionnez les points de suspension sur le côté droit
- Sélectionnez « Roll key... »
- Dans la boîte de dialogue « Roll API key », sélectionnez une date d'expiration, par exemple « now »
- Sélectionnez « Roll API Key »

Pour plus d'informations, consultez [la documentation de Stripe sur la rotation des clés API](https://docs.stripe.com/keys#rolling-keys).
