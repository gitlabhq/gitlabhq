## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'une clé secrète Stripe en production. Les clés secrètes en production authentifient les requêtes sur votre serveur en mode production. Par défaut, vous pouvez utiliser cette clé pour effectuer n'importe quelle requête API sans restriction. Un acteur malveillant ayant accès à cette clé pourrait obtenir un accès en lecture/écriture à toutes les données Stripe de ce compte. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour obtenir des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, consultez la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour effectuer une rotation de votre clé secrète Stripe en production :

- Connectez-vous à votre compte Stripe et accédez à <https://dashboard.stripe.com/apikeys>
- Vérifiez que le « Mode test » est désactivé
- Dans la section « Standard keys », trouvez la clé identifiée et sélectionnez les points de suspension sur le côté droit
- Sélectionnez « Roll key... » - Dans la boîte de dialogue « Roll API key », sélectionnez une date d'expiration, par exemple « now »
- Sélectionnez « Roll API Key »

Pour plus d'informations, consultez [la documentation Stripe sur la rotation des clés API](https://docs.stripe.com/keys#rolling-keys).
