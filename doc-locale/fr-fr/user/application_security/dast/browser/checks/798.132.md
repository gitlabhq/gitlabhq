## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton d'accès personnel CircleCI identifié. Les jetons d'accès personnels accordent le même niveau de permissions que l'utilisateur qui a créé le jeton. Un acteur malveillant ayant accès à ce jeton peut usurper l'identité de l'utilisateur et accéder à toutes les fonctionnalités et services de CircleCI. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour effectuer la rotation d'un jeton d'accès personnel :

- Dans l'application CircleCI, accédez à vos paramètres utilisateur.
- Sélectionnez « Personal API Tokens ».
- Sélectionnez « X » dans la colonne Remove pour le jeton que vous souhaitez remplacer et confirmez la suppression. Sélectionnez « Create New Token ».
- Dans le champ Token name, saisissez un nouveau nom pour l'ancien jeton en cours de rotation. Ce nom peut être identique à celui de l'ancien jeton.
- Sélectionnez « Add API Token ».
- Une fois le jeton affiché, copiez-le et collez-le dans un autre emplacement. Il n'est pas possible de consulter le jeton à nouveau.

Pour plus d'informations, veuillez consulter leur [documentation sur la rotation des jetons d'accès personnels](https://circleci.com/docs/managing-api-tokens/#rotating-a-personal-api-token).
