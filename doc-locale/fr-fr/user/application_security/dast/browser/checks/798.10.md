## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un secret client Asana détecté. Les secrets clients sont utilisés pour l'authentification et l'autorisation via OAuth. Un acteur malveillant ayant accès à ce secret pourrait accéder aux comptes utilisateurs et exécuter des fonctionnalités en leur nom. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés divulguées, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet). Pour révoquer le secret client détecté : connectez-vous à votre compte développeur et accédez à <https://app.asana.com/0/my-apps> ; sur la page « My apps », trouvez l'application qui utilise le secret ; sélectionnez votre application dans la console développeur ; accédez à l'onglet « OAuth » dans la barre latérale ; sélectionnez « Reset » à côté de votre secret client. Pour plus d'informations, veuillez [consulter leur documentation sur la configuration d'OAuth](https://developers.asana.com/docs/oauth)
