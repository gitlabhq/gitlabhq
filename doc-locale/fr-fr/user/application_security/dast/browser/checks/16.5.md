## Description {#description}

Le site web cible renvoie des en-têtes AspNet ainsi que des informations de version de ce site web. En exposant ces valeurs, des attaquants peuvent tenter de déterminer si le logiciel cible est vulnérable à des vulnérabilités connues, ou de répertorier les sites connus utilisant des versions particulières afin de les exploiter ultérieurement lorsqu'une vulnérabilité est identifiée dans cette version spécifique.

## Remédiation {#remediation}

Pour supprimer l'en-tête `X-AspNet-Version`, définissez `<httpRuntime enableVersionHeader="false" />` dans la section `<system.Web>` du fichier `Web.config`.
