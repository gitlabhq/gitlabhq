## Description {#description}

L'application est vulnérable à l'injection de template côté serveur (SSTI), qui permet aux attaquants de manipuler des templates côté serveur. Cette vulnérabilité survient lorsque des données utilisateur non fiables sont directement utilisées dans des templates côté serveur sans assainissement adéquat. Les attaquants peuvent exploiter cette faiblesse pour injecter et exécuter du code arbitraire dans des templates, compromettant potentiellement l'intégrité et la confidentialité du système.

## Remédiation {#remediation}

Les données contrôlées par l'utilisateur doivent toujours avoir leurs éléments spéciaux neutralisés lorsqu'elles sont utilisées dans la construction d'instructions Expression Language. Consultez la documentation du système de templates utilisé pour savoir comment neutraliser correctement les données contrôlées par l'utilisateur.
