## Description {#description}

L'en-tête `X-Content-Type-Options` avec la valeur `nosniff` garantit que les agents utilisateurs ne tentent pas de deviner le format des données reçues. Les agents utilisateurs, tels que les navigateurs, tentent généralement de deviner le type de ressource demandée via un processus appelé « reniflage de type MIME » (MIME type sniffing).

Sans cet en-tête, le navigateur peut mal interpréter les données, ce qui peut conduire à des attaques de confusion MIME. Si un attaquant parvient à téléverser des fichiers accessibles via un navigateur, il pourrait téléverser des fichiers pouvant être interprétés comme du HTML et exécuter des attaques de type Cross-Site Scripting (XSS).

## Remédiation {#remediation}

Nous recommandons que l'en-tête et la valeur `X-Content-Type-Options: nosniff` soient définis à l'échelle du serveur. Cela garantit que les ressources auxquelles il manque par erreur une valeur `Content-Type` ne sont pas mal interprétées.
