## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'une clé secrète de chiffrement age détectée. Age est un outil de chiffrement de fichiers moderne et sécurisé, un format et une bibliothèque Go. Il se caractérise par de petites clés explicites, aucune option de configuration et une composabilité de style UNIX. Ces clés sont généralement utilisées pour chiffrer des fichiers sensibles. Un acteur malveillant ayant accès à cette clé peut déchiffrer n'importe quel fichier ou message chiffré avec elle. L'exposition de cette valeur pourrait permettre à des attaquants d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, veuillez consulter la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet). Pour générer une nouvelle clé age, exécutez la commande suivante : ```console age-keygen -o new_key.age``` Envisagez de protéger le fichier d'identité avec une phrase de passe. Cela peut ne pas être possible si cette clé est destinée à être utilisée dans des systèmes automatisés : ```console age-keygen | age -p > new_key.age```
