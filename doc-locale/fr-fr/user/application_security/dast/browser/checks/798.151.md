## Description {#description}

Le corps de la réponse contient du contenu correspondant au modèle d'un jeton SCIM GitLab qui a été identifié. Le jeton SCIM est utilisé pour configurer des fournisseurs d'identité (IdP) tiers. Un acteur malveillant ayant accès à ce jeton peut configurer un IdP et ajouter des utilisateurs pour accéder au système GitLab. L'exposition de cette valeur pourrait permettre à des personnes malveillantes d'accéder à toutes les ressources accordées par ce jeton.

## Remédiation {#remediation}

Pour des conseils généraux sur la gestion des incidents de sécurité liés aux clés compromises, consultez la documentation GitLab sur [l'exposition des identifiants sur Internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet).

Pour faire pivoter le jeton SCIM :

- Connectez-vous à votre compte GitLab en tant qu'administrateur
- Dans la barre latérale gauche, en bas, sélectionnez Admin
- Sélectionnez « Settings » puis « General »
- Développez la section SCIM Token et sélectionnez « Generate a SCIM token »
- Sous « Your SCIM token », sélectionnez « reset it » pour générer un nouveau jeton

Pour plus d'informations, consultez la [documentation de GitLab sur la configuration SCIM](../../../../../administration/settings/scim_setup.md#configure-gitlab).
