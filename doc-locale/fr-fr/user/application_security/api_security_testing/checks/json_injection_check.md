## Description {#description}

Vérification des vulnérabilités de sérialisation/injection JSON.

## Remédiation {#remediation}

L'injection JSON est une technique d'attaque utilisée pour manipuler ou compromettre la logique d'une application ou d'un service JSON. L'injection de contenu et/ou de structures JSON non prévus dans un message JSON peut modifier la logique prévue de l'application. De plus, l'injection JSON peut entraîner l'insertion de contenu malveillant dans le message/document résultant.
