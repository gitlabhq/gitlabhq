- Édition : Gratuite, GitLab Premium, GitLab Ultimate
- Offre : GitLab.com, GitLab Self-Managed, GitLab Dedicated

{{< /details >}}

Trouvez la version de GitLab que vous utilisez.

## Pour GitLab Self-Managed et GitLab Dedicated {#for-gitlab-self-managed-and-gitlab-dedicated}

Prérequis :

- Vous devez être un utilisateur authentifié.

Pour trouver la version de GitLab :

- Dans la barre latérale gauche, en bas, sélectionnez **Aide** > **Aide**.

La version s'affiche en haut de la page.

## Pour GitLab.com {#for-gitlabcom}

- Accédez à <https://gitlab.com/help>.

La version s'affiche en haut de la page. Par exemple, `GitLab Enterprise Edition 18.10.0-pre bc9e216d399` indique une version préliminaire de GitLab 18.10.
