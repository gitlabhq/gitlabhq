Le tableau de bord des [métriques DevOps Research and Assessment (DORA)](dora_metrics.md) affiche l'évolution de chaque métrique DORA dans le temps, pour la dernière semaine, le dernier mois, les 90 derniers jours ou les 180 derniers jours. Ces informations fournissent des insights sur la santé de votre organisation.

## Consulter les analyses des métriques DORA {#view-dora-metrics-analytics}

Vous pouvez consulter le tableau de bord des métriques DORA pour un groupe ou un projet.

Prérequis :

- Pour consulter les métriques DORA, le groupe ou le projet doit disposer d'un environnement dans l'[édition de déploiement de production](../../ci/environments/_index.md#deployment-tier-of-environments).

### Pour un groupe {#for-a-group}

Pour consulter le tableau de bord des métriques DORA pour un groupe :

1. Dans la barre supérieure, sélectionnez **Rechercher ou accéder à** et repérez votre groupe.
1. Dans la barre latérale gauche, sélectionnez **Analyse** > **Tableaux de bord de données d'analyse**.
1. Sélectionnez **DORA metrics dashboard**.

### Pour un projet {#for-a-project}

Pour consulter le tableau de bord des métriques DORA pour un projet :

1. Dans la barre supérieure, sélectionnez **Rechercher ou accéder à** et repérez votre projet.
1. Dans la barre latérale gauche, sélectionnez **Analyse** > **Tableaux de bord de données d'analyse**.
1. Sélectionnez **DORA metrics dashboard**.
