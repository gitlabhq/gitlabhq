La fonctionnalité **Nouveautés** présente aux utilisateurs les points forts des nouvelles fonctionnalités des 10 dernières versions de GitLab.

Tous les utilisateurs peuvent voir la liste des fonctionnalités, mais les entrées peuvent différer selon le type d'abonnement :

- Les fonctionnalités disponibles uniquement sur GitLab.com ne sont pas affichées sur les instances GitLab Self-Managed.
- Les fonctionnalités disponibles uniquement sur les instances GitLab Self-Managed ne sont pas affichées sur GitLab.com.

Pour GitLab Self-Managed, la mise à jour de **Nouveautés** est incluse dans la première release de correctif après une nouvelle version. Par exemple, `13.10.1`.

## Configurer Nouveautés {#configure-whats-new}

Vous pouvez configurer **Nouveautés** pour afficher les fonctionnalités en fonction du niveau, ou vous pouvez le masquer.

Prérequis :

- Vous devez être administrateur.

Pour configurer **Nouveautés** :

1. Dans le coin supérieur droit, sélectionnez **Admin**.
1. Dans la barre latérale gauche, sélectionnez **Paramètres** > **Préférences**.
1. Développez **Nouveautés** et choisissez l'option requise.
1. Sélectionnez **Sauvegarder les modifications**.
