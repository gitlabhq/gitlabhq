GitLab expose certaines variables d'environnement qui peuvent être utilisées pour remplacer leurs valeurs par défaut.

Les utilisateurs configurent généralement GitLab avec :

- `/etc/gitlab/gitlab.rb` pour les installations avec le package Linux.
- `gitlab.yml` pour les installations compilées à partir des sources.

Vous pouvez utiliser les variables d'environnement suivantes pour remplacer certaines valeurs :

## Variables d'environnement prises en charge {#supported-environment-variables}

| Variable                                     | Type    | Description                                                                                                                                                                                                                                                                                                                      |
|----------------------------------------------|---------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `DATABASE_URL`                               | string  | L'URL de la base de données ; est de la forme : `postgresql://localhost/blog_development`.                                                                                                                                                                                                                                                     |
| `ENABLE_BOOTSNAP`                            | string  | Active ou désactive [Bootsnap](https://github.com/Shopify/bootsnap) pour accélérer le démarrage initial de Rails. Activé par défaut pour les environnements hors production. Définir à `0` pour désactiver.                                                                                                                                                           |
| `EXTERNAL_URL`                               | string  | Spécifiez l'URL externe au [moment de l'installation](https://docs.gitlab.com/omnibus/settings/configuration/#specify-the-external-url-at-the-time-of-installation).                                                                                                                                                     |
| `EXTERNAL_VALIDATION_SERVICE_TIMEOUT`        | integer | Délai d'attente, en secondes, pour un [service de validation de pipeline CI/CD externe](cicd/external_pipeline_validation.md). La valeur par défaut est `5`.                                                                                                                                                                                                  |
| `EXTERNAL_VALIDATION_SERVICE_URL`            | string  | URL vers un [service de validation de pipeline CI/CD externe](cicd/external_pipeline_validation.md).                                                                                                                                                                                                                                    |
| `EXTERNAL_VALIDATION_SERVICE_TOKEN`          | string  | Le `X-Gitlab-Token` pour l'authentification auprès d'un [service de validation de pipeline CI/CD externe](cicd/external_pipeline_validation.md).                                                                                                                                                                                              |
| `GITLAB_CDN_HOST`                            | string  | Définit l'URL de base d'un CDN pour diffuser des ressources statiques (par exemple, `https://mycdnsubdomain.fictional-cdn.com`).                                                                                                                                                                                                                    |
| `GITLAB_EMAIL_DISPLAY_NAME`                  | string  | Le nom utilisé dans le champ **De** dans les e-mails envoyés par GitLab.                                                                                                                                                                                                                                                                    |
| `GITLAB_EMAIL_FROM`                          | string  | L'adresse e-mail utilisée dans le champ **De** dans les e-mails envoyés par GitLab.                                                                                                                                                                                                                                                           |
| `GITLAB_EMAIL_REPLY_TO`                      | string  | L'adresse e-mail utilisée dans le champ **Répondre à** dans les e-mails envoyés par GitLab.                                                                                                                                                                                                                                                       |
| `GITLAB_EMAIL_SUBJECT_PREFIX`                | string  | Le préfixe de l'objet des e-mails envoyés par GitLab.                                                                                                                                                                                                                                                                          |
| `GITLAB_EMAIL_SUBJECT_SUFFIX`                | string  | Le suffixe de l'objet des e-mails envoyés par GitLab.                                                                                                                                                                                                                                                                          |
| `GITLAB_HOST`                                | string  | L'URL complète du serveur GitLab (incluant `http://` ou `https://`).                                                                                                                                                                                                                                                           |
| `GITLAB_MARKUP_TIMEOUT`                      | string  | Délai d'attente, en secondes, pour les commandes `rest2html` et `pod2html` exécutées par le [gem `gitlab-markup`](https://gitlab.com/gitlab-org/gitlab-markup/). La valeur par défaut est `10`.                                                                                                                                                               |
| `GITLAB_ROOT_PASSWORD`                       | string  | Définit le mot de passe de l'utilisateur `root` lors de l'installation.                                                                                                                                                                                                                                                                           |
| `GITLAB_SHARED_RUNNERS_REGISTRATION_TOKEN`   | string  | Définit le jeton d'enregistrement initial utilisé pour les runners. [Déprécié dans GitLab 16.11](https://gitlab.com/gitlab-org/gitlab/-/merge_requests/148310).                                                                                                                                                                                |
| `RAILS_ENV`                                  | string  | L'environnement Rails ; peut être `production`, `development`, `staging` ou `test`.                                                                                                                                                                                                                                          |
| `GITLAB_RAILS_CACHE_DEFAULT_TTL_SECONDS`     | integer | Le TTL par défaut utilisé pour les entrées stockées dans le cache Rails. La valeur par défaut est `28800`. [Introduit](https://gitlab.com/gitlab-org/gitlab/-/merge_requests/95042) dans la version 15.3.                                                                                                                                                               |
| `GITLAB_CI_CONFIG_FETCH_TIMEOUT_SECONDS`     | integer | Délai d'attente pour la résolution des inclusions distantes dans la configuration CI, en secondes. Doit être compris entre `0` et `60`. La valeur par défaut est `30`. [Introduit](https://gitlab.com/gitlab-org/gitlab/-/merge_requests/116383) dans la version 15.11.                                                                                                                               |
| `GITLAB_CI_CONFIG_GITALY_TIMEOUT_SECONDS`    | integer | Délai d'attente par requête en secondes pour les appels Gitaly lors de la récupération des fichiers de configuration CI (inclusions locales, de projet et de composant). La valeur par défaut est `10`.                                                              |
| `GITLAB_CI_CONFIG_HTTP_OPEN_TIMEOUT_SECONDS`  | integer | Délai d'attente d'ouverture (connexion) par requête en secondes pour les appels HTTP lors de la récupération des fichiers de configuration CI distants. Doit être compris entre `1` et `60`. La valeur par défaut est `10`.                                                                                   |
| `GITLAB_CI_CONFIG_HTTP_READ_TIMEOUT_SECONDS`  | integer | Délai d'attente de lecture par requête en secondes pour les appels HTTP lors de la récupération des fichiers de configuration CI distants. Doit être compris entre `1` et `60`. La valeur par défaut est `30`.                                                                                                |
| `GITLAB_CI_MAX_COMMIT_MESSAGE_SIZE_IN_BYTES` | integer | Taille maximale du message de commit en octets pouvant être envoyée au runner CI. Doit être compris entre `0` et `1000000`. La valeur par défaut est `100000`. [Introduit](https://gitlab.com/gitlab-org/gitlab/-/merge_requests/208666) dans la version 18.6.                                                                                                                                                                           |
| `GITLAB_DISABLE_MARKDOWN_TIMEOUT`            | string  | Si cette variable est définie à `true`, `1` ou `yes`, le rendu Markdown sur le backend n'expire pas. La valeur par défaut est `false`. [Introduit](https://gitlab.com/gitlab-org/gitlab/-/merge_requests/163662) dans la version 17.4.                                                                                                                                    |
| `GITLAB_LFS_LINK_BATCH_SIZE`                 | integer | Définit la taille du lot pour la liaison des fichiers LFS. La valeur par défaut est `1000`.                                                                                                                                                                                                                                                                    |
| `GITLAB_LFS_MAX_OID_TO_FETCH`                | integer | Définit le nombre maximum d'objets LFS à lier. La valeur par défaut est `100000`.                                                                                                                                                                                                                                                            |
| `SIDEKIQ_SEMI_RELIABLE_FETCH_TIMEOUT`        | integer | Définit le délai d'attente pour la récupération semi-fiable de Sidekiq. La valeur par défaut est `5`. [Avant GitLab 16.7](https://gitlab.com/gitlab-org/gitlab/-/merge_requests/139583), la valeur par défaut était `3`. Si vous constatez une consommation élevée du CPU Redis sur GitLab 16.6 et versions antérieures, ou si vous avez personnalisé cette variable, vous devez mettre à jour cette variable à `5`. |
| `SSL_IGNORE_UNEXPECTED_EOF`                  | string  | OpenSSL 3.0 exige que les serveurs envoient une alerte `close_notify` avant de fermer une connexion SSL. La valeur par défaut est `false`. Si vous définissez cette variable à `true`, l'alerte est désactivée. Pour plus d'informations, consultez la [documentation OpenSSL](https://docs.openssl.org/3.0/man3/SSL_CTX_set_options/#notes).                                                        |

## Ajouter d'autres variables {#adding-more-variables}

Nous accueillons favorablement les merge requests visant à rendre davantage de paramètres configurables à l'aide de variables. Apportez des modifications au fichier `config/initializers/1_settings.rb` et utilisez le schéma de nommage `GITLAB_#{name in 1_settings.rb in upper case}`.

## Configuration de l'installation du package Linux {#linux-package-installation-configuration}

Pour définir des variables d'environnement, suivez [ces instructions](https://docs.gitlab.com/omnibus/settings/environment-variables/).

Il est possible de préconfigurer l'image Docker GitLab en ajoutant la variable d'environnement `GITLAB_OMNIBUS_CONFIG` à la commande `docker run`. Pour plus d'informations, consultez [Préconfigurer le conteneur Docker](../install/docker/configuration.md#pre-configure-docker-container).
