- Édition : Gratuite, GitLab Premium, GitLab Ultimate
- Offre : GitLab Self-Managed

{{< /details >}}

Si vous exécutez une instance GitLab Self-Managed avec 50 utilisateurs ou plus sur le niveau Free ([Community Edition ou Enterprise Edition sans licence](https://about.gitlab.com/install/ce-or-ee/)), vous pouvez demander une revue d'instance gratuite.

<!-- vale gitlab_base.FutureTense = NO -->

Après avoir soumis la demande, un membre de l'équipe GitLab examinera les détails de votre instance et vous contactera avec des suggestions pour améliorer votre utilisation de GitLab.

<!-- vale gitlab_base.FutureTense = YES -->

Pour demander une revue d'instance :

1. Connectez-vous en tant qu'administrateur.
1. Dans le coin supérieur droit, sélectionnez votre avatar.
1. Sélectionnez **Obtenir une revue d'instance gratuite**.
1. Sur la page de revue d'instance, saisissez vos coordonnées.
1. Sélectionnez **Demande une revue d'instance**.
