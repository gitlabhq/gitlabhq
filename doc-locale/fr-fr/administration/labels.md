Prérequis :

- Accès administrateur.

Pour gérer les labels de l'instance GitLab :

1. Dans le coin supérieur droit, sélectionnez **Admin**.
1. Dans la barre latérale gauche, sélectionnez **Labels**.

Pour plus d'informations, consultez [gérer les labels](../user/project/labels.md).

Les labels créés dans la zone **Admin** sont automatiquement ajoutés aux nouveaux projets. Ils ne sont pas disponibles pour les nouveaux groupes. La mise à jour ou l'ajout de labels dans la zone **Admin** ne modifie pas les labels des projets existants.
