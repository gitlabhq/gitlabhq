Pour essayer GitLab Duo, vous pouvez obtenir un accès pendant une durée limitée avec un essai gratuit.

Pendant la période d'essai, vous aurez accès à l'ensemble des fonctionnalités du module complémentaire que vous avez choisi. À la fin de la période d'essai, pour maintenir votre accès, vous pouvez acheter le module complémentaire.

Les essais des modules complémentaires GitLab Duo durent :

- 30 jours si vous êtes dans l'édition Gratuite sur GitLab.com.
- 60 jours si vous êtes dans l'édition GitLab Premium ou GitLab Ultimate.

L'essai commence lorsque vous recevez l'e-mail de confirmation incluant le code d'activation, et non lorsque vous l'activez.

## Démarrer un essai Ultimate avec GitLab Duo Core {#start-ultimate-trial-with-gitlab-duo-core}

### Sur GitLab Self-Managed {#on-gitlab-self-managed}

Prérequis :

- Une [GitLab Enterprise Edition (EE)](../administration/license.md) active.
- De GitLab 18.0 ou d'une version ultérieure.
- Accès à [GitLab Duo Core](subscription-add-ons.md#gitlab-duo-self-hosted).
- Disposer d'un accès administrateur.

Pour démarrer un essai GitLab Ultimate avec GitLab Duo Core et accéder aux fonctionnalités natives de l'IA, contactez votre interlocuteur commercial.

## Démarrer un essai GitLab Duo Pro {#start-gitlab-duo-pro-trial}

Obtenez un essai de GitLab Duo Pro pour tester les [fonctionnalités de GitLab Duo Pro](../user/gitlab_duo/feature_summary.md) pendant une durée limitée.

Vous pouvez obtenir un essai de GitLab Duo Pro si vous disposez de l'édition GitLab Premium sur GitLab.com, GitLab Self-Managed ou GitLab Dedicated.

{{< tabs >}}

{{< tab title="GitLab.com" >}}

Prérequis :

- Vous devez disposer du rôle Owner pour un groupe principal qui possède un abonnement GitLab Premium payant actif. La propriété indirecte via l'appartenance à un groupe n'est pas suffisante.

Pour démarrer un essai GitLab Duo Pro sur GitLab.com :

1. Dans la barre supérieure, sélectionnez **Rechercher ou accéder à** et repérez votre groupe.
1. Dans la barre latérale gauche, sélectionnez **Paramètres** > **Facturation**.
1. Sélectionnez **Start a free GitLab Duo Pro trial**.
1. Remplissez les champs.
1. Sélectionnez **Continuer**.
1. Si vous y êtes invité, sélectionnez le groupe auquel l'essai doit être appliqué.
1. Sélectionnez **Activer mon essai**.
1. [Attribuez des sièges](subscription-add-ons.md#assign-gitlab-duo-seats) aux utilisateurs qui ont besoin d'un accès.

{{< /tab >}}

{{< tab title="GitLab Self-Managed, GitLab Dedicated" >}}

Prérequis :

- Vous devez disposer d'un abonnement GitLab Premium payant actif.
- Vous devez disposer de GitLab 16.8 ou d'une version ultérieure et votre instance doit être en mesure de [synchroniser les données de votre abonnement](manage_subscription.md#subscription-data-synchronization) avec GitLab.
- GitLab Duo nécessite GitLab 17.2 ou une version ultérieure pour offrir la meilleure expérience utilisateur et les meilleurs résultats. Les versions antérieures peuvent continuer à fonctionner, mais l'expérience peut être dégradée.

Pour démarrer un essai GitLab Duo Pro sur GitLab Self-Managed ou GitLab Dedicated, contactez votre interlocuteur commercial.

Une fois l'essai synchronisé, [attribuez des sièges](subscription-add-ons.md#assign-gitlab-duo-seats) aux utilisateurs auxquels vous souhaitez accorder l'accès à GitLab Duo.

## Démarrer un essai GitLab Duo Enterprise {#start-gitlab-duo-enterprise-trial}

{{< details >}}

- Édition : GitLab Premium, GitLab Ultimate

{{< /details >}}

Obtenez un essai de GitLab Duo Enterprise pour tester les [fonctionnalités de GitLab Duo Enterprise](../user/gitlab_duo/feature_summary.md) pendant une durée limitée.

Si vous êtes dans l'édition Gratuite, vous ne pouvez pas obtenir un essai de GitLab Duo Enterprise. Pour essayer les fonctionnalités de GitLab Duo Agent Platform, vous pouvez démarrer un [essai Ultimate](free_trials.md).

{{< tabs >}}

{{< tab title="GitLab.com" >}}

Prérequis :

- Vous devez disposer du rôle Owner pour un groupe principal qui possède un abonnement GitLab Ultimate payant actif.

Pour démarrer un essai GitLab Duo Enterprise sur GitLab.com :

1. Dans la barre supérieure, sélectionnez **Rechercher ou accéder à** et repérez votre groupe.
1. Dans la barre latérale gauche, sélectionnez **Paramètres** > **Facturation**.
1. Sélectionnez **Start a free GitLab Duo Enterprise trial**.
1. Remplissez les champs.
1. Sélectionnez **Continuer**.
1. Si vous y êtes invité, sélectionnez le groupe auquel l'essai doit être appliqué.
1. Sélectionnez **Activer mon essai**.
1. [Attribuez des sièges](subscription-add-ons.md#assign-gitlab-duo-seats) aux utilisateurs qui ont besoin d'un accès.

{{< /tab >}}

{{< tab title="GitLab Self-Managed, GitLab Dedicated" >}}

Prérequis :

- Vous devez disposer d'un abonnement GitLab Ultimate payant actif.
- Vous devez disposer de GitLab 17.3 ou d'une version ultérieure et votre instance doit être en mesure de [synchroniser les données de votre abonnement](manage_subscription.md#subscription-data-synchronization) avec GitLab.

Pour démarrer un essai GitLab Duo Enterprise sur GitLab Self-Managed ou GitLab Dedicated, contactez votre interlocuteur commercial.

Une fois l'essai synchronisé, [attribuez des sièges](subscription-add-ons.md#assign-gitlab-duo-seats) aux utilisateurs auxquels vous souhaitez accorder l'accès à GitLab Duo.
