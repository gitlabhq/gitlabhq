Mattermost fourni avec le package Linux a été [abandonné dans GitLab 18.9 et supprimé dans GitLab 19.0](../../update/deprecations.md#mattermost-bundled-with-linux-package).

Pour migrer votre Mattermost intégré vers un déploiement autonome, consultez [Migration de Mattermost intégré vers Mattermost Standalone](https://docs.mattermost.com/administration-guide/onboard/migrate-gitlab-omnibus.html) dans la documentation Mattermost.
