Software Development Flowは、他のフローと同じ基盤であるGitLab Duo Agent Platformのフローレジストリ上で動作するようになりました。
IDEでのフローの動作は変わらず、修正や改善は今後このバージョンに対して行われます。

Software Development Flowを引き続き使用するには、エディタ拡張機能を以下のいずれかのバージョン以降に更新してください。

- GitLab for VS Code 6.85.0
- GitLab Duo plugin for JetBrains IDEs 3.40.0
- GitLab for Visual Studio 0.79.0
