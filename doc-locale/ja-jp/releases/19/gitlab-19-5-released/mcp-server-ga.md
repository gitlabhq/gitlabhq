以前のバージョンのGitLabでは、MCPクライアントがアクセスできるGitLabツールのセットは限られていました。今回のリリースで、GitLab MCPサーバーが一般提供（GA）を開始しました。

MCPサーバーを使用することで、Claude CodeやCursorなどのMCP対応エージェントは、拡張されたGitLabツールカタログおよびGitLab Duo Agent Platformのエージェントとフローに直接アクセスできるようになります。エージェントはGitLabワークフローのより広い範囲にわたって動作し、使い慣れたツールを離れることなくAgent Platformのエージェントとフローを実行できます。
