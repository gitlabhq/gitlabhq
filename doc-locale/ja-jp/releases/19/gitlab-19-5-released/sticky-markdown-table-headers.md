以前のバージョンのGitLabでは、長いテーブルをスクロールするとヘッダー行が画面外に消えてしまい、各列の内容を把握しにくい問題がありました。

今回のリリースで、表示モード、プレビュー、リッチテキストエディタのいずれにおいても、スクロール中もテーブルの上部にヘッダーが固定表示されるようになりました。固定ヘッダーは常に有効なため、設定を変更する必要はありません。
