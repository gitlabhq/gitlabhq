VS CodeおよびJetBrains IDEにおけるGitLab Duo Agentic ChatのUIが再設計され、GitLab 19.3でベータ版として導入されましたが、このたび一般提供が開始され、デフォルトのレイアウトとなりました。
ベータ機能や実験的機能を有効にしなくても使用できます。

新しいレイアウトにはタブがありません。会話の開始、チャット履歴の確認、エージェントとモデルの選択をすべて同じ画面で行えます。

新しいレイアウトは以下でデフォルトとなっています。

- GitLab for VS Code 7.2.0以降
- GitLab Duo plugin for JetBrains IDEs 3.50.0以降

ソフトウェア開発フローを使用したり、実行済みのフローを確認したりするには、パネルからクラシックレイアウトに切り替えてください。
