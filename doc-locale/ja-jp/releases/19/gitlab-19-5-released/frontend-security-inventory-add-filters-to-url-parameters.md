セキュリティインベントリのフィルタリングされたビューをリンクで共有できるようになりました。ツールカバレッジ、脆弱性数、またはプロジェクト名でフィルタリングし、URLをコピーして送信するだけです。リンクを開いた相手には、同じビューが表示されます。

以前は、プロジェクト名の検索のみがURLに保存されていたため、共有リンクでは他のフィルターが失われていました。今回のリリースで、フィルターの状態がすべて保持されるようになったため、ビューをブックマークしたり、該当プロジェクトを担当するチームに共有したりできます。
