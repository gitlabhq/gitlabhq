GitLab Duo Agent Platformは、デベロッパーフローに対して独立したモデル選択をサポートするようになりました。
管理者は、他のGitLab Duo Agent Platform機能とは別に、デベロッパーフロー専用のAIモデルを選択できます。これにより、チームはモデル選択をより細かく制御できるようになります。
