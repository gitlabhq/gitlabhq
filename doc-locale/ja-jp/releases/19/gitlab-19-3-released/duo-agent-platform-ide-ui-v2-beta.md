GitLab for VS Code拡張機能のGitLab Duo Agentic ChatインターフェースのUIが再設計され、ベータ版として利用可能になりました。新しいインターフェースは既存のAgentic Chatパネルを再構築したもので、AIモデル、エージェント、スラッシュコマンド、ツール承認といった基盤となる機能はそのまま引き継がれています。

再設計されたUIは、GitLab 19.3およびGitLab for VS Code拡張機能6.87.0以降で利用できます。

新しいUIを使用するには、トップレベルグループまたはインスタンスで[ベータ版および実験的機能を有効にし](../../../user/gitlab_duo/turn_on_off.md#turn-on-beta-and-experimental-features)、拡張機能をリロードしてください。

新UIとクラシックUIはパネルからいつでも切り替えられます。ベータ版はVS Codeのみで利用可能です。
