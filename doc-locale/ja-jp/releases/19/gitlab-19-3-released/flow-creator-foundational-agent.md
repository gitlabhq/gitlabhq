AIカタログに搭載された専用の基本エージェントであるフロークリエーターを使用して、自然言語の会話を通じてGitLab Duo Agent Platform向けのカスタムフローを作成できるようになりました。
フロークリエーターでは、フローに実行させたい内容を説明するだけで、エージェントがすぐに登録・使用できる完全な実行可能フローYAMLを生成します。
また、既存フローのデバッグやフレームワークの概念説明もサポートしています。
