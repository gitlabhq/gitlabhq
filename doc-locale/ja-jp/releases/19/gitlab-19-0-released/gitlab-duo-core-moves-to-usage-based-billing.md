GitLab 19.0より、GitLab Duo Coreは従量制課金に移行します。Web IDEおよびデスクトップIDEでのコード提案は、[GitLabクレジット](../../../subscriptions/gitlab_credits.md)を消費するようになりました。

GitLab Duo Chatも変更されます。GitLab Duo Coreユーザーの場合、ChatはエージェントベースになりGitLab Duo Agent Platform上で動作します。GitLab UIまたはデスクトップIDEでGitLab Duo Chatを使用するには、インスタンスまたはトップレベルグループでGitLab Duo Agent Platformを有効にしてください。
