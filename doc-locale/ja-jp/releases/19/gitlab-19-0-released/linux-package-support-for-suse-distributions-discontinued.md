GitLab 19.0では、SUSEディストリビューション向けLinuxパッケージのサポートが終了します。対象となるのは、openSUSE Leap 15.6、SUSE Linux Enterprise Server 12.5、およびSUSE Linux Enterprise Server 15.6です。GitLab 18.11が、これらのディストリビューション向けLinuxパッケージを提供する最後のバージョンとなります。SUSEディストリビューションを引き続き使用するには、[GitLabのDockerデプロイ](../../../install/docker/installation.md)に移行してください。
