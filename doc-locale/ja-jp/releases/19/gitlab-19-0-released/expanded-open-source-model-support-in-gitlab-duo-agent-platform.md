GitLab Duo Agent Platformは、セルフホスト型デプロイ向けに追加のオープンソースモデルをサポートするようになりました。対応モデルにはDevstral 2 123B、GLM-5.1-FP8などが含まれます。これにより、オフライン環境やネットワーク制限のある環境を含む、さまざまな環境でエージェント型ワークフローを活用できます。
