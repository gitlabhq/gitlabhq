これまで、作業アイテムタイプは**イシュー**または**タスク**のいずれかでした。プロジェクト内でカスタムの作業アイテムタイプを設定し、チームの計画・追跡方法に合わせて活用できるようになりました。

タイプを作成または名前変更して、**ユーザーストーリー**、**バグ**、**メンテナンス**として使用できます。各作業アイテムにはタイプ名と固有のアイコンが表示されます。新しいタイプはカスタムフィールドとステータスのライフサイクルをサポートしており、保存済みビューやイシューボードにも表示されます。トップレベルグループ（GitLab.com）または組織（GitLab Self-Managed）でのタイプ設定は、すべてのプロジェクトに継承されます。

また、各プロジェクトで使用可能なタイプを制御することもできます。すべてのプロジェクトで一括してタイプを有効または無効にするか、個々のプロジェクトが独自にタイプの表示設定を管理できるようにすることが可能です。プロジェクトでタイプを無効にしても、既存の作業アイテムには影響しません。
