PostgreSQL の最小サポートバージョンがバージョン 17 になりました。パッケージ版の PostgreSQL 16 を使用している場合は、GitLab 19.0 をインストールする前に、[パッケージ版 PostgreSQL サーバーをアップグレード](https://docs.gitlab.com/omnibus/settings/database.html#upgrade-packaged-postgresql-server)してください。
