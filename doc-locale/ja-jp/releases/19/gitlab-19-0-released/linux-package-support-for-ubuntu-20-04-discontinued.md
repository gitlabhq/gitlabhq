Ubuntu 20.04は2025年5月に標準サポートが終了しました。GitLab 19.0以降、Ubuntu 20.04向けのLinuxパッケージは提供されません。GitLab 18.11がこのディストリビューション向けパッケージを含む最後のリリースです。GitLab 19.0へのアップグレード前に、Ubuntu 22.04または他の[サポート対象オペレーティングシステム](../../../install/package/_index.md#supported-platforms)へ移行してください。
