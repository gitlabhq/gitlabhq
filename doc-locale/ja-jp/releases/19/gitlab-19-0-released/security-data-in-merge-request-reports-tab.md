マージリクエストに新しくレポートタブが追加されました。パイプラインのセキュリティスキャン結果、ライセンスコンプライアンス結果、コード品質レポートのすべての検出内容を確認できます。

マージリクエストのマージを妨げるポリシー違反については、アクティビティフィードのGitLab botコメントで引き続き確認できます。
