バンドルされたMattermostは、GitLab 19.0のLinuxパッケージから削除されました。現在バンドルされたMattermostを使用している場合は、移行手順について[LinuxパッケージからMattermost Standaloneへの移行](https://docs.mattermost.com/administration-guide/onboard/migrate-gitlab-omnibus.html)を参照してください。バンドルされたMattermostを使用していないお客様への影響はありません。
