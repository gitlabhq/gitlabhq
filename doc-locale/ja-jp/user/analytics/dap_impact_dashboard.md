GitLab Duo Agent Platformインパクトダッシュボードには、組織がAgent Platformをどのように使用しているか、またその使用にどれだけのコストがかかっているかが表示されます。このダッシュボードには、グループおよびプロジェクトから集計されたデータが、ユーザーの採用状況とエンゲージメント、作業アクティビティ、クレジット消費量のメトリクスとして表示されます。

このダッシュボードは、次の目的で使用します:

- 組織全体でのAgent Platformワークフローの量を測定する。
- モデル、フロータイプ、グループまたはプロジェクト別にクレジット消費量を追跡する。
- 保持率、解約率、アクティビティ階層など、ユーザーの採用トレンドを監視する。
- Agent Platformを最も積極的に使用しているプロジェクトとグループを特定する。

## 概要 {#overview}

**概要**タブには、選択したスコープと期間におけるAgent Platformの使用状況の概要が表示されます。

- **アクティブプロジェクト**: Agent Platformセッションが1つ以上あるプロジェクトの数。
- **アクティブユーザー**: Agent Platformセッションが1つ以上あるユーザーの数。
- **完了したセッション**: 作成され、完了したAgent Platformセッションの数。
- **消費されたクレジット**: Agent Platformセッションで消費されたクレジットの数。
- **クレジットの使用先**: 各Agent Platformフロータイプで消費されたクレジットの数。

## 採用状況 {#adoption}

**採用状況**タブには、選択したスコープと期間において、ユーザーがAgent Platform機能をどのように採用しているかに関するメトリクスが表示されます。

**ユーザー**セクションには、次のメトリクスが表示されます:

- **すべてのユーザー**: Agent Platformセッションが1つ以上あるユーザーの数。
- **新規対リピーター**: Agent Platformセッションが1つ以上ある新規ユーザーとリピーターユーザーの数と割合。リピーターユーザーとは、同じ長さの前の期間にAgent Platformセッションがあったユーザーです。
- **アクティビティ別ユーザー**: Agent Platformフロータイプ別のユーザー数。複数のフロータイプを使用するユーザーは、それぞれのカテゴリでカウントされます。

**エンゲージメント**セクションには、次のメトリクスが表示されます:

- **複数アクティビティユーザー**: 複数のAgent Platformフロータイプでセッションを持つユーザーの数。
- **離脱**: 前の期間に1日のみアクティブで、選択した期間に戻ってこなかったユーザーの数。
- **階層別セッションと上位機能**: 最もよく使用されている上位5つのAgent Platform機能について、ユーザー階層別のセッション数。

**採用階層**セクションには、次のメトリクスが表示されます:

- **階層別ユーザー**: Agent Platformセッションが1つ以上あるユーザーの数。
- **合計セッション数**: フロータイプおよびエージェント別のAgent Platformセッションの数。
- **ユーザー比率対セッション比率**: ユーザー階層別のユーザー数とセッション数。
- **階層別のセッション強度**: ユーザー階層別のユーザー数とセッション数。
- **グループとプロジェクトの比較**: グループおよびプロジェクト別のユーザー数と使用されたクレジット数。

## 作業 {#work}

**作業**タブには、選択したスコープと期間において、Agent Platform機能がどのように使用されているかに関するメトリクスが表示されます。

**アクティビティ概要**セクションには、次のメトリクスが表示されます:

- **セッション**: Agent Platformセッションの総数。
- **アクティビティ別セッション**: アクティビティ別のAgent Platformセッションの数。
- **経時的なセッション**: 作成されたAgent Platformセッションの数（フロータイプ別に積み上げ表示）。

**MRサイクルタイム**セクションには、次のメトリクスが表示されます:

- **サイクルタイム: Duo作成**: GitLab Duoによって作成されたマージリクエストについて、オープンからマージまでの日数の中央値と75パーセンタイル値。マージされたマージリクエストの数が含まれます。
- **サイクルタイム: その他すべて**: GitLab Duoによって作成されていないマージリクエストについて、オープンからマージまでの日数の中央値と75パーセンタイル値。マージされたマージリクエストの数が含まれます。

**マージリクエスト量**セクションには、次のメトリクスが表示されます:

- **Duoによって開かれた**: GitLab Duoによって作成されたマージリクエストの数。
- **マージ済み: Duo作成**: GitLab Duoによって作成され、マージされたマージリクエストの数。
- **マージ済み: その他すべて**: GitLab Duoによって作成されていない、マージされたマージリクエストの数。
- **ステータス別のDuo作成マージリクエスト**: 選択した期間において、GitLab Duoによって作成され、現在のステータスを持つマージリクエストの数。

**機能の成果**セクションには、次のメトリクスが表示されます:

- **Agentic Code Reviewセッション**: Code Reviewフローのセッション数。
- **リクエストされたレビュー**: Code Reviewにリクエストされたレビューの数。
- **公開されたレビュー**: Code Reviewによって公開されたレビューの数。
- **コメントあり**: Code Reviewによって公開された、コメントが1つ以上あるレビューの数。
- **コメントなし**: Code Reviewによって公開された、コメントのないレビューの数。
- **経時的なAgentic Code Reviewの成果**: 選択した期間において、Code Reviewにリクエストされ、コメントの有無を問わず公開されたレビューの数。
- **Agentic Developerセッション**: Developerフローのセッション数。
- **完了**: Developerフローの完了したセッションの数。
- **一時停止**: Developerフローの一時停止されたセッションの数。
- **キャンセル済み**: Developerフローのキャンセルされたセッションの数。
- **失敗**: Developerフローの失敗したセッションの数。
- **経時的なAgentic Developerセッション**: 選択した期間において、Developerフローの完了、一時停止、キャンセル、失敗したセッションの数。
- **Agentic Fix Pipelineセッション**: Fix Pipelineフローのセッション数。
- **投稿された提案**: GitLab Duoによって失敗したパイプラインに投稿された修正提案の数。
- **適用された提案**: GitLab Duoによって失敗したパイプラインに投稿され、適用された修正提案の数。
- **経時的なAgentic Fix Pipelineの提案**: 選択した期間において、GitLab Duoによって失敗したパイプラインに投稿され、適用された修正提案の数。
- **Agentic SASTセッション**: Agentic SASTフローのセッション数。
- **脆弱性検出後に作成されたMR**: Resolve SAST Vulnerabilityセッションによって作成されたマージリクエストの数。
- **経時的なAgentic SASTセッション**: 作成されたSASTフローセッションの数と、そのセッション内で作成されたマージリクエストの数。

## 支出 {#spend}

**支出**タブには、選択したスコープと期間において、Agent Platform機能がどれだけ使用されているかに関するメトリクスが表示されます。

- **モデル別、機能別のクレジット**: 異なるモデルで使用されたクレジットの数（Agent Platform機能別に積み上げ表示）。
- **クレジット**: 消費されたクレジットの総数。
- **チャット**: チャットセッションで消費されたクレジットの数。
- **経時的なクレジット**: 時間の経過に伴って使用されたクレジットの数（機能別に積み上げ表示）。

## ダッシュボードを表示する {#view-the-dashboard}

前提条件: 

- クレジット使用データを表示するには、グループのオーナーロールが必要です。

1. 上部のバーで、**検索または移動先** > **検索**を選択します。
1. 左側のサイドバーで、**分析ダッシュボード**を選択します。
1. **DAP Impact**を選択します。
1. タブを選択して、さまざまなメトリクスを表示します。
1. オプション。デフォルトでは、ダッシュボードには過去30日間のトップレベルグループのメトリクスが表示されます。結果をフィルタリングできます:

   - 特定のグループまたはプロジェクトのメトリクスを表示するには、該当するタブの**スコープ**ドロップダウンリストから、表示したいグループまたはプロジェクトを選択します。
   - 別の期間のメトリクスを表示するには、該当するタブの**Period**ドロップダウンリストから、表示したい期間を選択します。
   - 選択したスコープと期間をリセットするには、**リセット**を選択します。

1. 表示されたメトリクスをGitLab Duoで分析するには、**Analyze with Duo**を選択します。
