GitLabは、ネームスペースがGitLab.comで消費するリソースを追跡するため、制限に達する前に使用状況とストレージを監視および管理できます。

使用状況とは、ネームスペースとそのプロジェクトが消費するストレージなどのリソースを指します。

ストレージとは、プロジェクトが使用するディスク領域を指します。各プロジェクトには、サブスクリプションのプランによって異なるストレージ制限があります。

使用状況を監視すると、次のことができます:

- プロジェクトの予期せぬ制限を回避します。
- 制限に達する前にストレージ購入を計画します。
- チームが中断することなくコードプッシュすることを確実にします。
