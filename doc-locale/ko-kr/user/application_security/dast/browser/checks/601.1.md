## 설명 {#description}

이 사이트는 사용자가 제공한 입력을 통한 오픈 리다이렉트를 허용하도록 발견되었습니다. 오픈 리다이렉트는 원본 도메인 또는 URL이 합법적인 링크처럼 보이지만 사용자를 악의적인 사이트로 리다이렉트하는 피싱 공격에서 흔히 악용됩니다. 예를 들어 `https://example.com/redirect?url=https://%62%61%64%2e%63%6f%6d%2f%66%61%6b%65%6c%6f%67%69%6e`은 디코딩하면 `bad.com/fakelogin`이 됩니다.

## 수정 {#remediation}

`GET` 요청에서 발견된 사용자 입력을 기반으로 클라이언트를 리다이렉트하면 안 됩니다. 사용자를 리다이렉트할 대상 링크 목록이 서버 측에 포함되어 있고, 리다이렉트할 링크를 반환하기 위해 인덱스로 숫자 값을 사용하여 검색되는 것이 좋습니다. 예를 들어 `/redirect?id=1`는 애플리케이션이 `1` 인덱스를 조회하고 `https://example.com`와 같은 URL을 반환하도록 합니다. 이 URL은 301 응답 코드와 `Location` 헤더를 사용하여 사용자를 리다이렉트하는 데 사용됩니다.
