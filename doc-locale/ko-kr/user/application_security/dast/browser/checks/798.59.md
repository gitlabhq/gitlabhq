## 설명 {#description}

응답 본문에는 Heroku API 키 또는 애플리케이션 인증 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. API 키 및 인증 토큰을 사용하여 사용자 또는 계정을 대신하여 API 호출을 수행할 수 있습니다. 이러한 토큰에 액세스할 수 있는 악의적 행위자는 Heroku API 플랫폼과 배포된 모든 애플리케이션에 액세스할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

식별된 사용자의 API 키를 재생성하려면:

- 계정에 로그인하고 <https://dashboard.heroku.com/account>을 방문하세요.
- "API Key" 섹션에서 "Regenerate API Key"를 선택하세요.
- 메시지가 표시되면 "Regenerate API Key" 대화 상자에서 "Regenerate API Key"를 선택하세요.

애플리케이션 인증 토큰을 재생성하려면:

- 계정에 로그인하고 <https://dashboard.heroku.com/account/applications>을 방문하세요.
- "Authorizations" 섹션에서 식별된 토큰을 포함하는 등록된 인증을 찾으세요.
- 연필 아이콘을 선택하세요.
- "Regenerate token"을 선택하세요.

API 키에 대한 자세한 내용은 [API 키 생성에 대한 FAQ](https://help.heroku.com/PBGP6IDE/how-should-i-generate-an-api-key-that-allows-me-to-use-the-heroku-platform-api)를 참조하세요. Heroku는 애플리케이션 인증 토큰에 대한 설명서를 제공하지 않습니다.
