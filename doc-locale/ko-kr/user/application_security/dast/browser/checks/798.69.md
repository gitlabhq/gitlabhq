## 설명 {#description}

응답 본문에는 LinkedIn 클라이언트 보안 암호의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 클라이언트 시크릿은 사용자가 애플리케이션에 로그인할 수 있도록 할 때 사용됩니다. 요청된 범위에 따라 악의적인 행위자가 서비스를 악용하여 사용자의 정보에 접근할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

클라이언트 보안 암호를 재생성하려면:

- LinkedIn 계정에 로그인하고 <https://www.linkedin.com/developers/apps/>을 방문하세요.
- 식별된 보안 암호가 포함된 애플리케이션을 찾고 해당 이름을 선택하세요.
- "Auth" 탭을 선택하세요.
- "Application credentials" 섹션에서 "새 클라이언트 보안 암호 생성"을 선택하세요.
- "새 클라이언트 보안 암호 생성"이 없으면 두 개의 활성 보안 암호가 있을 가능성이 높으므로 하나를 삭제하면 나타납니다.
- 식별된 보안 암호 옆의 "X"를 선택하여 제거하세요.
- 메시지가 표시되면 "Remove the Primary Client Secret" 대화 상자에서 "Confirm"을 선택하세요.

자세한 내용은 [LinkedIn API 액세스 설명서](https://learn.microsoft.com/en-us/linkedin/learning/getting-started/request-access)를 참조하세요.
