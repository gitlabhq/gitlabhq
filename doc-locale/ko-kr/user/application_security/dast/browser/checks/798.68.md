## 설명 {#description}

응답 본문에는 LinkedIn 클라이언트 ID의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 클라이언트 ID는 클라이언트 보안 암호와 함께 사용됩니다. 악의적인 행위자가 이 ID에 액세스할 수 있으면 클라이언트 보안 암호에도 액세스할 수 있는 경우 클라이언트 애플리케이션을 사칭할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요. 클라이언트 ID는 취소하거나 재생성할 필요가 없습니다. 자세한 내용은 [LinkedIn API 액세스 설명서](https://learn.microsoft.com/en-us/linkedin/learning/getting-started/request-access)를 참조하세요.
