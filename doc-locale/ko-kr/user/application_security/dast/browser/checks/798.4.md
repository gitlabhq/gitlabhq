## 설명 {#description}

응답 본문에는 age 암호화 시크릿 키의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. Age는 현대적이고 안전한 파일 암호화 도구, 형식 및 Go 라이브러리입니다. 작은 명시적 키, 구성 옵션 없음, UNIX 스타일의 조합성을 제공합니다. 이러한 키는 일반적으로 민감한 파일을 암호화하는 데 사용됩니다. 이 키에 액세스할 수 있는 악의적인 사용자는 이로 암호화된 모든 파일 또는 메시지를 복호화할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키 처리에 대한 일반적인 지침은 [인터넷에 대한 자격증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)에 대한 GitLab 설명서를 참조하세요. 새 age 키를 생성하려면 다음 명령을 실행하세요: ```console age-keygen -o new_key.age``` 암호를 사용하여 ID 파일을 보호하는 것을 고려하세요. 이 키가 자동화된 시스템에서 사용되도록 의도된 경우 이것이 가능하지 않을 수 있습니다: ```console age-keygen | age -p > new_key.age```
