## 설명 {#description}

응답 본문에는 Ionic 개인 액세스 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 개인 액세스 토큰은 Ionic CLI, Appflow CLI 또는 타사 애플리케이션을 인증하는 데 사용할 수 있습니다. 이 토큰에 대한 액세스 권한을 가진 악의적인 행위자는 연결된 리포지토리 및 파이프라인에 대한 전체 액세스 권한을 얻을 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키에 관한 보안 사고 처리에 대한 일반적인 지침은 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)에 대한 GitLab 문서를 참조하세요.

API 토큰을 취소하려면:

- Ionic 계정에 로그인하고 <https://dashboard.ionicframework.com/settings/personal-access-tokens>을 방문하세요.
- 확인된 API 토큰을 찾습니다.
- "삭제"를 선택합니다.
- 메시지가 표시되면 "확실합니까?" 대화 상자에서 "확실합니다. 이 개인 액세스 토큰 삭제"를 선택합니다.

자세한 내용은 [Ionic의 액세스 토큰 설명서](https://ionic.io/docs/appflow/personal-access-tokens)를 참조하세요.
