## 설명 {#description}

응답 본문에는 실시간 Shippo API 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. API 토큰을 사용하여 배송 서비스에 사용되는 Shippo API에 액세스할 수 있습니다. 악의적인 행위자가 이 토큰에 액세스하면 청구 및 주문 정보에 액세스하고 배송 데이터를 수정할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

API 토큰을 취소하려면:

- Shippo 계정에 로그인하고 <https://apps.goshippo.com/>에 액세스하세요.
- 오른쪽 위에서 "기어" 아이콘을 선택하여 "설정" 페이지로 이동하세요.
- 왼쪽 메뉴에서 "고급"까지 스크롤하고 "API"를 선택하세요.
- "토큰" 섹션에서 "토큰 관리"를 선택하세요.
- 식별된 토큰을 찾고 휴지통 아이콘을 선택하세요.
- 프롬프트가 표시되면 "토큰 관리" 대화 상자에서 "예, 토큰 제거"를 선택하세요.

자세한 내용은 [Shippo의 API 키 설명서](https://portal.goshippo.com/api-config/api)를 참조하세요.
