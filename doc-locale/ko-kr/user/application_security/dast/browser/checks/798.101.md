## 설명 {#description}

응답 본문에 SendGrid API 토큰 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키 처리에 관한 보안 사건 대응에 대한 일반 지침을 보려면 GitLab 문서의 [인증 정보 인터넷 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.
