## 설명 {#description}

응답 본문에는 HashiCorp Vault 배치 토큰의 패턴과 일치하는 내용이 포함되어 있습니다. 배치 토큰은 수백 개에서 수천 개의 시스템이 Vault에 액세스해야 하지만 고유 토큰을 생성하면 확장되지 않을 때 사용됩니다. 이 토큰은 일반적으로 수명이 짧으며 특정 Vault 정책에 바인딩됩니다. 이 토큰에 액세스할 수 있는 악의적인 행위자는 서비스를 사칭할 수 있으며 배치 토큰이 생성된 정책과 동일한 권한 수준을 갖게 됩니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키와 관련된 보안 사건 처리에 대한 일반적인 지침은 [인터넷에 대한 자격증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)에 대한 GitLab 문서를 참조하세요. 배치 토큰은 취소할 수 없으므로 배치 토큰을 생성할 때 매우 짧은 "유지 시간" 값을 사용해야 합니다. 자세한 내용은 [배치 토큰에 대한 Vault의 문서](https://developer.hashicorp.com/vault/tutorials/tokens/batch-tokens)를 참조하세요.
