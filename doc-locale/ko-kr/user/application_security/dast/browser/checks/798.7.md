## 설명 {#description}

응답 본문에 Alibaba AccessKey ID의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 이 값이 노출되면 공격자가 이 토큰으로 허용된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키 처리에 관한 일반적인 지침을 보려면 [인터넷에 노출된 자격 증명](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)에 대한 GitLab 설명서를 확인하세요.
