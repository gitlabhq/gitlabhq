## 설명 {#description}

응답 본문에 Postman API 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있었습니다. API 키는 계정에 권한이 있는 모든 Postman 데이터에 액세스할 수 있습니다. 이 토큰에 접근할 수 있는 악의적 행위자는 API 키를 생성한 사용자가 접근할 수 있는 Postman 서비스에 저장된 모든 데이터에 액세스할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

API 토큰을 재생성하려면:

- <https://www.postman.com/>에서 Postman 계정에 로그인하세요.
- 오른쪽 상단의 프로필 사진을 선택한 후 "설정"을 선택하세요.
- 왼쪽 메뉴에서 "API 키"를 선택하세요.
- 식별된 키를 찾은 후 "API 키" 섹션의 상태 열 옆에 있는 줄임표를 선택하세요.
- "재생성"을 선택하세요.
- 메시지가 나타나면 "API 키 재생성" 대화 상자에서 "API 키 재생성"을 선택하세요.

자세한 내용은 [Postman의 API 키 문서](https://learning.postman.com/docs/developer/postman-api/authentication/)를 참조하세요.
