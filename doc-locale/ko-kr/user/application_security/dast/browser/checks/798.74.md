## 설명 {#description}

응답 본문에 Mailgun 개인 API 토큰 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 이 키를 사용하면 다양한 API 엔드포인트를 통해 읽기, 쓰기 및 삭제 작업을 수행할 수 있으며 사용자의 모든 발신 도메인에 대해 수행할 수 있습니다. 악의적인 행위자가 이 키에 액세스하면 제한 없이 Mailgun에 대한 모든 API 요청을 수행할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

개인 API 토큰을 회전시키려면:

- Mailgun 계정에 로그인하고 <https://app.mailgun.com/>에서 대시보드에 액세스합니다.
- 오른쪽 상단에서 계정 프로필을 선택한 다음 "API Security"를 선택합니다
- 식별된 키를 찾아 휴지통 아이콘을 선택합니다
- 휴지통 아이콘을 선택할 수 없는 경우 먼저 "Add new key"를 선택하여 새 키를 생성해야 합니다
- 메시지가 표시되면 "Delete API Key" 대화 상자에서 "Delete"를 선택합니다

자세한 내용은 [Mailgun의 API 키 문서](https://documentation.mailgun.com/docs/mailgun/user-manual/get-started/#primary-account-api-key)를 참조하세요.
