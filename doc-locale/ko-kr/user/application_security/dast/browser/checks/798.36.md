## 설명 {#description}

응답 본문에 EasyPost 프로덕션 API 키의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 프로덕션 API 키는 라이브 애플리케이션 작업에 사용되며 전체 계정 액세스를 허용합니다. 이 토큰에 액세스할 수 있는 악의적인 행위자는 대상 환경에 대한 모든 API 호출을 실행할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

식별된 API 토큰을 취소하려면:

- 계정에 로그인하고 설정 페이지로 이동합니다 <https://www.easypost.com/account/settings>
- "프로덕션 API 키" 아래에서 "상태" 확인란을 선택하여 키를 비활성화합니다
- "이 키를 비활성화하시겠습니까?" 대화상자에서 "비활성화"를 선택합니다
- "상태" 확인란 영역에서 휴지통 아이콘을 선택하여 키를 삭제합니다

API 키 관리 취소 및 처리에 대한 정보는 [해당 설명서를 참조](https://docs.easypost.com/docs/authentication#api-key-management)하세요.
