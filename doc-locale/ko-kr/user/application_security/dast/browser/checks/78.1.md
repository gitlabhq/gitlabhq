## 설명 {#description}

대상 애플리케이션 서버에서 임의의 OS 명령을 실행할 수 있습니다. OS 명령 주입은 전체 시스템 손상으로 이어질 수 있는 중대한 취약성입니다.

## 수정 {#remediation}

사용자 입력은 OS 명령을 실행하는 함수의 명령이나 명령 인수를 구성할 때 절대 사용되면 안 됩니다. 여기에는 사용자 업로드 또는 다운로드로 제공된 파일명이 포함됩니다.

애플리케이션이 다음을 수행하지 않는지 확인하세요:

- 프로세스 이름을 실행할 때 사용자 제공 정보를 사용하지 않습니다.
- 셸 메타 문자를 이스케이프하지 않는 OS 명령 실행 함수에서 사용자 제공 정보를 사용하지 않습니다.
- OS 명령의 인수에 사용자 제공 정보를 사용하지 않습니다.

애플리케이션은 OS 명령으로 전달될 인수의 하드코딩된 집합을 가져야 합니다. 파일명이 이러한 함수로 전달되는 경우, 대신 파일명의 해시 또는 다른 고유 식별자를 사용하는 것이 권장됩니다. 제3자 명령에 대한 알 수 없는 공격의 위험으로 인해 OS 시스템 명령을 사용하는 대신 동일한 기능을 구현하는 기본 라이브러리를 사용하는 것이 강력히 권장됩니다.
