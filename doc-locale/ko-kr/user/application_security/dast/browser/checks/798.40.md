## 설명 {#description}

응답 본문에 Fastly API 사용자 또는 자동화 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. Fastly API 토큰은 구성 방식에 따라 읽기/쓰기 또는 읽기 전용 액세스 권한을 부여할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

API 토큰을 취소하려면:

- <https://manage.fastly.com/account>에서 Fastly 웹 인터페이스에 로그인합니다.
- 왼쪽 메뉴에서 "계정"을 클릭한 다음 "API 토큰"을 클릭합니다.
- 삭제할 토큰을 찾고 범위에 대한 세부 정보를 기록합니다.
- 준비가 되면 휴지통 아이콘을 선택합니다.
- 메시지가 표시되면 "삭제"를 선택합니다.

자세한 내용은 [Fastly의 API 토큰 사용 설명서](https://docs.fastly.com/en/guides/using-api-tokens)를 참조하세요.
