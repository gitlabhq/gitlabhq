## 설명 {#description}

애플리케이션의 XML 파서가 외부 리소스를 포함하도록 만들 수 있습니다. 이는 파일을 포함할 수 있으며 경우에 따라 타사 서버에 요청을 시작할 수 있습니다.

## 수정 {#remediation}

대상 애플리케이션에서 사용하는 XML 파서의 설명서를 참고하여 보안 지침 및 강화 단계를 확인합니다. 모든 XML 파서가 외부 엔티티 분석 및 XML `xinclude` 기능을 비활성화하는 것이 좋습니다. `libxml` 기반의 대부분의 XML 파서는 네트워크 액세스를 비활성화하도록 구성할 수 있습니다.
