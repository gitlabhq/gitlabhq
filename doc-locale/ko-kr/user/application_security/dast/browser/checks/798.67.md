## 설명 {#description}

응답 본문에서 OAuth 2.0 Linear 클라이언트 시크릿 또는 ID의 패턴과 일치하는 콘텐츠가 식별되었습니다. 클라이언트 시크릿은 사용자가 애플리케이션에 로그인할 수 있도록 할 때 사용됩니다. 요청된 범위에 따라 악의적인 행위자가 서비스를 가장하여 사용자의 정보에 액세스할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

Linear OAuth 2.0 클라이언트 시크릿을 취소하려면:

- <https://linear.app/>에서 계정에 로그인합니다.
- 왼쪽 위 모서리에서 조직을 선택하고 "Preferences"를 선택합니다.
- 왼쪽 메뉴에서 "My Account" 아래의 "API"를 선택합니다.
- 페이지의 "OAuth Applications" 섹션에서 식별된 키를 포함하는 애플리케이션을 찾습니다
- 애플리케이션 이름 오른쪽의 줄임표를 선택한 후 "Manage application"을 선택합니다 - "Admin Actions" 옆에서 "Rotate secret"을 선택합니다
- 메시지가 표시되면 "Rotate your client secret?" 대화 상자에서 "Rotate"를 선택합니다

자세한 내용은 [Linear의 OAuth 2.0 인증 설명서](https://developers.linear.app/docs/oauth/authentication)를 참조하세요.
