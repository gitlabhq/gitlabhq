## 설명 {#description}

응답 본문에 RubyGems API 토큰 패턴과 일치하는 콘텐츠가 있는 것으로 확인되었습니다. RubyGems 토큰은 API에 액세스하거나 패키지를 게시하는 데 사용됩니다. RubyGems 토큰은 특정 권한이나 범위로 생성할 수 있습니다. 권한 및 범위에 따라 이 토큰에 액세스할 수 있는 악의적인 행위자는 패키지를 추가 또는 제거하거나, 소유자를 추가 또는 제거하거나, 대시보드를 볼 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

API 토큰을 취소하려면:

- RubyGems 계정에 로그인하고 <https://rubygems.org/settings/edit>에 액세스합니다.
- 아래로 스크롤하여 "API Keys"를 선택하거나 <https://rubygems.org/profile/api_keys>로 이동합니다.
- 식별된 토큰을 찾고 "Delete"를 선택합니다.
- 메시지가 표시되면 대화상자에서 "OK"를 선택합니다.

자세한 내용은 [RubyGems API 토큰 설명서](https://guides.rubygems.org/api-key-scopes/)를 참조하세요.
