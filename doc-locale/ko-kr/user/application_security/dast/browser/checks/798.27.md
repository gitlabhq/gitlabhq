## 설명 {#description}

응답 본문에는 Discord 클라이언트 ID의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 클라이언트 ID는 OAuth 애플리케이션에서 사용되며 클라이언트 비밀과 함께 사용됩니다. 이 값 자체는 어떤 액세스 권한도 부여하지 않으며 클라이언트 비밀 값과 함께 사용되어야 합니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요. Discord 클라이언트 ID는 취소할 수 없습니다. 대신 완전히 새로운 Discord 애플리케이션을 생성해야 합니다.

자세한 내용은 [Discord의 OAuth 문서](https://discord.com/developers/docs/topics/oauth2)를 참조하세요.
