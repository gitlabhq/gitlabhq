## 설명 {#description}

누락되었거나 유효하지 않은 `Content-Security-Policy` (CSP)이 대상 사이트에서 식별되었습니다. CSP는 XSS(Cross-Site Scripting)와 같은 다양한 클라이언트 측 공격으로부터 웹사이트를 강화하는 데 도움이 될 수 있습니다.

## 수정 {#remediation}

대상 사이트에 CSP가 누락되어 있으면 CSP를 활성화하기 위한 관련 URL을 조사하세요. 그렇지 않으면 권장사항을 따라 필요한 조치가 있는지 확인하세요.
