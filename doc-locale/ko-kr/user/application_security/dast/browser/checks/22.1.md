## 설명 {#description}

취약성은 URL 엔드포인트의 파라미터에 페이로드를 삽입하여 임의의 파일을 읽을 수 있도록 악용될 수 있습니다. 이를 통해 민감한 파일을 읽거나, 다른 사용자의 데이터에 액세스하거나, 시스템 접근을 얻기 위한 추가 악용에 도움이 될 수 있습니다.

## 수정 {#remediation}

사용자 입력은 파일 시스템과 상호 작용하기 위해 경로나 파일을 구성할 때 절대 사용되어서는 안 됩니다. 여기에는 사용자 업로드 또는 다운로드로 제공된 파일명이 포함됩니다.

가능하면 파일명을 해싱하고 사용자나 다른 시스템 구성 요소에서 제공한 파일명에 직접 액세스를 시도하는 대신 데이터베이스 또는 데이터스토어에서 해싱된 파일명을 참조하는 것을 고려하세요.

응용 프로그램이 파일명으로 작업해야 하는 드문 경우에는 언어에서 제공하는 기능을 사용하여 제공된 값에서 파일명 부분만 추출하세요. 사용자 입력에서 오는 경로 또는 디렉터리 정보를 사용하려고 시도하지 마세요.
