## 설명 {#description}

응답 본문에는 Shippo Test API 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. API 토큰을 사용하면 배송 서비스에 사용되는 Shippo API에 액세스할 수 있습니다. 악의적인 행위자가 이 토큰에 액세스하면 청구 및 주문 정보에 액세스하고 배송 데이터를 수정할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키 처리에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

API 토큰을 취소하려면:

- Shippo 계정에 로그인하고 <https://apps.goshippo.com/>에 액세스합니다.
- 오른쪽 상단에서 "기어" 아이콘을 선택하여 "설정" 페이지로 이동합니다.
- 왼쪽 메뉴에서 "고급"으로 스크롤하고 "API"를 선택합니다.
- "토큰" 섹션에서 "토큰 관리"를 선택합니다.
- 식별된 토큰을 찾고 휴지통 아이콘을 선택합니다.
- 메시지가 표시되면 "토큰 관리" 대화 상자에서 "예, 토큰 제거"를 선택합니다.

자세한 내용은 [Shippo의 API 키 설명서](https://portal.goshippo.com/api-config/api)를 참조하세요.
