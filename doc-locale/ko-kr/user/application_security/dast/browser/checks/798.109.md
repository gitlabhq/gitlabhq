## 설명 {#description}

응답 본문에 Slack 봇 사용자 OAuth 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. Slack 앱의 기능과 권한은 요청하는 범위에 따라 결정됩니다. 전체 권한 목록은 [Slack의 범위 설명서](https://api.slack.com/scopes)에서 확인할 수 있습니다. 악의적 행위자가 이 토큰에 액세스할 수 있으면 할당된 기능을 실행할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

Slack 봇 사용자 OAuth 토큰을 취소하려면 (참고: 모든 사용자가 애플리케이션을 다시 승인해야 합니다):

- Slack에 로그인하고 <https://api.slack.com/apps>에 액세스합니다.
- 식별된 토큰이 있는 애플리케이션을 찾고 이름을 선택합니다.
- 왼쪽 메뉴에서 "OAuth & 권한"을 선택합니다.
- "모든 OAuth 토큰 취소"로 스크롤하고 "토큰 취소"를 선택합니다.
- 메시지가 표시되면 "확실하신가요?" 대화에서 "예, 확실합니다"를 선택합니다.
- 잠시 후 "OAuth 토큰" 섹션으로 다시 스크롤하여 "XXX로 다시 설치"를 선택합니다. 여기서 XXX는 워크스페이스 이름입니다.

자세한 정보는 [Slack의 OAuth 설명서](https://api.slack.com/authentication/oauth-v2)를 참고하세요.
