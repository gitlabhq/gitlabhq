## 설명 {#description}

응답 본문에 CircleCI 프로젝트 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. CircleCI 프로젝트 토큰에는 세 가지 범위 중 하나를 지정할 수 있습니다. - Status - Read Only - Admin 감지된 토큰의 액세스 수준에 따라 이 토큰에 액세스할 수 있는 악의적인 행위자는 프로젝트 및 CI/CD 파이프라인에 대한 완전한 액세스 권한을 얻을 수 있습니다. 이 값을 노출하면 공격자가 이 토큰에 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련된 보안 사건 처리에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

프로젝트 토큰을 회전하려면:

- CircleCI 애플리케이션에서 사이드바의 Projects를 선택하고 프로젝트 옆의 줄임표(...)를 선택한 후 "Project Settings"를 선택합니다.
- API Permissions을 선택합니다.
- 바꾸려는 토큰의 Remove 열에서 "X"를 선택합니다. 확인 창이 나타나면 형식에 DELETE 텍스트를 입력하고 "Delete API Token"을 선택합니다.
- "Create API Token"을 선택합니다.
- 드롭다운 목록에서 이전 토큰에 사용한 것과 동일한 범위를 선택합니다.
- Label 필드에 토큰에 대한 레이블을 입력합니다. 이전 토큰에 지정된 것과 동일한 이름일 수 있습니다.
- "Add API Token"을 선택합니다.

자세한 정보는 [프로젝트 토큰 회전에 대한 설명서](https://circleci.com/docs/managing-api-tokens/#rotating-a-project-api-token)를 참조하세요.
