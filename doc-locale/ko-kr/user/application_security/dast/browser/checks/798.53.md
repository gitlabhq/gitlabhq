## 설명 {#description}

응답 본문에는 GitHub OAuth 액세스 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 기존의 OAuth 토큰과 달리, 사용자 액세스 토큰은 범위를 사용하지 않습니다. 대신 세분화된 권한을 사용합니다. 사용자 액세스 토큰은 사용자와 앱이 모두 가진 권한만 있습니다. 악의적인 행위자가 토큰에 액세스하고 앱이 리포지토리의 콘텐츠를 쓸 수 있는 권한을 받았지만 사용자는 콘텐츠만 읽을 수 있는 경우, 사용자 액세스 토큰은 콘텐츠만 읽을 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요. 자세한 내용은 [OAuth 액세스 토큰을 취소하기 위한 GitHub 문서](https://docs.github.com/en/rest/apps/oauth-applications?apiVersion=2022-11-28#delete-an-app-token)를 참조하세요. 또한 GitHub Apps는 OAuth 앱보다 선호되므로 [자세한 내용을 보려면 GitHub 문서](https://docs.github.com/en/apps/oauth-apps/building-oauth-apps/differences-between-github-apps-and-oauth-apps)를 참조하세요.
