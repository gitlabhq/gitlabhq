## 설명 {#description}

응답 본문에는 GitLab 피드 토큰의 패턴과 일치하는 콘텐츠가 포함됩니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키와 관련된 보안 사건 처리에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

피드 토큰을 재생성하려면:

- GitLab 계정에 로그인하고 [사용자 설정](../../../../profile/_index.md#access-your-user-settings) 왼쪽 메뉴에서 "액세스 토큰"을 선택합니다
- "피드 토큰" 섹션에서 "이 토큰 재설정" 링크를 선택합니다
- 확인 대화상자가 나타나면 "확인"을 선택합니다. 자세한 정보는 [GitLab 피드 토큰 설명서](../../../../../security/tokens/_index.md#feed-token)를 참조하세요.
