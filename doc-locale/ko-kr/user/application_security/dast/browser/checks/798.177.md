## 설명 {#description}

응답 본문에 Stripe 비밀 테스트 키의 패턴과 일치하는 콘텐츠가 포함되어 있는 것으로 확인되었습니다. 테스트 비밀 키는 테스트 데이터 및 기능에 액세스하고 실행하는 데 사용됩니다. 이 테스트 키에 액세스할 수 있는 악의적인 행위자는 액세스만 시뮬레이션할 수 있으며, 계정 객체는 민감한 필드를 반환하지 않습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있게 될 수 있습니다.

## 수정 {#remediation}

유출된 키 처리에 관한 일반적인 지침을 보려면 GitLab 설명서의 [기밀 정보 인터넷 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

Stripe 비밀 테스트 키를 순환하려면:

- Stripe 계정에 로그인하고 <https://dashboard.stripe.com/apikeys>에 액세스합니다.
- 상단 메뉴에서 토글을 선택하여 "테스트 모드"가 활성화되었는지 확인하세요.
- "표준 키" 섹션에서 식별된 키를 찾고 오른쪽의 줄임표를 선택합니다.
- "키 순환..."을 선택합니다.
- "API 키 순환" 대화 상자에서 만료 날짜(예: "지금")를 선택합니다.
- "API 키 순환"을 선택합니다.

자세한 내용은 [API 키 순환에 대한 Stripe 설명서](https://docs.stripe.com/keys#rolling-keys)를 참조하세요.
