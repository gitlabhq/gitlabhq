## 설명 {#description}

응답 본문에 Asana 클라이언트 ID 패턴과 일치하는 콘텐츠가 검출되었습니다. 이 ID는 클라이언트 비밀과 함께 사용됩니다. 악의적인 행위자가 이 ID에 액세스할 수 있으면 클라이언트 비밀에도 액세스할 수 있을 경우 클라이언트 애플리케이션을 사칭할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

Asana 클라이언트 ID는 순환할 수 없으며, 새 클라이언트 ID를 얻기 위해서는 새로운 OAuth 클라이언트 애플리케이션을 생성해야 합니다. 자세한 내용은 [OAuth 구성에 대한 해당 문서를 참조하세요](https://developers.asana.com/docs/oauth)
