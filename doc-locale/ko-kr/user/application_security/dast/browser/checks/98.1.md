## 설명 {#description}

서버는 PHP 원격 파일 포함(RFI) 취약성에 노출되어 있으며, 공격자는 원격 파일을 로드하고 서버 측에서 PHP 스크립트로 실행할 수 있습니다. 이 취약성은 신뢰할 수 없는 사용자 입력이 적절한 유효성 검사 없이 스크립트 포함에 직접 사용될 때 발생합니다. 공격자는 이 취약성을 활용하여 임의의 원격 파일을 포함하고 실행하여 시스템의 무결성과 기밀성을 손상시킬 수 있습니다.

## 수정 {#remediation}

`include` 및 `require` 문에서 사용자 제어 데이터를 직접 사용하지 않도록 하고 대신 스크립트를 동적으로 포함하기 위해 허용 목록 접근 방식을 고려하세요.

가능하면 서버의 PHP 구성에서 `allow_url_include=Off`을 설정하여 `include` 및 `require` 문에서 URL을 사용할 수 없도록 하세요.
