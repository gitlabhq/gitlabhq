## 설명 {#description}

응답 본문에는 Lob API 키의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. API 키는 주소 확인, 캠페인 생성, 인쇄 또는 고객에게 직접 메일을 보내는 데 사용할 수 있습니다. 악의적인 행위자가 이 키에 액세스하면 제한 없이 Lob에 대한 모든 API 요청을 수행할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

API 키를 순환하려면:

- 계정에 로그인하여 <https://dashboard.lob.com/>로 이동합니다.
- 왼쪽 아래 모서리에서 기어 아이콘 / "설정" 메뉴 옵션을 선택합니다.
- "설정"에서 "API 키" 탭을 선택합니다.
- "라이브 환경"의 "비밀 API 키" 섹션에서 순환 화살표 아이콘을 선택합니다.
- 메시지가 표시되면 "비밀 라이브 API 키 순환" 대화 상자에서 "예"를 선택합니다.

자세한 내용은 [Lob의 API 키 문서](https://docs.lob.com/#tag/Authentication/API-Keys)를 참조하세요.
