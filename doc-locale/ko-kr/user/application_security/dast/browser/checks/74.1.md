## 설명 {#description}

XSL 템플릿을 서버 측 XSLT 프로세서에 제공할 수 있습니다. XSLT 프로세서를 악용하여 파일을 읽거나 쓰고, 아웃바운드 연결을 시작하며, 경우에 따라 임의의 코드를 실행할 수 있습니다.

## 수정 {#remediation}

애플리케이션은 사용자가 제공한 스타일시트를 절대로 수용해서는 안 됩니다. XSLT 프로세서는 잠재적으로 악성인 스타일시트 파일을 처리하도록 설계되지 않았습니다. 그러나 일부 프로세서는 사용 가능한 보안 기능을 구현하거나 제공합니다. 대상 애플리케이션에서 사용하는 XSLT 프로세서의 문서를 참조하여 보안 지침 및 강화 단계를 확인하세요. 모든 XML 파서 및 프로세서는 최소한 외부 엔티티 해석을 비활성화하는 것이 좋습니다.
