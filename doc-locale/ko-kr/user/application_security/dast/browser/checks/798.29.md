## 설명 {#description}

응답 본문에는 Doppler 개인 액세스 토큰 패턴과 일치하는 콘텐츠가 포함되어 있으며 감지되었습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

Doppler 개인 액세스 토큰을 취소하려면:

- <https://dashboard.doppler.com/>에 열고 로그인하세요
- 오른쪽 메뉴의 "토큰"을 선택합니다
- "개인" 탭을 선택합니다
- 개인 토큰을 찾은 후 작업 열에서 "롤"을 선택합니다
- "롤 개인 토큰" 대화 상자가 표시된 후 "롤"을 선택합니다
- 새 토큰의 값을 복사합니다

자세한 내용은 해당 설명서를 참조하세요: <https://docs.doppler.com/docs/start>
