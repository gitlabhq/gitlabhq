## 설명 {#description}

대상 웹사이트는 AspNet 헤더 및 이 웹사이트의 버전 정보를 반환합니다. 이러한 값을 노출하면 공격자가 대상 소프트웨어가 알려진 취약성에 취약한지 확인하거나 특정 버전을 실행하는 알려진 사이트를 카탈로그화하여 나중에 특정 버전에서 취약성이 확인될 때 악용할 수 있습니다.

## 수정 {#remediation}

`X-AspNet-Version` 헤더를 제거하려면 `Web.config` 파일의 `<system.Web>` 섹션에서 `<httpRuntime enableVersionHeader="false" />`를 설정합니다.
