## 설명 {#description}

응답 본문에는 GitLab 배포 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 배포 토큰은 사용자 계정과 관계없이 배포 작업의 인증을 활성화합니다. 배포 토큰을 사용하면 자동화된 작업이 다음을 수행할 수 있습니다. - Git 리포지토리 복제 - GitLab 컨테이너 레지스트리에서 끌어오고 푸시 - GitLab 패키지 레지스트리에서 끌어오고 푸시 이 토큰에 액세스할 수 있는 악의적인 행위자는 Git 리포지토리에 액세스하거나 릴리스된 패키지 또는 컨테이너를 손상시킬 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키 처리에 대한 일반적인 지침은 [인증 정보 인터넷 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)에 대한 GitLab 설명서를 참조하세요.

자세한 내용은 [배포 토큰 취소에 대한 GitLab 설명서](../../../../project/deploy_tokens/_index.md)를 참조하세요.
