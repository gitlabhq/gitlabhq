## 설명 {#description}

응답 본문에는 GitLab CI 빌드(작업) 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 작업 토큰은 파이프라인 작업의 컨텍스트 내에서 기능을 실행하는 데 사용됩니다. 대부분의 경우 작업 토큰은 권한이 제한되어 있으며 파이프라인이 실행되는 리포지토리에서만 읽을 수 있습니다. 외부 프로젝트는 다른 프로젝트의 작업 토큰에 대한 액세스를 부여할 수 있습니다. 악의적인 행위자는 이 토큰을 사용하여 리포지토리에 액세스하려고 시도할 수 있는 제한된 시간이 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련된 보안 사건 처리에 대한 일반적인 지침은 [인터넷에 노출된 자격 증명](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)에 대한 GitLab 설명서를 참조하세요. 작업 토큰은 단기간 유효하기 때문에 해지 프로세스가 없으며, 해당 토큰을 생성한 작업이 완료된 후에는 더 이상 사용할 수 없습니다. 작업 토큰이 정확히 어떤 작업에 액세스할 수 있는지에 대한 자세한 내용은 [작업 토큰에 대한 GitLab 설명서](../../../../../ci/jobs/ci_job_token.md)를 참조하세요.
