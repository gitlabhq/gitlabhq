## 설명 {#description}

대상 애플리케이션에서 코드 주입 취약점이 발견되었습니다. 악의적인 행위자가 임의의 Ruby 코드를 서버에서 실행하도록 주입할 수 있습니다. 저장된 보안 정보에 액세스하거나 코드를 주입하여 계정을 탈취하거나 OS 명령을 실행함으로써 전체 시스템이 손상될 수 있습니다.

## 수정 {#remediation}

사용자 입력을 `eval`, `send`, `public_send`, `instance_eval` 또는 `class_eval`와 같이 문자열 데이터를 코드로 평가하는 함수에 직접 전달하지 마세요. 문자열 값을 이 메서드에 전달하는 것에는 거의 이점이 없으므로, 사용자 입력을 사용하여 동적으로 로직을 평가하는 더 안전한 구현으로 현재 로직을 교체하는 것이 가장 좋은 권장사항입니다. `send` 또는 `public_send`을 사용하는 경우 첫 번째 인수가 알려진 하드코딩된 메서드/기호이며 사용자 입력에서 나오지 않도록 해야 합니다.

`eval`, `instance_eval` 및 `class_eval`의 경우 사용자 입력을 이 메서드에 직접 전달해서는 안 됩니다. 한 가지 방법은 키를 사용하여 조회할 수 있는 해시에 함수 또는 메서드를 저장하는 것입니다. 키가 존재하면 함수를 실행할 수 있습니다.

```ruby
def func_to_run
  puts 'hello world'
end

input = 'fn'

function_map = { fn: method(:func_to_run) }

if function_map.key?(input.to_sym)
  function_map[input.to_sym].call
else
  puts 'invalid input'
end
```
