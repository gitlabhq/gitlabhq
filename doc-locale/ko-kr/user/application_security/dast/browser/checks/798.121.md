## 설명 {#description}

응답 본문에는 X 비밀 액세스 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 액세스 비밀은 OAuth 1.0a API 요청을 인증하는 데 사용되는 사용자별 자격 증명입니다. 사용자를 대신하여 요청이 이루어지는 X 계정을 지정합니다. 악의적인 행위자가 이 토큰에 액세스하면 사용자를 대신하여 요청을 위조할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.
