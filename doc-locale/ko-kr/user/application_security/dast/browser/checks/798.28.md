## 설명 {#description}

응답 본문에는 Discord 클라이언트 비결의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 이 값을 노출하면 공격자가 이 토큰에 의해 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키 처리에 관한 일반적인 지침은 [기밀 정보 인터넷 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)에 대한 GitLab 설명서를 참조하세요.

Discord 클라이언트 비결을 회전하려면:

- 로그인하여 <https://discord.com/developers/applications/>을 방문하세요.
- 식별된 비결이 속한 애플리케이션을 선택합니다.
- 왼쪽 메뉴에서 "OAuth 2" 메뉴 항목을 선택합니다.
- 페이지의 "클라이언트 정보" 섹션 아래에서 "비결 재설정"을 선택합니다.
- 메시지가 표시되면 "예, 진행하세요!"를 선택합니다.

자세한 내용은 [Discord의 OAuth 설명서](https://discord.com/developers/docs/topics/oauth2)를 참조하세요.
