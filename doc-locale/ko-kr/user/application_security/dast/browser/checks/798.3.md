## 설명 {#description}

응답 본문에 Adobe 클라이언트 보안 정보의 패턴과 일치하는 콘텐츠가 감지되었습니다. Adobe 클라이언트 보안 정보는 다양한 API 또는 웹후크 이벤트 기반 서비스에 연결하는 데 사용됩니다. 프로젝트에 정의된 서비스 유형에 따라 보안 정보에 액세스할 수 있는 악의적 행위자는 이를 사용하여 민감한 정보를 포함할 수 있는 다양한 API 또는 이벤트에 액세스할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요. 수정 단계는 유출된 클라이언트 보안 정보의 유형에 따라 달라집니다. 아래의 다음 수정 단계 유형을 참조하여 감지된 보안 정보에 해당하는 단계를 사용하세요.

OAuth(서버 간):

- <https://developer.adobe.com/console>에서 계정에 로그인합니다.
- 프로젝트 또는 "모든 프로젝트"를 선택하여 영향을 받는 프로젝트를 찾습니다. 왼쪽에서 "자격 증명" 아래의 "OAuth 서버 간"을 선택합니다.
- "클라이언트 보안 정보" 아래에서 "클라이언트 보안 정보 검색"을 선택합니다.
- 보안 정보 테이블이 표시되면 테이블 아래에서 "새 클라이언트 보안 정보 추가"를 선택합니다.
- 새 보안 정보가 생성되면 유출된 토큰 값을 찾아 휴지통 아이콘을 선택하여 제거합니다.
- 보안 정보 값을 복사하고 모든 서비스를 새 클라이언트 보안 정보로 업데이트합니다.

OAuth Web App(이벤트 기반 프로젝트):

- 프로젝트 또는 "모든 프로젝트"를 선택하여 영향을 받는 프로젝트를 찾습니다.
- 왼쪽에서 "자격 증명" 아래의 "OAuth Web App"을 선택합니다.
- "클라이언트 보안 정보 검색"을 선택합니다.
- 이것이 유출된 보안 정보인지 확인합니다.
- 이 프로젝트가 이벤트에 대해 구성된 경우 제거하기 전에 모든 이벤트 세부 정보를 복사합니다. 오른쪽에 나열된 이벤트를 찾아 선택하면 됩니다. 이벤트 배송 방법, 공급자, 구독된 이벤트 및 연결된 자격 증명과 같은 세부 정보를 표시하는 대시보드로 이동해야 합니다.
- 이벤트를 제거하려면 프로젝트 페이지의 오른쪽에 있는 "다른 서비스 연결" 위의 이벤트에서 "..."를 선택합니다.
- "제거"를 선택합니다.
- 메시지가 표시되면 프로젝트 이름을 입력하고 "이벤트 등록 삭제"를 선택합니다.
- 오른쪽 상단에서 "자격 증명 삭제"를 선택합니다.
- 메시지가 표시되면 프로젝트 이름을 입력하고 "자격 증명 삭제"를 선택합니다.
- 이전과 동일한 세부 정보로 이벤트를 다시 추가합니다.
- 자격 증명을 다시 추가하라는 메시지가 표시되면 "User Authentication" OAuth를 사용해야 합니다.
- OAuth 2.0 인증 및 권한 부여를 위해 "Web App"을 선택합니다.
- 이벤트가 다시 추가된 후 왼쪽의 "자격 증명" 아래에서 "OAuth Web App"을 선택합니다.
- "클라이언트 보안 정보 검색"을 선택합니다.
- 보안 정보 값을 복사하고 모든 서비스를 새 클라이언트 보안 정보로 업데이트합니다.

OAuth Web App(API 서비스 기반 프로젝트):

- <https://developer.adobe.com/console>에서 계정에 로그인합니다.
- 프로젝트 또는 "모든 프로젝트"를 선택하여 영향을 받는 프로젝트를 찾습니다.
- 왼쪽에서 "자격 증명" 아래의 "OAuth Web App"을 선택합니다.
- "클라이언트 보안 정보 검색"을 선택합니다.
- 이 프로젝트가 API에 대해 구성된 경우 휴지통 아이콘 "제거"를 선택하여 연결된 제품 및 서비스를 제거합니다.
- 메시지가 표시되면 프로젝트 이름을 입력하고 "API 제거"를 선택합니다.
- 오른쪽 상단에서 "자격 증명 삭제"를 선택합니다.
- 메시지가 표시되면 프로젝트 이름을 입력하고 "자격 증명 삭제"를 선택합니다.
- 이전과 동일한 세부 정보로 API를 다시 추가합니다.
- OAuth 2.0 인증 및 권한 부여를 위해 "Web App"을 선택합니다.
- 서비스가 다시 추가된 후 왼쪽의 "자격 증명" 아래에서 "OAuth Web App"을 선택합니다.
- "클라이언트 보안 정보 검색"을 선택합니다.
- 보안 정보 값을 복사하고 모든 서비스를 새 클라이언트 보안 정보로 업데이트합니다.
