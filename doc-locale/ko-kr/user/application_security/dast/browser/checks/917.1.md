## 설명 {#description}

대상 애플리케이션 서버에서 임의의 Expression Language(EL) 문을 실행할 수 있습니다. EL 주입은 중대한 심각도 취약성으로 전체 시스템 침해로 이어질 수 있습니다. EL 주입은 공격자가 제어하는 데이터를 특수 문자를 중립화하지 않고 EL 문을 구성하는 데 사용할 때 발생할 수 있습니다. 이러한 특수 문자는 인터프리터에 의해 실행되기 전에 의도된 EL 문을 수정할 수 있습니다.

## 수정 {#remediation}

사용자 제어 데이터는 Expression Language 문을 생성할 때 항상 특수 요소가 중립화되어야 합니다. 사용 중인 EL 인터프리터 설명서를 참조하여 사용자가 제어하는 데이터를 올바르게 중립화하는 방법을 확인하세요.
