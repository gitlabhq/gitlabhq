## 설명 {#description}

응답 본문에는 Duffel API 토큰의 패턴과 일치하는 콘텐츠가 감지되었습니다. Duffel API 토큰은 생성 방식에 따라 읽기-쓰기 또는 읽기 전용일 수 있습니다. 읽기-쓰기 토큰에 접근할 수 있는 악의적인 행위자는 주문을 실행하고, 항공편이나 호텔을 예약하거나, 고객 목록을 보거나 수정할 수 있습니다. 읽기 전용 토큰은 고객 목록을 보고, 예약 및 항공편 정보를 나열할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

토큰을 재생성하려면:

- <https://app.duffel.com/>에 열고 로그인하세요
- 페이지 상단에서 Developers 드롭다운 목록을 선택하고 "Developers"를 선택하세요
- 왼쪽 메뉴에서 "Access tokens"를 선택하세요
- 감지된 액세스 토큰을 선택하세요
- 토큰의 유형("Read and Write" 또는 "Read Only")을 확인하세요
- "Danger Zone"에서 "Delete token"을 선택하세요
- 감지된 토큰과 동일한 설정으로 새로운 토큰을 다시 생성하세요

자세한 정보는 설명서를 참조하세요: <https://duffel.com/docs/guides/getting-started-with-the-dashboard#access-tokens>
