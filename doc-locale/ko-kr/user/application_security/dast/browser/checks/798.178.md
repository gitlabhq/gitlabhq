## 설명 {#description}

응답 본문에 Stripe 제한된 테스트 키의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 테스트 제한 키는 특정 API 리소스에 대한 읽기 또는 쓰기 액세스만 허용하여 더 높은 보안을 제공합니다. 이 키에 액세스하는 악의적 행위자는 정의된 범위로 제한되며 테스트 데이터에만 액세스할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키와 관련된 보안 사고 처리에 대한 일반적인 지침은 [인터넷에 노출된 자격 증명](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)에 관한 GitLab 문서를 참조하세요.

Stripe 제한된 테스트 키를 교체하려면:

- Stripe 계정에 로그인하고 <https://dashboard.stripe.com/apikeys>에 액세스합니다.
- 상단 메뉴에서 토글을 선택하여 "Test mode"가 활성화되었는지 확인합니다.
- "Restricted keys" 섹션에서 식별된 키를 찾고 오른쪽의 생략 기호를 선택합니다.
- "Roll key..."를 선택합니다.
- "Roll API key" 대화 상자에서 만료 날짜를 선택합니다(예: "now").
- "Roll API Key"를 선택합니다.

자세한 내용은 [API 키 교체에 관한 Stripe 문서](https://docs.stripe.com/keys#rolling-keys)를 참조하세요.
