## 설명 {#description}

개인 RFC 1918/RFC 4193 주소가 대상 애플리케이션에서 확인되었습니다. 공개 웹사이트는 개인 IP 주소로 요청을 발행하면 안 됩니다. 서버 측 요청 위조(SSRF)와 같은 후속 공격을 시도하는 공격자는 이 정보를 사용하여 추가 내부 대상을 식별할 수 있습니다.

## 수정 {#remediation}

내부 IP 주소를 잘못 지정하고 있는 리소스를 식별하고 공개 버전으로 바꾸거나 대상 애플리케이션에서 참조를 제거합니다.
