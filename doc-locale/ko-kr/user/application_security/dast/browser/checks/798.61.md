## 설명 {#description}

응답 본문에는 Intercom API 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.
