## 설명 {#description}

응답 본문에는 Contentful 미리보기 API 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 미리보기 API 토큰은 Content Delivery API(CDA)와 동일한 동작 및 매개변수를 유지하지만, 항목 및 자산에 대한 최신 초안을 제공합니다. Content Preview API는 항목의 최신 버전을 표시하는 데 사용됩니다. 악의적인 행위자가 이 토큰에 액세스할 수 있으면 게시된 항목과 게시 취소된 항목을 볼 수 있습니다. 자세한 내용은 [미리보기 API 설명서](https://www.contentful.com/developers/docs/references/content-preview-api/)를 참조하세요. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키 처리에 관한 일반적인 지침은 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)에 관한 GitLab 설명서를 참조하세요.

미리보기 API 토큰을 해지하려면 다음을 수행하세요:

- 로그인하여 <https://app.contentful.com/>을 방문하세요.
- 오른쪽 상단 모서리의 톱니바퀴 아이콘을 선택한 다음 "API Keys"를 선택하세요.
- 감지된 API 키를 찾고 API 키 테이블에서 해당 이름을 선택하세요.
- 오른쪽 상단 모서리에서 "Delete"를 선택하세요.
- 메시지가 표시되면 "Delete"를 선택하세요. 이는 Delivery API 토큰도 삭제합니다.

새로운 API 키 세트를 생성해야 합니다.

자세한 내용은 [인증에 관한 개발자 설명서](https://www.contentful.com/developers/docs/references/authentication/#the-content-delivery-and-preview-api)를 참조하세요.
