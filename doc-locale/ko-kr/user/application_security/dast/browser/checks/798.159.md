## 설명 {#description}

응답 본문에 Artifactory Identity Token의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. Artifactory Identity Token은 리포지토리에 액세스하고, 아티팩트를 다운로드하고, 아티팩트를 업로드하고, 토큰의 할당된 권한을 기반으로 JFrog Artifactory 내에서 권한이 있는 작업을 실행할 수 있습니다. 토큰이 유출되면 악의적인 행위자가 이 토큰을 사용하여 독점 코드를 도용하거나, 손상된 종속성을 소프트웨어 공급망에 주입하거나, Artifactory를 빌드에 사용하는 연결된 CI/CD 시스템에 무단 액세스할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키 처리에 관한 일반적인 지침은 GitLab 설명서에서 [인증 정보 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.
