## 설명 {#description}

응답 본문에 Artifactory API Key의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. Artifactory API Key는 아티팩트 배포, 리포지토리 관리, 권한 구성, JFrog Artifactory 리포지토리에서 아티팩트 검색 등의 작업을 수행할 수 있습니다. 유출된 경우, 악의적 행위자가 이를 사용하여 민감한 독점 코드를 유출하거나, 빌드 파이프라인에 악성 패키지를 주입하거나, 조직의 소프트웨어 배포 기능을 방해할 수 있는 중요한 아티팩트를 삭제할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키 처리에 대한 일반적인 지침을 보려면 GitLab 설명서의 [Credential exposure to the internet](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)를 참조하세요.
