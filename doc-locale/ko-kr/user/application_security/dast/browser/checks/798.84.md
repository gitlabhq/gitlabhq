## 설명 {#description}

응답 본문에 npm 액세스 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 액세스 토큰은 클래식 또는 세분화된 토큰 모두 사용 가능하며, 두 유형 모두 권한을 사용자 지정할 수 있습니다. 권한에 따라 이 토큰에 액세스할 수 있는 악의적인 행위자는 패키지와 패키지 정보를 읽거나 새 패키지를 생성하여 해당 계정으로 게시할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰에 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키와 관련된 보안 사건 처리에 대한 일반적인 지침은 GitLab 설명서에서 [인증서 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

UI에서 액세스 토큰을 취소하려면:

- npm 계정에 <https://www.npmjs.com/login>에서 로그인합니다.
- 오른쪽 위 모서리에서 프로필 사진을 선택한 후 "액세스 토큰"을 선택합니다.
- 식별된 토큰을 찾아 "삭제" 열에서 "x"를 선택합니다.
- 메시지가 표시되면 대화상자에서 "확인"을 선택합니다.

자세한 내용은 [npm 액세스 토큰 취소에 대한 설명서](https://docs.npmjs.com/revoking-access-tokens)를 참조하세요.
