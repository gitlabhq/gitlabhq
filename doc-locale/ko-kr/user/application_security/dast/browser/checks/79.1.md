## 설명 {#description}

크로스 사이트 스크립팅(XSS)은 웹 애플리케이션이나 시스템을 악용하여 사용자 입력을 마크업 또는 스크립트 코드로 처리하는 공격입니다. 데이터를 사용하는 특정 컨텍스트에 따라 데이터를 인코딩하는 것이 중요합니다. 최소 6가지 컨텍스트 유형이 있습니다:

- HTML 태그 내부 `<div>context 1</div>`
- 속성 내부: ```<div class="context 2"></div>```
- 이벤트 속성 내부 ```<button onclick="context 3">button</button>```
- 스크립트 블록 내부: ```<script>var x = "context 4"</script>```
- 안전하지 않은 요소 HTML 할당: ```element.innerHTML = "context 5"```
- URL 내부: ```<iframe src="context 6"></iframe><a href="context 6">link</a>```

스크립트 블록만 여러 방식으로 인코딩할 수 있습니다. 사용자 입력을 스크립트 태그 외부에 작성해야 하는 경우 주의하세요.

## 수정 {#remediation}

애플리케이션에 표시되는 사용자 입력은 인코딩, 정제 또는 검증되어야 하므로 HTML로 처리되거나 JavaScript 코드로 실행되지 않습니다. 서버 측 템플릿과 클라이언트 측 템플릿을 혼합하지 않도록 주의하세요. 서버 측에서는 `{{ 7*7 }}`과 같은 텍스트를 인코딩하지 않기 때문입니다. 이는 클라이언트 측 기능을 실행할 수 있습니다.

데이터 저장소에 삽입하기 전에 사용자 입력을 인코딩하지 마세요. 데이터는 출력 컨텍스트에 따라 인코딩되어야 합니다. 인코딩을 처리하도록 표시 시스템을 강제하는 것이 훨씬 더 안전합니다.

사용자 입력을 자동으로 인코딩하기 위해 기본 제공 프레임워크 기능을 사용하는 것을 고려하세요. 입력을 자동으로 인코딩할 수 없는 경우 적절한 출력 인코딩을 사용하도록 주의하세요. 다음 권장 사항은 최선의 노력이며 모든 상황에서 작동하지 않을 수 있습니다.

- HTML 태그 내부에서 `script`을 제외한 다음을 인코딩합니다:
  - `<`을 `&lt;`로
  - `>`을 `&gt;`로
  - `'`을 `&apos;`로
  - `"`을 `&quot;`로
  - `=`을 `&#61;`로
- 속성 내부에서 이벤트 속성을 제외한 다음을 인코딩합니다:
  - `<`을 `&lt;`로
  - `>`을 `&gt;`로
  - `'`을 `&apos;`로
  - `"`을 `&quot;`로
  - `=`을 `&#61;`로
- 이벤트 속성, 스크립트 블록 및 안전하지 않은 HTML 할당 내부에서 다음을 인코딩합니다:
  - 리터럴 탭(`\t`)을 `\\t`로
  - 리터럴 줄 바꿈(`\n`)을 `\\n`로
  - 리터럴 세로 탭(`\v`)을 `\u000b`로
  - 리터럴 폼 피드(`\f`)를 `\\f`로
  - 리터럴 캐리지 리턴(`\r`)을 `\\r`로
  - 리터럴 등호(`=`)를 `\u0061`로
  - 리터럴 백틱(`\`)을 `\u0060`로
  - 리터럴 큰따옴표(`"`)를 `\u0022`로
  - 리터럴 앰퍼샌드(`&`)를 `\u0026`로
  - 리터럴 작은따옴표(`'`)를 `\u0027`로
  - 리터럴 더하기 기호(`+`)를 `\u002b`로
  - 리터럴 슬래시(`/`)를 `\/`로
  - 리터럴 보다 작음 기호(`<`)를 `\u003c`로
  - 리터럴 보다 큼 기호(`>`)를 `\u003e`로
  - 리터럴 열린 괄호(`(`)를 `\u0028`로
  - 리터럴 닫힌 괄호(`)`)를 `\u0029`로
  - 리터럴 열린 대괄호(`[`)를 `\u005b`로
  - 리터럴 닫힌 대괄호(`]`)를 `\u005d`로
  - 리터럴 열린 중괄호(`{`)를 `\u007b`로
  - 리터럴 닫힌 중괄호(`}`)를 `\u007d`로
  - 리터럴 백슬래시(`\`)를 `\\`로

  이 목록은 전체 목록이 아닙니다. 컨텍스트에 따라 추가 문자를 인코딩해야 할 수 있습니다.
- URL 내부:
  - 사용자 입력을 URL에 인쇄할 수 없습니다. 공격자는 `javascript:...` 코드 또는 악성 링크를 주입할 수 있습니다.
