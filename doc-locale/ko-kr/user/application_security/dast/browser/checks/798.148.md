## 설명 {#description}

응답 본문에 GitLab Agent for Kubernetes 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. Kubernetes 액세스 토큰은 GitLab agent for Kubernetes가 Kubernetes 클러스터에 인증하는 데 사용됩니다. 이 토큰에 액세스할 수 있는 악의적인 사용자는 에이전트의 구성 프로젝트에서 소스 코드에 액세스하거나, GitLab 인스턴스의 모든 공개 프로젝트에서 소스 코드에 액세스하거나, 매우 특정한 조건에서 Kubernetes 매니페스트를 얻을 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키 처리와 관련된 보안 인시던트 처리에 대한 일반적인 지침은 GitLab 문서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요. 자세한 내용은 [Kubernetes 에이전트 토큰 회전에 관한 GitLab 문서](../../../../clusters/agent/work_with_agent.md#reset-the-agent-token)를 참조하세요.
