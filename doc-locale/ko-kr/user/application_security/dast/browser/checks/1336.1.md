## 설명 {#description}

애플리케이션은 공격자가 서버 측에서 템플릿을 조작할 수 있도록 하는 서버 측 템플릿 주입(SSTI)취약성이 있습니다. 이 취약성은 신뢰할 수 없는 사용자 입력이 적절한 새니타이제이션 없이 서버 측 템플릿에 직접 사용될 때 발생합니다. 공격자는 이 약점을 악용하여 템플릿에 임의의 코드를 주입하고 실행하여 시스템의 무결성과 기밀성을 손상시킬 수 있습니다.

## 수정 {#remediation}

사용자 제어 데이터는 Expression Language 문을 생성할 때 항상 특수 요소가 중립화되어야 합니다. 사용 중인 템플릿 시스템의 설명서를 참조하여 사용자 제어 데이터를 적절히 중립화하는 방법을 확인하세요.
