## 설명 {#description}

응답 본문에 PlanetScale 암호 패턴과 일치하는 콘텐츠가 포함되어 있는 것으로 확인되었습니다. PlanetScale 암호는 데이터베이스 인스턴스에 연결할 때 사용됩니다. 악의적인 행위자가 이 암호에 접근하면 PlanetScale에서 관리하는 데이터베이스에 접근할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요. 자세한 내용은 [PlanetScale 데이터베이스 연결 문자열 설명서](https://planetscale.com/docs/concepts/connection-strings)를 참조하세요.
