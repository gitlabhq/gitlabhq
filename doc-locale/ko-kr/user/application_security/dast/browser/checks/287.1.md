## 설명 {#description}

대상 애플리케이션이 HTTP를 통한 기본 인증 방식을 사용하여 사용자를 인증하는 것으로 발견되었습니다. 기본 인증은 사용자명과 암호를 base64로 인코딩하여 `Authentication` 헤더에서 전송합니다. 클라이언트와 서버 사이의 통신 경로(또는 같은 로컬 네트워크)에 있는 공격자는 패킷 스니퍼를 사용하여 사용자명과 암호를 읽고 디코딩할 수 있습니다.

## 수정 {#remediation}

가능하면 OAuth 2.0과 같이 사용자를 인증하는 더 강력한 방법으로 전환하거나, Argon2id 알고리즘으로 보호된 데이터 저장소에 사용자명과 암호를 저장하세요. 기본 인증을 반드시 사용해야 하는 경우, 자격 증명이 HTTPS/TLS과 같은 보안 채널을 통해서만 전송되도록 하세요.
