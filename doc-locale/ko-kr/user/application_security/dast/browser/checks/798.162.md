## 설명 {#description}

응답 본문에는 Oculus 액세스 토큰 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 사용자 토큰은 앱이 API를 호출하여 특정 사용자의 Oculus 데이터를 읽거나, 수정하거나, 쓸 때마다 필요합니다. 이 토큰에 접근한 악의적인 행위자는 특정 사용자 대신 Oculus API를 호출할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키와 관련된 보안 사건 처리에 대한 일반적인 지침은 GitLab 문서의 [인터넷에 노출된 자격 증명](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

Oculus 액세스 토큰을 순환시키려면:

- <https://developer.oculus.com/>에서 Oculus 개발자 계정에 로그인하세요.
- 왼쪽 메뉴에서 "Development"를 선택한 후 "API"를 선택하세요.
- "User Token" 아래에서 "Generate Token"을 선택하세요.

자세한 내용은 [Meta의 액세스 토큰 보호에 대한 문서](https://developers.meta.com/horizon/resources/publish-sec-details#protecting-credentials-and-access-tokens)를 참조하세요.
