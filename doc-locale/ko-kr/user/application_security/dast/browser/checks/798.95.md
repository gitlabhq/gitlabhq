## 설명 {#description}

응답 본문에 Pulumi API 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 개인 액세스 토큰은 사용자의 권한에 매핑됩니다. 이 토큰에 액세스할 수 있는 악의적 행위자는 액세스 토큰의 소유자로서 스택, 태그, 업데이트 및 웹후크를 삭제할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키 처리에 관한 일반적인 지침은 [인터넷에 노출된 자격증명](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)에 대한 GitLab 설명서를 참조하세요. API 토큰을 취소하려면:

- Pulumi 계정에 로그인하고 <https://app.pulumi.com/>에 액세스합니다.
- 오른쪽 위 모서리에서 프로필 사진을 선택하고 "개인 액세스 토큰"을 선택합니다.
- 식별된 토큰을 찾고 키의 "작업" 열에서 줄임표를 선택한 후 "토큰 삭제"를 선택합니다.
- 메시지가 표시되면 "토큰 삭제" 대화 상자에서 "토큰 삭제"를 선택합니다.

자세한 내용은 [Pulumi의 개인 액세스 토큰 설명서](https://www.pulumi.com/docs/pulumi-cloud/access-management/access-tokens/#personal-access-tokens)를 참조하세요.
