## 설명 {#description}

응답 본문에 GitLab 러너 인증 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 이러한 토큰을 사용하면 사용자가 선택한 프로젝트로 러너로 등록하거나 인증할 수 있습니다. 악의적인 행위자가 이 토큰에 액세스할 수 있으면 파이프라인에 사용자 지정 러너를 추가하고 러너가 사용된 경우 리포지토리를 손상시킬 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키와 관련된 보안 사건 처리에 대한 일반적인 지침은 [인터넷에 대한 자격증 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)에 대한 GitLab 문서를 참조하세요.

러너 인증 토큰을 취소하려면 러너를 제거한 후 다시 만들어야 합니다:

- GitLab 계정에 로그인하고 러너 등록 토큰을 생성한 프로젝트를 방문합니다.
- 왼쪽 메뉴에서 "설정"을 선택합니다.
- "설정" 옵션 아래에서 "CI/CD"를 선택합니다.
- "러너" 섹션 아래에서 식별된 토큰이 있는 러너를 찾습니다. (확실하지 않은 경우 러너 `config.toml`를 확인할 수 있습니다.)
- "러너 제거"를 선택합니다.
- 메시지가 표시되면 "제거"를 선택합니다.

자세한 내용은 [GitLab 러너 등록 문서](https://docs.gitlab.com/runner/register/)를 참조하세요.
