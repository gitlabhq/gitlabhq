## 설명 {#description}

응답 본문에 Stripe 라이브 비밀 키의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 라이브 비밀 키는 라이브 모드에서 서버의 요청을 인증합니다. 기본적으로 이 키를 사용하여 제한 없이 모든 API 요청을 수행할 수 있습니다. 이 키에 액세스한 악의적인 행위자는 이 계정의 Stripe에 있는 모든 데이터에 대한 읽기/쓰기 액세스를 얻을 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

Stripe 라이브 비밀 키를 순환하려면:

- Stripe 계정에 로그인하고 <https://dashboard.stripe.com/apikeys>에 액세스합니다.
- "테스트 모드"가 비활성화되었는지 확인합니다.
- "표준 키" 섹션에서 식별된 키를 찾고 오른쪽의 줄임표를 선택합니다.
- "키 순환..."을 선택합니다. "API 키 순환" 대화상자에서 만료 날짜(예: "지금")를 선택합니다.
- "API 키 순환"을 선택합니다.

자세한 내용은 [Stripe의 API 키 순환에 관한 설명서](https://docs.stripe.com/keys#rolling-keys)를 참조하세요.
