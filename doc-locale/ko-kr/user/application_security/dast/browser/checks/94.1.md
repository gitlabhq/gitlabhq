## 설명 {#description}

대상 애플리케이션이 코드 주입에 취약한 것으로 발견되었습니다. 악의적인 행위자가 서버에서 실행될 임의의 PHP 코드를 주입할 수 있습니다. 이로 인해 저장된 비밀정보에 액세스하거나 계정을 탈취하는 코드를 주입하거나 OS 명령을 실행하여 전체 시스템 손상이 발생할 수 있습니다.

## 수정 {#remediation}

사용자 입력값을 `eval`과 같이 문자열 데이터를 코드로 평가하는 함수에 직접 전달하지 마세요. `eval`에 문자열 값을 전달하는 것은 거의 이점이 없으므로, 사용자 입력값을 사용하여 동적으로 로직을 평가하는 더 안전한 구현으로 현재 로직을 바꾸는 것이 가장 좋습니다. 다른 방법으로는 `array()`를 사용하여 예상되는 사용자 입력값을 배열 키에 저장하고 해당 키를 함수 실행을 위한 조회로 사용하는 것입니다:

```php
$func_to_run = function()
{
    print('hello world');
};

$function_map = array();
$function_map["fn"] = $func_to_run; // store additional input to function mappings here

$input = "fn";

// lookup "fn" as the key
if (array_key_exists($input, $function_map)) {
    // run the $func_to_run that was stored in the "fn" array hash value.
    $func = $function_map[$input];
    $func();
} else {
    print('invalid input');
}
```
