## 설명 {#description}

응답 본문에는 Contentful 전달 API 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. Contentful Delivery API(CDA)는 Contentful에서 앱, 웹사이트 및 기타 미디어로 콘텐츠를 전달하는 읽기 전용 API입니다. 콘텐츠는 JSON 데이터로 전달되며, 이미지, 비디오 및 기타 미디어는 파일로 전달됩니다. 이 토큰에 액세스할 수 있는 악의적인 행위자는 항목에 대한 읽기 전용 액세스 권한을 가집니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

전달 API 토큰을 취소하려면:

- 로그인하여 <https://app.contentful.com/>에 접속하세요.
- 오른쪽 위 모서리의 톱니바퀴 아이콘을 선택한 다음 "API 키"를 선택하세요.
- 검색된 API 키를 찾아 API 키 테이블에서 해당 이름을 선택하세요.
- 오른쪽 위 모서리에서 "삭제"를 선택하세요.
- 확인 메시지가 표시되면 "삭제"를 선택합니다. 이 작업은 미리보기 API 토큰도 삭제됩니다. 새로운 API 키 세트를 생성해야 합니다.

자세한 내용은 [인증에 대한 개발자 설명서](https://www.contentful.com/developers/docs/references/authentication/#the-content-delivery-and-preview-api)를 참조하세요.
