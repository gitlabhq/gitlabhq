## 설명 {#description}

응답 본문에 Slack 웹후크 URL의 패턴과 일치하는 콘텐츠가 감지되었습니다. Slack 웹후크 URL은 외부 소스에서 Slack으로 메시지를 게시하는 데 사용됩니다. 메시지와 몇 가지 다른 선택적 세부 정보가 포함된 JSON 페이로드가 있는 HTTP 요청을 사용합니다. 서식이 지정된 메시지를 표시하기 위해 메시지 첨부 파일을 포함할 수 있습니다. 이 URL에 액세스할 수 있는 악의적인 행위자는 바인딩된 Slack 채널에 메시지를 게시할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키에 관한 보안 사건 처리에 대한 일반적인 지침은 [기밀 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)에 관한 GitLab 문서를 참조하세요.

Slack 웹후크 URL을 회전하려면:

- Slack에 로그인하고 <https://api.slack.com/apps>에 액세스합니다.
- 식별된 웹후크 URL을 사용하여 애플리케이션을 찾고 이름을 선택합니다.
- 왼쪽 메뉴에서 "수신 웹후크"를 선택합니다.
- "웹후크 URL" 테이블에서 식별된 웹후크 URL 옆의 휴지통 아이콘을 선택합니다.
- 메시지가 표시되면 확인 대화 상자에서 "제거"를 선택합니다.

자세한 내용은 [Slack의 웹후크 설명서](https://api.slack.com/messaging/webhooks)를 참조하세요.
