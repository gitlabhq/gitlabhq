## 설명 {#description}

캐리지 리턴/라인 피드(CRLF) 문자를 삽입하여 악의적 사용자가 임의의 데이터를 HTTP 응답에 주입할 수 있습니다. HTTP 응답을 수정하여 공격자는 시스템의 다른 사용자에 대해 크로스 사이트 스크립팅 또는 캐시 중독 공격을 수행할 수 있습니다.

## 수정 {#remediation}

사용자 입력은 줄바꿈에 대한 검증 없이 HTTP 헤더 응답을 생성할 때 사용되어서는 안 됩니다. 여기에는 HTTP 리다이렉트를 위해 사용자가 제공한 URL이 포함됩니다.
