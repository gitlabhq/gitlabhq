## 설명 {#description}

응답 본문에 Mailgun 웹후크 서명 키의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 이 키는 Mailgun이 들어오는 모든 웹후크 메시지 페이로드에 서명하는 데 사용됩니다. 이 키에 액세스할 수 있는 악의적 행위자는 가짜 웹후크 이벤트에 서명하고 이를 서비스로 보내 유효성 검사를 통과하고 처리되도록 할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

HTTP 웹후크 서명 키를 회전하려면:

- Mailgun 계정에 로그인하고 <https://app.mailgun.com/>에서 대시보드에 액세스합니다.
- 우측 상단에서 계정 프로필을 선택하고 "API Security"를 선택합니다.
- "HTTP webhook signing key" 섹션에서 우측의 회전 화살표 아이콘을 선택합니다.
- 메시지가 표시되면 "Reset HTTP webhook signing key" 대화 상자에서 "Reset Key"를 선택합니다.

자세한 내용은 [Mailgun의 웹후크 문서](https://documentation.mailgun.com/docs/mailgun/user-manual/tracking-messages/#securing-webhooks)를 참조하세요.
