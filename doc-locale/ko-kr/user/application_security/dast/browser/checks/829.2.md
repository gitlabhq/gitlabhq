## 설명 {#description}

JavaScript 또는 CSS 소스 파일에서 유효하지 않은 [Sub-Resource Integrity(SRI)](https://developer.mozilla.org/en-US/docs/Web/Security/Subresource_Integrity) `integrity` 값 또는 누락된 `crossorigin` 값이 포함되어 있습니다. 이 스크립트 또는 링크를 조사하여 악의적으로 변조되지 않았는지 확인합니다. 확실하지 않으면 스크립트의 소유자에게 문의하거나 알려진 올바른 버전으로 교체합니다.

## 수정 {#remediation}

식별된 모든 리소스는 대상 애플리케이션과 동일한 도메인에서 제공되어야 합니다. 이것이 불가능한 경우 `script` 값을 구현하는 모든 `src` 태그 또는 `href` 값을 구현하는 `link` 태그에 Sub-Resource Integrity를 포함할 것을 강력히 권장합니다. SRI 무결성 값을 생성하려면 [SRI hash](https://www.srihash.org/) 도구를 사용하거나 다음 명령 중 하나를 실행합니다:

- `cat FILENAME.js | openssl dgst -sha384 -binary | openssl base64 -A`
- `shasum -b -a 384 FILENAME.js | awk '{ print $1 }' | xxd -r -p | base64`

이 도구의 출력은 추가 속성으로 추가되어야 하며, 특히 `integrity` 및 `crossorigin=anonymous` 또는 `crossorigin=use-credentials` 중 하나입니다. 유효한 SRI로 보호된 스크립트 태그의 예를 아래에서 확인할 수 있습니다:

```html
<script src="https://example.com/example-framework.js"
    integrity="sha384-oqVuAfXRKap7fdgcCY5uykM6+R9GqQ8K/uxy9rx7HNQlGYl1kPzQho1wx4JwY8wC"
    crossorigin="anonymous"></script>
```
