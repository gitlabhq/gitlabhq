## 설명 {#description}

응답 본문에는 Mailchimp API 키 패턴과 일치하는 콘텐츠가 포함되어 있습니다. API 키를 사용하여 이메일을 보내거나, 마케팅 캠페인을 생성 및 전송하거나, 고객 목록 및 이메일 주소에 액세스할 수 있습니다. 이 키에 액세스할 수 있는 악의적인 행위자는 제한 없이 Mailchimp에 대한 모든 API 요청을 수행할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

API 키를 취소하려면:

- <https://login.mailchimp.com/>에서 Mailchimp 계정에 로그인하세요.
- 프로필 아이콘을 선택한 후 프로필을 선택하세요.
- Extras 드롭다운 목록을 선택한 후 "API 키"를 선택하세요.
- 식별된 키를 찾아 "취소"를 선택하세요.
- 메시지가 표시되면 "REVOKE"를 입력하여 확인한 후 "API 키 취소" 대화 상자에서 "취소"를 선택하세요.

자세한 정보는 [Mailchimp의 API 키 보안 설명서](https://mailchimp.com/help/about-api-keys/#api+key+security)를 참조하세요.
