## 설명 {#description}

응답 본문에 Typeform 개인 액세스 토큰 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 개인 액세스 토큰은 Typeform API에 액세스하기 위한 것입니다. 할당된 범위와 권한에 따라, 이 토큰에 액세스할 수 있는 악의적인 행위자는 양식 데이터를 읽고, 업데이트하거나 삭제할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키와 관련된 보안 사건 처리에 대한 일반적인 지침은 GitLab 설명서의 [기밀 정보의 인터넷 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요. Typeform API 토큰을 다시 생성하려면: - Typeform 계정에 로그인하고 <https://admin.typeform.com/>로 이동합니다 - 우측 상단 모서리에서 프로필 사진을 선택하고 "계정" 아래에서 "설정"을 선택합니다 - 좌측 메뉴에서 "개인 토큰"을 선택합니다 - "토큰 이름" 테이블에서 식별된 토큰을 찾고, 줄임표를 선택하고, "토큰 다시 생성"을 선택합니다 자세한 내용은 [Typeform의 개인 액세스 토큰 설명서](https://www.typeform.com/developers/get-started/personal-access-token/)를 참조하세요.
