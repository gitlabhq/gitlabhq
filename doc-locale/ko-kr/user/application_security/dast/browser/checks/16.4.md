## 설명 {#description}

대상 웹 사이트는 내부/숨겨진 IP 주소 또는 호스트 이름을 포함할 수 있는 `X-Backend-Server` 헤더를 반환합니다. 이러한 값을 노출하면 공격자가 보안 프록시를 우회하고 이러한 호스트에 직접 액세스할 수 있습니다.

## 수정 {#remediation}

`X-Backend-Server` 헤더 값 노출을 비활성화하는 방법에 대해 프록시/로드 밸런서 설명서 또는 공급자에 문의하세요.
