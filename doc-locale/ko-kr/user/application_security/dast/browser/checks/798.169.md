## 설명 {#description}

응답 본문에 Segment 공개 API 토큰 패턴과 일치하는 콘텐츠가 포함되어 있습니다. Segment 공개 API는 Segment 워크스페이스와 관련 리소스를 관리하는 데 사용됩니다. 이 패턴과 일치하는 두 가지 유형의 토큰이 있습니다: 워크스페이스 소유자 토큰과 제한된 역할 토큰입니다. 일반적으로 이러한 토큰을 사용하면 API 호출자가 읽기, 쓰기 및 삭제 작업을 수행할 수 있습니다. 워크스페이스 소유자 토큰에 액세스할 수 있는 악의적인 행위자는 모든 워크스페이스 데이터에 액세스할 수 있습니다. 제한된 역할 토큰은 생성 시에 액세스 권한을 부여받은 데이터에만 액세스할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰에서 부여한 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키 처리에 관한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

공개 API 토큰을 회전하려면:

- Segment 계정에 로그인하고 <https://app.segment.com/>에서 워크스페이스에 액세스합니다.
- 왼쪽 메뉴에서 "설정"을 선택하고 "워크스페이스 설정"으로 이동합니다.
- "워크스페이스 설정" 페이지에서 "액세스 관리" 탭을 선택합니다.
- "액세스 관리" 아래의 "토큰" 탭을 선택합니다.
- 식별된 키를 찾아 선택합니다.
- 오른쪽에서 "토큰 권한" 섹션의 "토큰 편집"을 선택합니다.
- 오른쪽 위 모서리에서 "토큰 제거"를 선택합니다.
- 메시지가 표시되면 대화 상자에서 "토큰 제거"를 선택합니다.

자세한 내용은 [Segment의 공개 API 설명서](https://segment.com/docs/api/public-api/)를 참조하세요.
