## 설명 {#description}

응답 본문에 PKCS8 개인 키 패턴과 일치하는 콘텐츠가 포함되어 있습니다. PKCS #8은 개인 키 정보를 저장하기 위한 표준 구문입니다. 악의적인 사용자가 이 키에 접근하면 과거 및 향후의 모든 메시지를 암호화하고 해독할 수 있습니다. 이 키를 사용하여 암호화된 과거 메시지는 손상된 것으로 간주되어야 하며, 새로운 메시지는 신뢰할 수 없습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 접근할 수 있습니다.

## 수정 {#remediation}

유출된 키 처리에 관한 일반적인 보안 인시던트 대응 지침은 GitLab 설명서의 [인증 정보 인터넷 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요. PKCS8 키는 순환할 수 없으며, 새로운 키를 생성해야 합니다. 자세한 내용은 [openssl.org의 키 생성 예시 설명서](https://docs.openssl.org/3.4/man1/openssl-genpkey/#examples)를 참조하세요.
