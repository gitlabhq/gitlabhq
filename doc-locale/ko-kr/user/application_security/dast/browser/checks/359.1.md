## 설명 {#description}

대상 애플리케이션이 응답에서 신용카드 정보를 반환하는 것으로 발견되었습니다. 이러한 정보를 반환하는 조직은 업계 규정을 위반할 수 있으며 벌금을 부과받을 수 있습니다.

## 수정 {#remediation}

신용카드와 같은 PII는 절대 사용자에게 직접 반환되어서는 안 됩니다. 식별자의 마지막 몇 자리 또는 문자를 제외한 대부분의 정보는 마스킹되어야 합니다. 예를 들어, 신용카드 번호는 마지막 네 자리만 반환해야 합니다: `****-****-****-1234`. 이 마스킹이 서버에서 수행되고 그 다음에만 마스킹된 데이터를 클라이언트로 다시 전송하세요. 데이터가 여전히 가로챌 수 있거나 마스킹이 해제될 수 있으므로 이러한 값을 마스킹하기 위해 클라이언트 측 JavaScript 또는 다른 방법에 의존하지 마세요.

또한 신용카드 정보는 절대 파일이나 데이터베이스에 암호화되지 않은 상태로 저장되어서는 안 됩니다.
