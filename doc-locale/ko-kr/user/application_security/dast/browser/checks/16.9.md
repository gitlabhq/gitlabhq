## 설명 {#description}

`Content-Security-Policy-Report-Only` (CSPRO)이 대상 사이트에서 식별되었습니다. CSP-Report-Only 헤더는 정상적인 사용을 방해하지 않는 `Content-Security-Policy`을 구현하는 방법을 결정하는 데 도움이 됩니다.

## 수정 {#remediation}

이 `Content-Security-Policy-Report-Only`을 강화하기 위해 필요한 작업이 있는지 결정하려면 권장 사항을 따르세요. 모든 알림이 해결된 후 이 헤더를 `Content-Security-Policy`로 변경합니다.
