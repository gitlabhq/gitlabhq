## 설명 {#description}

응답 본문에 CircleCI 개인 액세스 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 개인 액세스 토큰은 토큰을 생성한 사용자와 동일한 수준의 권한을 부여합니다. 이 토큰에 액세스할 수 있는 악의적인 행위자는 사용자를 가장할 수 있으며 CircleCI의 모든 기능과 서비스에 액세스할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키와 관련된 보안 사건 처리에 대한 일반적인 지침은 GitLab 설명서의 [인증 정보 인터넷 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

개인 액세스 토큰 교체:

- CircleCI 애플리케이션에서 사용자 설정으로 이동합니다.
- "Personal API Tokens"을(를) 선택합니다.
- 교체할 토큰의 Remove 열에서 "X"를 선택하고 삭제를 확인합니다. - "Create New Token"을(를) 선택합니다.
- Token name 필드에 교체 중인 이전 토큰의 새 이름을 입력합니다. 이전 토큰에 지정된 동일한 이름일 수 있습니다.
- "Add API Token"을(를) 선택합니다.
- 토큰이 표시되면 다른 위치에 복사하여 붙여넣습니다. 토큰을 다시 볼 수 없습니다.

자세한 내용은 해당 [개인 액세스 토큰 교체에 대한 설명서](https://circleci.com/docs/managing-api-tokens/#rotating-a-personal-api-token)를 참조하세요.
