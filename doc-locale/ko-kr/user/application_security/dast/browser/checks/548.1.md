## 설명 {#description}

대상 웹 서버는 `index.html`과 같은 인덱스 파일이 포함되지 않은 디렉토리의 콘텐츠를 나열하도록 구성됩니다. 이로 인해 민감한 정보가 실수로 노출되거나 공격자가 파일 이름과 디렉토리의 구조 및 저장 방식에 대한 세부 정보를 얻을 수 있습니다.

## 수정 {#remediation}

디렉토리 인덱싱을 비활성화해야 합니다.

Apache: Apache 기반 웹 사이트의 경우 모든 `<Directory>` 정의에 `apache2.conf` 또는 `httpd.conf` 구성 파일에 `Options -Indexes`이(가) 구성되어 있는지 확인하세요.

NGINX: NGINX 기반 웹 사이트의 경우 모든 `location` 정의에 `nginx.conf` 파일에서 `autoindex off` 지시문이 설정되어 있는지 확인하세요.

IIS: IIS 기반 웹 사이트 버전 7.0 이상의 경우 `applicationHost.config` 또는 `Web.config` 파일에서 `<directoryBrowse enabled="false" />` 요소를 사용할 수 있습니다.

다른 모든 서버 유형의 경우 디렉토리 인덱싱을 비활성화하는 방법에 대해 제품 문서를 참조하세요.
