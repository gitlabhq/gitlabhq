## 설명 {#description}

응답 본문에는 GitLab SCIM 토큰 패턴과 일치하는 콘텐츠가 포함되어 있습니다. SCIM 토큰은 타사 ID 공급자(IdP)를 구성하는 데 사용됩니다. 이 토큰에 대한 액세스 권한이 있는 악의적 행위자는 IdP를 구성하고 사용자를 추가하여 GitLab 시스템에 액세스할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키와 관련된 보안 인시던트 처리에 대한 일반 지침은 [인터넷 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)에 대한 GitLab 문서를 참조하세요.

SCIM 토큰을 회전하려면:

- 관리자로 GitLab 계정에 로그인합니다
- 왼쪽 사이드바의 하단에서 Admin을 선택합니다
- "설정"을 선택한 다음 "일반"을 선택합니다
- SCIM 토큰 섹션을 확장하고 "SCIM 토큰 생성"을 선택합니다
- "Your SCIM token"에서 "reset it"을 선택하여 새 토큰을 생성합니다

자세한 내용은 [SCIM 구성에 대한 GitLab 문서](../../../../../administration/settings/scim_setup.md#configure-gitlab)를 참조하세요.
