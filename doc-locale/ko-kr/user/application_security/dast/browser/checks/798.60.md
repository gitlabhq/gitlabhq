## 설명 {#description}

응답 본문에는 HubSpot 비공개 앱 API 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 비공개 앱을 사용하면 HubSpot의 API를 사용하여 HubSpot 계정에서 특정 데이터에 액세스할 수 있으며 특정 범위를 설정하여 제한할 수 있습니다. 이 토큰에 액세스할 수 있는 악의적인 행위자는 애플리케이션의 범위에 설정된 것과 동일한 수준의 API 엔드포인트를 호출할 수 있습니다. 마케팅 캠페인만 읽는 것부터 사용자 및 계정 정보에 액세스하고 이메일을 전송하는 것까지 어디서나 가능합니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

비공개 앱 API 토큰을 회전하려면:

- HubSpot 계정에 <https://app.hubspot.com/>로 로그인하세요.
- 왼쪽 메뉴에서 데이터베이스 아이콘 위에 마우스를 올린 후 "통합"을 선택하세요.
- 식별된 토큰이 있는 비공개 앱을 찾아 이름을 선택하세요.
- 페이지 상단의 "Auth" 탭을 선택하세요.
- 페이지의 "Access token" 섹션에서 "Rotate"를 선택하세요.
- 메시지가 표시되면 "Rotate and expire this token now"를 선택하세요.
- "Rotate access token now?" 대화 상자에서 "Rotate now"를 선택하세요.

자세한 내용은 [HubSpot's documentation on private apps](https://developers.hubspot.com/beta-docs/guides/apps/private-apps/overview)를 참조하세요.
