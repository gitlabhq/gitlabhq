## 설명 {#description}

응답 본문에 사용 중단된 GitLab 러너 등록 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 이 토큰을 사용하면 사용자가 선택한 프로젝트에 러너를 등록할 수 있습니다. 이 토큰에 액세스할 수 있는 악의적 사용자는 파이프라인에 사용자 지정 러너를 추가하고 러너를 사용한 경우 리포지토리를 손상시킬 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키와 관련된 보안 사건 처리에 대한 일반적인 지침은 GitLab 문서의 [인증 정보 인터넷 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참고하세요.

러너 등록 토큰을 회전하려면:

- GitLab 계정에 로그인하고 러너 등록 토큰을 생성한 프로젝트를 방문합니다.
- 왼쪽 메뉴에서 "설정"을 선택합니다.
- "설정" 옵션에서 "CI/CD"를 선택합니다.
- "러너" 섹션에서 "새 프로젝트 러너" 옆의 케밥 메뉴(세로 줄임표)를 선택합니다.
- 드롭다운 목록에서 "등록 토큰 재설정"을 선택합니다.
- 메시지가 표시되면 "등록 토큰 재설정" 대화상자에서 "토큰 재설정"을 선택합니다.

자세한 내용은 [GitLab 러너 인증 토큰 사용에 대한 GitLab 문서](https://docs.gitlab.com/runner/register/#register-with-a-runner-authentication-token)를 참고하세요.
