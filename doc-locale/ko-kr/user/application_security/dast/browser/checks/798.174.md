## 설명 {#description}

응답 본문에 SSH 개인 키의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. SSH 개인 키는 인증 및 대칭 키 교환에 사용됩니다. 악의적인 행위자가 이 키에 접근하면 이를 사용하여 애플리케이션 또는 서비스를 가장할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 접근할 수 있습니다.

## 수정 {#remediation}

유출된 키와 관련된 보안 사건 처리에 대한 일반적인 지침을 보려면 [인터넷에 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)에 대한 GitLab 문서를 참조하세요.

새로운 ECDSA 키를 생성하려면 `ssh-keygen` 도구를 사용합니다:

```shell
ssh-keygen -t ecdsa
```

SSH의 최신 버전은 `-----BEGIN OPENSSH PRIVATE KEY-----` 대신 `-----BEGIN EC PRIVATE KEY-----`를 출력할 수 있습니다

자세한 내용은 [`ssh-keygen` 문서](https://linux.die.net/man/1/ssh-keygen)를 참조하세요.
