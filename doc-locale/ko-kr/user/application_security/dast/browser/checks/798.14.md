## 설명 {#description}

응답 본문에는 Bitbucket 클라이언트 비밀의 패턴과 일치하는 내용이 포함됩니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키 처리에 관한 일반적인 지침은 [인터넷에 대한 자격증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)에 대한 GitLab 문서를 참조하세요.
