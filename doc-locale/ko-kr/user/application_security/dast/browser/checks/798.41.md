## 설명 {#description}

응답 본문에는 Finicity 클라이언트 비밀의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련된 보안 사건 처리에 대한 일반적인 지침은 [인터넷에 노출된 자격 증명](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)에 대한 GitLab 설명서를 참조하세요.
