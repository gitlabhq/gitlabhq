## 설명 {#description}

응답 본문에 Mailgun 공개 확인 키의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 이러한 키는 더 이상 지원되지 않으므로 대신 v4 확인 서비스를 사용해야 합니다. 이 키에 액세스할 수 있는 악의적인 사용자가 이를 사용하여 이메일 주소의 유효성을 검사할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있게 될 수 있습니다.

## 수정 {#remediation}

유출된 키 처리에 관한 일반적인 지침은 GitLab 문서의 [기밀 정보 인터넷 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

공개 확인 키를 순환하려면:

- Mailgun 계정에 로그인하고 <https://app.mailgun.com/>에서 대시보드에 액세스합니다.
- 우측 상단에서 계정 프로필을 선택하고 "API Security"를 선택합니다.
- "Verification public key" 섹션에서 우측의 회전 화살표 아이콘을 선택합니다.
- 메시지가 표시되면 "Reset public verification key" 대화상자에서 "Reset Key"를 선택합니다.

자세한 내용은 [Mailgun의 API 키 문서](https://mailchimp.com/help/about-api-keys)를 참조하세요.
