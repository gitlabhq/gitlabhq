## 설명 {#description}

대상 애플리케이션은 HTTP를 통한 Digest Authentication 방식을 사용하여 사용자를 인증하도록 설계되었습니다. Digest Authentication는 보안이 안전하지 않은 해싱 알고리즘(MD5)을 사용하여 사용자명과 비밀번호를 해시하고 `Authentication` 헤더에서 이를 전송합니다. 클라이언트와 서버 간의 통신 경로(또는 동일한 로컬 네트워크)에 있는 공격자는 패킷 스니퍼를 사용하여 서버의 응답 매개변수를 수정하고 Digest Access 인증 모드의 보안을 낮출 수 있습니다. 또한 서버는 일반적으로 `.htpasswd`라는 파일에 해시된 자격 증명을 저장합니다. 이러한 비밀번호를 크래킹할 수 있는 도구들이 쉽게 이용 가능합니다.

## 수정 {#remediation}

가능하면 OAuth 2.0과 같이 사용자를 인증하는 더욱 강력한 방법으로 전환하거나, Argon2id 알고리즘으로 보호된 데이터 저장소에 사용자명과 비밀번호를 저장하세요. Digest Authentication을 반드시 사용해야 하는 경우, 자격 증명이 HTTPS/TLS과 같은 보안 채널을 통해서만 전송되도록 하세요.
