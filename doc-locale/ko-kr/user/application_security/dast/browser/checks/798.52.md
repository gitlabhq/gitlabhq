## 설명 {#description}

응답 본문에는 GitHub 개인 액세스 토큰(클래식)의 패턴과 일치하는 콘텐츠가 있습니다. 개인 액세스 토큰을 사용하면 토큰을 만든 사용자로 GitHub 서비스에 액세스할 수 있습니다. 대부분의 경우 이러한 토큰은 모든 리포지토리에 대한 읽기-쓰기 액세스 권한을 부여받습니다. 악의적인 행위자가 이 토큰에 액세스할 경우 토큰의 지정된 권한으로 사용자를 대신하여 기능을 실행할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키와 관련된 보안 사건 처리에 대한 일반적인 지침은 [인터넷에 대한 자격증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)에 대한 GitLab 설명서를 참조하세요.

개인 액세스 토큰을 다시 생성하려면:

- GitHub 계정에 로그인하고 <https://github.com/settings/tokens>에 액세스합니다.
- 식별된 토큰을 찾고 이름을 선택합니다.
- 페이지 상단에서 "토큰 다시 생성"을 선택합니다. 또는 페이지 하단에서 "이 토큰 삭제"를 선택하고 새로운 토큰을 만들 수 있습니다. 이 작업을 수행하기 전에 설정된 범위와 권한을 기록해 두세요.

자세한 내용은 [개인 액세스 토큰에 대한 GitHub 설명서](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens)를 참조하세요.
