## 설명 {#description}

`X-Content-Type-Options` 헤더의 `nosniff` 값은 사용자 에이전트가 수신된 데이터의 형식을 추측하지 않도록 보장합니다. 브라우저와 같은 사용자 에이전트는 MIME 유형 스니핑이라는 프로세스를 통해 요청되는 리소스 유형을 추측하려고 시도합니다.

이 헤더를 전송하지 않으면 브라우저가 데이터를 잘못 해석하여 MIME 혼동 공격으로 이어질 수 있습니다. 공격자가 브라우저를 사용하여 액세스할 수 있는 파일을 업로드할 수 있다면 HTML로 해석될 수 있는 파일을 업로드하여 교차 사이트 스크립팅(XSS) 공격을 실행할 수 있습니다.

## 수정 {#remediation}

`X-Content-Type-Options: nosniff` 헤더와 값을 서버 전체에서 설정하는 것을 권장합니다. 이렇게 하면 실수로 누락된 `Content-Type` 값이 있는 모든 리소스가 잘못 해석되지 않습니다.
