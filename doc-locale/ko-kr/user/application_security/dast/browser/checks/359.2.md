## 설명 {#description}

대상 애플리케이션이 주민등록번호(SSN) 정보를 응답으로 반환하는 것으로 확인되었습니다. 이러한 정보를 반환하는 조직은 미국의 주(state) 또는 연방법을 위반할 수 있으며 엄격한 처벌에 직면할 수 있습니다.

## 수정 {#remediation}

사용자에게 주민등록번호와 같은 개인 정보는 절대 직접 반환되어서는 안 됩니다. 식별자의 마지막 몇 자리 또는 문자를 제외한 대부분의 정보는 마스킹되어야 합니다. 예를 들어 주민등록번호는 마지막 네 자리만 표시해야 합니다: `***-**-1234`. 이 마스킹이 서버에서 수행되고 마스킹된 데이터만 클라이언트로 다시 전송되는지 확인합니다. 데이터가 여전히 가로챌 수 있거나 마스크 해제될 수 있으므로 클라이언트 측 JavaScript 또는 다른 방법에 의존하여 이러한 값을 마스킹하지 않습니다.

또한 주민등록번호는 파일이나 데이터베이스에 암호화되지 않은 상태로 저장되어서는 안 됩니다.
