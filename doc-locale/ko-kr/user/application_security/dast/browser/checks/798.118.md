## 설명 {#description}

응답 본문에는 Twitch OAuth 클라이언트 시크릿의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. OAuth 클라이언트 시크릿은 서비스가 Twitch 사용자를 대신하여 기능을 실행할 수 있도록 하는 데 사용됩니다. 이 클라이언트 시크릿에 액세스할 수 있는 악의적인 행위자는 서비스를 가장하고 사용자를 대신하여 기능을 실행할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키 관리에 관한 일반적인 지침은 GitLab 설명서의 [기밀 정보 인터넷 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

OAuth 클라이언트 시크릿을 로테이션하려면:

- Twitch 계정에 로그인하고 <https://dev.twitch.tv/console>에 액세스하세요
- 식별된 키를 사용하는 확장을 찾습니다
- "Extensions" 섹션에서 확장 이름 옆의 "Manage"를 선택합니다
- 오른쪽 위 모서리에서 "Extension Settings"를 선택합니다
- "Twitch API Client Configuration" 섹션에서 "Twitch API Client Secret" 아래의 "Generate Secret"을 선택합니다
- 메시지가 나타나면 대화상자에서 "OK"를 선택합니다

자세한 내용은 [Twitch 개발자 설명서(OAuth)](https://dev.twitch.tv/docs/authentication/getting-tokens-oauth/#authorization-code-grant-flow)를 참조하세요.
