## 설명 {#description}

대상 웹사이트는 이 웹사이트의 버전 정보와 함께 AspNet 헤더를 반환합니다. 이러한 값을 노출하면 공격자는 대상 소프트웨어가 알려진 취약성에 취약한지 여부를 확인하려고 시도할 수 있습니다. 또는 특정 버전에서 취약성이 확인되었을 때 향후 악용할 수 있도록 특정 버전을 실행하는 알려진 사이트를 기록합니다.

## 수정 {#remediation}

`X-AspNetMvc-Version` 정보를 제거하려면 `Global.asax.cs` 파일의 `Application_Start()` 메서드에서 `MvcHandler.DisableMvcResponseHeader = true;`를 설정합니다.

```csharp
protected void Application_Start()
{
    MvcHandler.DisableMvcResponseHeader = true;
}
```
