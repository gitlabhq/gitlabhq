## 설명 {#description}

애플리케이션은 공격자가 내부 및 외부 리소스에 대한 권한 없는 요청을 할 수 있게 하는 높은 위험도의 취약성인 서버 측 요청 위조(SSRF)에 노출되어 있습니다. 사용자 제어 입력값이 리소스에 대한 요청에서 사용되기 전에 제대로 검증되거나 정제되지 않을 때 이 취약성이 발생하며, 공격자는 이러한 요청을 악의적 목적으로 조작할 수 있습니다.

## 수정 {#remediation}

요청을 구성하기 위해 사용자가 제공한 데이터를 사용하지 않도록 하세요. 이에 대한 비즈니스 필요성이 있다면 허용 목록 접근 방식을 검토하거나 방화벽 규칙 또는 SSRF 방지 기능이 있는 강력한 요청 라이브러리를 사용하여 내부 리소스에 대한 요청을 차단하는 것을 고려하세요.
