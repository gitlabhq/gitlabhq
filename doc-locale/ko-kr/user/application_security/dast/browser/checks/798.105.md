## 설명 {#description}

응답 본문에는 Shopify 개인 액세스 토큰 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 액세스 토큰에는 제한된 범위가 지정되거나 모든 저장소 데이터에 대한 전체 액세스 권한이 부여될 수 있습니다. 이 토큰에 액세스 권한을 얻은 악의적인 행위자는 저장소 데이터를 읽거나 수정할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요. 액세스 토큰은 취소할 수 없으므로 애플리케이션을 제거했다가 다시 설치해야 합니다. [자세한 내용은 Shopify 설명서를 참조하세요](https://shopify.dev/docs/apps/build/authentication-authorization/access-tokens/generate-app-access-tokens-admin#rotating-api-credentials-for-admin-created-apps).
