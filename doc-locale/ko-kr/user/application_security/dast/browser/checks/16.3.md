## 설명 {#description}

대상 웹사이트는 `X-Powered-By` 헤더 및 이 웹사이트의 버전 정보를 반환합니다. 이러한 값을 노출하면 공격자는 대상 소프트웨어가 알려진 취약성에 취약한지 확인하거나, 특정 버전이 향후 발견될 때 악용할 특정 버전을 실행하는 알려진 사이트를 카탈로그할 수 있습니다.

## 수정 {#remediation}

`X-Powered-By` 헤더에서 버전 정보를 제거할 것을 권장합니다.

PHP: PHP 기반 웹사이트의 경우 `php.ini` 구성 파일에서 `expose_php` 옵션을 `off`로 설정합니다.

다른 모든 서버 유형의 경우 `X-Powered-By` 헤더에서 버전 정보를 삭제하는 방법에 대해 제품 설명서를 참고하세요.
