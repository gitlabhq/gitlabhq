## 설명 {#description}

응답 본문에는 PyPi 업로드 토큰의 패턴과 일치하는 내용이 포함되어 있습니다. 업로드 토큰은 Python 패키지 게시를 위한 패키지 업로드에 사용됩니다. 이 토큰에 액세스할 수 있는 악의적인 행위자는 잠재적으로 악의적인 아티팩트를 업로드할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요. PyPi 업로드 토큰 대신 OIDC Connect로 전환하는 것을 강력히 권장합니다. [PyPi의 신뢰할 수 있는 게시자 설명서](https://docs.pypi.org/trusted-publishers/)를 참조하세요.

PyPi 업로드 토큰을 삭제하려면:

- PyPi 계정에 로그인하고 <https://pypi.org/manage/account/>을 방문하세요.
- "API 토큰" 섹션으로 스크롤합니다.
- 식별된 토큰을 찾고 "옵션" 드롭다운 목록을 선택합니다.
- "토큰 제거"를 선택합니다.
- 메시지가 표시되면 암호를 입력하고 "API 토큰 제거"를 선택합니다.

자세한 내용은 [PyPi의 업로드 토큰 설명서](https://pypi.org/help/#apitoken)를 참조하세요.
