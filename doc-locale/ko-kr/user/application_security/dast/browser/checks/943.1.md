## 설명 {#description}

애플리케이션이 MongoDB와 상호작용하기 위해 쿼리를 생성하지만, 쿼리의 의도된 로직을 수정할 수 있는 특수 요소를 중립화하지 않거나 잘못 중립화합니다.

## 수정 {#remediation}

find 또는 search 쿼리를 리팩터링하여 `$gt` 또는 `$in`와 같은 표준 필터링 연산자를 `$where`와 같은 광범위 연산자 대신 사용합니다. 가능하면 MongoDB JavaScript 인터페이스를 완전히 비활성화합니다.
