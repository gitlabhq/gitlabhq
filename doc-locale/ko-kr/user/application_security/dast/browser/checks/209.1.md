## 설명 {#description}

애플리케이션이 스택 추적과 같은 오류 데이터를 반환하는 것으로 발견되었습니다. 오류 메시지에 포함된 데이터에 따라 이 정보는 공격자가 추가 공격을 수행하는 데 사용될 수 있습니다. 스택 추적은 개발 및 디버깅 중에 도움이 되지만, 오류가 발생할 때 사용자에게 표시되어서는 안 됩니다.

## 수정 {#remediation}

애플리케이션은 예외 조건을 내부적으로 처리하고 사용자에게 표시할 수 있는 오류 코드에 알려진 오류 유형을 매핑해야 합니다. 이러한 오류 코드는 애플리케이션에 맞게 사용자 지정되어야 하며 관련 HTTP 오류 코드와 함께 반환되어야 합니다.

오류가 발생하면 애플리케이션이 오류 유형이나 클래스를 식별하고 사용자에게 숫자 값을 표시합니다. 사용자에게 오류 코드가 표시되었을 때 대응하는 요청 ID를 가지도록 요청을 추적해야 합니다. 지원 팀은 최종 사용자에게 세부 정보를 유출하지 않고 로그 파일에서 HTTP 오류, 사용자 지정 오류 코드 및 요청 ID를 상호 연관시켜 오류의 근본 원인을 파악할 수 있습니다.

사용자 지정 오류 반환 예시:

```plaintext
HTTP/1.1 500 Internal Server Error
...
Error [0004] Occurred, please contact support or re-try your request again shortly.
Request ID [a4bc91def12]
...
```
