## 설명 {#description}

응답 본문에 Lob 게시 가능 API 키 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 게시 가능 API 키는 미국 검증, 국제 검증 및 미국 자동 완성 요청에만 사용됩니다. 이 키에 액세스할 수 있는 악의적인 행위자는 계정에서 제한된 기능을 실행할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키 처리와 관련된 보안 사건 대응에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 노출된 자격 증명](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

게시 가능 API 키를 회전하려면:

- 계정에 로그인하여 <https://dashboard.lob.com/>로 이동합니다.
- 왼쪽 하단 모서리에서 기어 아이콘 / "설정" 메뉴 옵션을 선택합니다.
- "설정"에서 "API 키" 탭을 선택합니다.
- "게시 가능 API 키" 섹션에서 키가 라이브 환경 키인지 테스트 환경 키인지 확인합니다.
- 식별된 키의 회전 화살표 아이콘을 선택합니다.
- 메시지가 표시되면 "게시 가능 API 키 회전" 대화상자에서 "예"를 선택합니다.

자세한 내용은 [Lob의 API 키 설명서](https://docs.lob.com/#tag/Authentication/API-Keys)를 참조하세요.
