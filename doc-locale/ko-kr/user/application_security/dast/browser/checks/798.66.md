## 설명 {#description}

응답 본문에는 Linear API 토큰 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 개인 API 토큰은 Linear의 GraphQL API에 액세스하는 데 사용할 수 있습니다. 악의적인 행위자가 이 토큰에 액세스하면 Linear 및 계정이 통합된 모든 시스템의 이슈, 프로젝트 및 팀을 읽거나 쓸 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

Linear API 토큰을 폐지하려면:

- <https://linear.app/>에서 계정에 로그인합니다.
- 왼쪽 위 모서리에서 조직을 선택하고 "Preferences"를 선택합니다.
- 왼쪽 메뉴에서 "My Account" 아래의 "API"를 선택합니다.
- 페이지의 "Personal API Keys" 섹션에서 식별된 API 키를 찾습니다.
- 식별된 키 옆의 "Revoke"를 선택합니다.
- 메시지가 표시되면 "Revoke access?" 대화 상자에서 "Revoke"를 선택합니다.

자세한 내용은 [개인 API 키 사용에 관한 Linear 설명서](https://developers.linear.app/docs/graphql/working-with-the-graphql-api#personal-api-keys)를 참조하세요.
