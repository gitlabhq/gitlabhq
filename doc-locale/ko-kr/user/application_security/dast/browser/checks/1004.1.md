## 설명 {#description}

쿠키는 `Set-Cookie` 헤더에서 `HttpOnly` 속성이 설정되지 않은 상태로 전송되었습니다. JavaScript가 쿠키 값에 액세스하지 못하도록 방지하려면 - 보통 `document.cookies`을(를) 통해 액세스됨 - 인증에 사용되는 모든 쿠키는 `HttpOnly` 속성이 설정되어야 합니다.

## 수정 {#remediation}

대부분의 웹 애플리케이션 프레임워크에서는 쿠키가 사용자 에이전트에 전송되는 방식을 구성할 수 있습니다. 클라이언트에 쿠키를 할당할 때 다양한 보안 지시문을 활성화하는 방법에 대한 자세한 내용은 프레임워크 설명서를 참조하세요.

애플리케이션이 응답 헤더에 직접 쓰기를 통해 쿠키를 할당하는 경우, 모든 응답이 `HttpOnly` 속성을 포함하도록 하세요. 이 보호를 활성화하면 애플리케이션이 특정 교차 사이트 스크립팅(XSS) 공격의 영향을 완화할 수 있습니다.

예:

```http
Set-Cookie: {cookie_name}=<random secure value>; HttpOnly
```
