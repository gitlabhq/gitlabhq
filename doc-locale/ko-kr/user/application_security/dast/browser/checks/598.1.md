## 설명 {#description}

요청 URL과 쿠키 값에서 세션 ID가 확인되었습니다. 세션 ID는 프록시 시스템에 의해 캡처되거나 브라우저 히스토리에 저장되거나 로그 파일에 저장될 수 있으므로 GET 요청으로 전송해서는 안 됩니다. 공격자가 세션 ID에 대한 액세스를 얻으면 잠재적으로 대상 계정에 액세스할 수 있습니다.

## 수정 {#remediation}

요청 헤더는 타사 시스템에서 거의 기록되거나 캡처되지 않으므로 세션 ID 값이 쿠키에만 전송되도록 하고(`Set-Cookie` 응답 헤더를 통해 할당됨) 요청 URL에는 절대 전송되지 않도록 하세요.
