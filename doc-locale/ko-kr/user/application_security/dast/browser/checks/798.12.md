## 설명 {#description}

응답 본문에 AWS 액세스 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. AWS 액세스 토큰은 일반적으로 비밀 키 값과 함께 쌍을 이룹니다. 이 토큰에 액세스할 수 있는 악의적 행위자는 키를 생성한 사용자와 동일한 권한으로 AWS 서비스에 액세스할 수 있으며, 두 값 모두에 액세스할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

누출된 키와 관련하여 보안 사건을 처리하는 방법에 대한 일반적인 지침은 GitLab 설명서의 [인터넷에 대한 자격 증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요. 액세스 키를 삭제하려면: - "액세스 키" 섹션에서 식별된 키를 찾습니다 - "작업"을 선택합니다 - "삭제"를 선택합니다 - 대화 상자의 지침에 따라 먼저 비활성화한 다음 삭제를 확인합니다 AWS에서 액세스 키를 관리하고 취소하는 방법에 대한 자세한 내용은 [설명서](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_credentials_access-keys.html#Using_CreateAccessKey)를 참조하세요.
