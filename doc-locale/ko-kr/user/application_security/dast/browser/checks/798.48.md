## 설명 {#description}

응답 본문에는 Frame.io API 토큰의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. Frame.io는 범위가 지정된 API 토큰을 통해 외부 액세스를 지원합니다. 토큰은 개별 사용자 계정과 연결되며, 토큰을 만든 사용자와 동일한 액세스 권한을 갖습니다. Frame.io의 모든 API 작업은 범위에 따라 제한됩니다. 이 토큰에 액세스할 수 있는 악의적인 행위자는 토큰에 할당된 범위에 따라 다양한 기능을 실행할 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있게 될 수 있습니다.

## 수정 {#remediation}

유출된 키와 관련된 보안 사건 처리에 대한 일반적인 지침은 GitLab 설명서의 [기밀 정보의 인터넷 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을(를) 참조하세요.

API 토큰을 취소하려면:

- 로그인하고 <https://developer.frame.io/app/tokens>에 액세스합니다
- 식별된 토큰을 찾고 할당된 범위를 기록합니다
- 식별된 토큰의 오른쪽에 있는 휴지통 아이콘을 선택합니다
- "토큰 삭제?" 메시지가 표시되면 "삭제"를 선택합니다

자세한 내용은 [Frame.io의 인증 설명서](https://developer.frame.io/docs/getting-started/authentication)를 참조하세요.
