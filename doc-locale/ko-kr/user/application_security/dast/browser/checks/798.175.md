## 설명 {#description}

응답 본문에 Stripe 라이브 제한 키의 패턴과 일치하는 콘텐츠가 포함되어 있습니다. 제한 키는 특정 API 리소스에 대한 읽기 또는 쓰기 액세스만 허용하여 더 큰 보안을 제공합니다. 이 키에 액세스할 수 있는 악의적인 행위자는 키에 정의된 범위로 제한됩니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키 처리에 관한 일반적인 지침은 [인터넷에 대한 자격증명 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)에 대한 GitLab 설명서를 참조하세요.

Stripe 라이브 제한 키를 로테이션하려면:

- Stripe 계정에 로그인하고 <https://dashboard.stripe.com/apikeys>에 액세스하세요.
- "테스트 모드"가 비활성화되어 있는지 확인하세요.
- "제한 키" 섹션에서 식별된 키를 찾아 오른쪽의 줄임표를 선택하세요.
- "키 롤링..."을 선택하세요.
- "API 키 롤링" 대화 상자에서 만료 날짜(예: "지금")를 선택하세요.
- "API 키 롤링"을 선택하세요.

자세한 내용은 [API 키 로테이션에 대한 Stripe 설명서](https://docs.stripe.com/keys#rolling-keys)를 참조하세요.
