## 설명 {#description}

쿠키가 `Set-Cookie` 응답에서 `Secure` 속성 없이 전송되었습니다. 민감한 쿠키 값이 실수로 평문 HTTP를 통해 전송되는 것을 방지하려면 `Secure` 속성으로 쿠키를 선언하세요.

## 수정 {#remediation}

대부분의 웹 애플리케이션 프레임워크는 쿠키를 사용자 에이전트에 보내는 방법을 구성할 수 있습니다. 클라이언트에 쿠키를 할당할 때 다양한 보안 속성을 활성화하는 방법에 대한 자세한 내용은 프레임워크의 설명서를 참조하세요.

응용 프로그램이 응답 헤더에 직접 쓰기를 통해 쿠키를 할당하는 경우 모든 응답이 `Secure` 속성을 포함하는지 확인하세요. 이 보호를 활성화하면 응용 프로그램이 더 이상 HTTP를 통해 민감한 쿠키를 보내지 않습니다.

예:

```http
Set-Cookie: {cookie_name}=<random secure value>; Secure
```
