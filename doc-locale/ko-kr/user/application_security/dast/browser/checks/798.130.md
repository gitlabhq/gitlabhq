## 설명 {#description}

응답 본문에 Anthropic API 키의 패턴과 일치하는 콘텐츠가 포함되어 있음이 감지되었습니다. Anthropic 키는 생성형 AI 서비스에 액세스하는 데 사용됩니다. 악의적인 행위자는 이러한 키를 사용하여 계정에 과도한 요금을 발생시킬 수 있습니다. 이 값을 노출하면 공격자가 이 토큰으로 부여된 모든 리소스에 액세스할 수 있습니다.

## 수정 {#remediation}

유출된 키 처리에 관한 보안 사고 처리 지침은 GitLab 설명서의 [기밀 정보 노출](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)을 참조하세요.

유출된 Anthropic 키를 수정하려면 조직의 API 키 목록에서 삭제해야 합니다.

- [Anthropic 계정](https://console.anthropic.com/)에 로그인합니다.
- 프로필 아이콘을 선택한 후 "API 키"를 선택하거나 설정 탭을 통해 "API 설정"으로 이동합니다.
- 유출된 API 키를 식별하고 삭제하려는 키 옆의 미트볼 메뉴(가로 세 개의 점)를 선택합니다.
- "API 키 삭제"를 선택합니다.
- 참고: API 키 삭제는 영구적인 작업이며 실행 취소할 수 없습니다.
- "키 생성"을 선택하여 새 키를 생성하고 설명이 포함된 이름을 지정합니다.

자세한 내용은 Anthropic 웹사이트 <https://support.anthropic.com/en/articles/8384961-what-should-i-do-if-i-suspect-my-api-key-has-been-compromised>을(를) 참조하세요.
