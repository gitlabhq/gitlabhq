이러한 CI/CD 변수는 브라우저 기반 DAST 분석기에만 적용됩니다. 이러한 변수를 사용하여 DAST의 동작을 요구 사항에 맞게 커스터마이징할 수 있습니다.

## 스캐너 동작 {#scanner-behavior}

이러한 변수는 스캔이 어떻게 수행되는지와 결과가 어디에 저장되는지를 제어합니다.

| CI/CD 변수 | 형식 | 예제 | 설명 |
| :------------- | :--- | ------- | :---------- |
| `DAST_CHECKS_TO_EXCLUDE` | 문자열 | `552.2,78.1` | 스캔에서 제외할 검사 식별자의 쉼표로 구분된 목록입니다. 식별자는 [취약성 검사](../checks/_index.md)를 참조하세요. |
| `DAST_CHECKS_TO_RUN` | 문자열 목록 | `16.1,16.2,16.3` | 스캔에 사용할 검사 식별자의 쉼표로 구분된 목록입니다. 식별자는 [취약성 검사](../checks/_index.md)를 참조하세요. |
| `DAST_CRAWL_GRAPH` | 부울 | `true` | `true`으로 설정하여 스캔의 크롤 단계 중에 방문한 탐색 경로의 SVG 그래프를 생성합니다. 생성된 그래프에 액세스하려면 `gl-dast-crawl-graph.svg`를 작업 아티팩트로도 정의해야 합니다. 기본값은 `false`입니다. |
| `DAST_FULL_SCAN` | 부울 | `true` | `true`으로 설정하여 수동 및 활동 검사를 모두 실행합니다. 기본값은 `false`입니다. |

| `DAST_LOG_CONFIG` | 문자열 목록 | `brows:debug,auth:debug` | (더 이상 사용되지 않음) 콘솔 로그에서 사용할 모듈 및 해당 의도된 로깅 수준의 목록입니다. |

| `DAST_LOG_FILE_CONFIG` | 문자열 목록 | `brows:debug,auth:debug` | 파일 로그에서 사용할 모듈 및 해당 의도된 로깅 수준의 목록입니다. |
| `DAST_LOG_FILE_PATH` | 문자열 | `/output/browserker.log` | 파일 로그의 경로로 설정합니다. 기본값은 `gl-dast-scan.log`입니다. |
| `SECURE_ANALYZERS_PREFIX` | URL | `registry.organization.com` | 분석기를 다운로드할 Docker 레지스트리 기본 주소를 설정합니다. |
| `SECURE_LOG_LEVEL` | 문자열 | `debug` | 파일 로그의 기본 수준을 설정합니다. [SECURE_LOG_LEVEL](../troubleshooting.md#secure_log_level)을 참조하세요. |

## 요소, 작업 및 시간 초과 {#elements-actions-and-timeouts}

이러한 변수는 스캐너에 특정 요소를 찾는 위치, 수행할 작업, 작업 완료를 기다리는 시간을 알립니다.

| CI/CD 변수 | 형식 | 예제 | 설명 |
| :------------- | :--- | ------- | :---------- |
| `DAST_ACTIVE_SCAN_TIMEOUT` | [기간 문자열](https://pkg.go.dev/time#ParseDuration) | `3h` | 스캔의 활동 스캔 단계 완료를 기다리는 최대 시간입니다. 기본값은 3시간입니다. |
| `DAST_ACTIVE_SCAN_WORKER_COUNT` | 숫자 | `3` | 병렬로 실행할 활동 검사의 수입니다. 기본값은 3입니다. |
| `DAST_CRAWL_MAX_ACTIONS` | 숫자 | `10000` | 크롤러가 수행하는 작업의 최대 수입니다. 예제 작업에는 링크 선택 또는 양식 채우기가 포함됩니다. 기본값은 `10000`입니다. |
| `DAST_CRAWL_MAX_DEPTH` | 숫자 | `10` | 크롤러가 수행하는 연결된 작업의 최대 수입니다. 예를 들어, `Click, Form Fill, Click`은 깊이 3입니다. 기본값은 `10`입니다. |
| `DAST_CRAWL_TIMEOUT` | [기간 문자열](https://pkg.go.dev/time#ParseDuration) | `5m` | 스캔의 크롤 단계 완료를 기다리는 최대 시간입니다. 기본값은 `24h`입니다. |
| `DAST_CRAWL_WORKER_COUNT` | 숫자 | `3` | 사용할 동시 브라우저 인스턴스의 최대 수입니다. GitLab.com의 인스턴스 러너의 경우 최대 3개를 권장합니다. 더 많은 리소스를 포함한 비공개 러너는 더 높은 수에서 이점을 얻을 수 있지만, 5~7개 인스턴스 이후로는 거의 이점을 제공할 가능성이 낮습니다. 기본값은 동적이며 사용 가능한 논리 CPU의 수와 같습니다. |
| `DAST_PAGE_DOM_READY_TIMEOUT` | [기간 문자열](https://pkg.go.dev/time#ParseDuration) | `7s` | 탐색이 완료된 후 브라우저가 페이지를 로드되었다고 판단하고 분석할 준비가 될 때까지 기다리는 최대 시간입니다. 기본값은 `6s`입니다. |
| `DAST_PAGE_DOM_STABLE_WAIT` | [기간 문자열](https://pkg.go.dev/time#ParseDuration) | `200ms` | 페이지가 안정적인지 확인하기 전에 DOM 업데이트를 기다리는 시간을 정의합니다. 기본값은 `500ms`입니다. |
| `DAST_PAGE_ELEMENT_READY_TIMEOUT` | [기간 문자열](https://pkg.go.dev/time#ParseDuration) | `600ms` | 요소가 분석할 준비가 되었다고 결정하기 전에 기다리는 최대 시간입니다. 기본값은 `300ms`입니다. |
| `DAST_PAGE_IS_LOADING_ELEMENT` | [선택자](authentication.md#finding-an-elements-selector) | `css:#page-is-loading` | 페이지에서 더 이상 표시되지 않을 때 분석기에 페이지 로드가 완료되었고 스캔을 계속할 수 있음을 나타내는 선택자입니다. `DAST_PAGE_IS_READY_ELEMENT`과 함께 사용할 수 없습니다. |
| `DAST_PAGE_IS_READY_ELEMENT` | [선택자](authentication.md#finding-an-elements-selector) | `css:#page-is-ready` | 페이지에서 표시되는 것으로 감지되었을 때 분석기에 페이지 로드가 완료되었고 스캔을 계속할 수 있음을 나타내는 선택자입니다. `DAST_PAGE_IS_LOADING_ELEMENT`과 함께 사용할 수 없습니다. |
| `DAST_PAGE_MAX_RESPONSE_SIZE_MB` | 숫자 | `15` | HTTP 응답 본문의 최대 크기입니다. 이보다 큰 본문의 응답은 브라우저에서 차단됩니다. 기본값은 `10` MB입니다. |
| `DAST_PAGE_READY_AFTER_ACTION_TIMEOUT` | [기간 문자열](https://pkg.go.dev/time#ParseDuration) | `7s` | 브라우저가 페이지를 로드되었다고 판단하고 분석할 준비가 될 때까지 기다리는 최대 시간입니다. 기본값은 `7s`입니다. |
| `DAST_PAGE_READY_AFTER_NAVIGATION_TIMEOUT` | [기간 문자열](https://pkg.go.dev/time#ParseDuration) | `15s` | 브라우저가 한 페이지에서 다른 페이지로 탐색할 때까지 기다리는 최대 시간입니다. 기본값은 `15s`입니다. |
| `DAST_PASSIVE_SCAN_WORKER_COUNT` | 정수 | `5` | 병렬로 수동 스캔을 수행하는 작업자의 수입니다. 기본값은 사용 가능한 CPU의 수입니다. |
| `DAST_PKCS12_CERTIFICATE_BASE64` | 문자열 | `ZGZkZ2p5NGd...` | 상호 TLS가 필요한 사이트에 사용되는 PKCS12 인증서입니다. Base64 텍스트로 인코딩해야 합니다. |
| `DAST_PKCS12_PASSWORD` | 문자열 | `password` | `DAST_PKCS12_CERTIFICATE_BASE64`에서 사용된 인증서의 암호입니다. GitLab UI를 사용하여 민감한 [사용자 지정 CI/CD 변수](../../../../../ci/variables/_index.md#define-a-cicd-variable-in-the-ui)를 생성합니다. |
| `DAST_REQUEST_ADVERTISE_SCAN` | 부울 | `true` | `true`으로 설정하여 `Via: GitLab DAST <version>` 헤더를 전송된 모든 요청에 추가하여 요청이 GitLab DAST 스캔의 일부로 전송되었음을 광고합니다. 기본값: `false`. |
| `DAST_REQUEST_COOKIES` | 사전 | `abtesting_group:3,region:locked` | 모든 요청에 추가할 쿠키 이름과 값입니다. |
| `DAST_REQUEST_HEADERS` | 문자열 | `Cache-control:no-cache` | 요청 헤더 이름과 값의 쉼표로 구분된 목록으로 설정합니다. 다음 헤더는 지원되지 않습니다: `content-length`, `cookie2`, `keep-alive`, `hosts`, `trailer`, `transfer-encoding` 및 `proxy-` 접두사가 있는 모든 헤더입니다. |
| `DAST_REQUEST_USER_AGENT` | 문자열 |  | 브라우저에서 전송된 사용자 에이전트 문자열을 변경하도록 설정합니다. 기본 사용자 에이전트는 Linux의 Google Chrome입니다. |
| `DAST_SCOPE_ALLOW_HOSTS` | 문자열 목록 | `site.com,another.com` | 이 변수에 포함된 호스트 이름은 크롤링할 때 범위 내에 있는 것으로 간주됩니다. 기본적으로 `DAST_TARGET_URL` 호스트 이름은 허용 호스트 목록에 포함됩니다. `DAST_REQUEST_HEADERS`를 사용하여 설정된 헤더는 이러한 호스트 이름에 대해 수행된 모든 요청에 추가됩니다. |
| `DAST_SCOPE_EXCLUDE_ELEMENTS` | [선택자](authentication.md#finding-an-elements-selector) | `a[href='2.html'],css:.no-follow` | 스캔할 때 무시되는 선택자의 쉼표로 구분된 목록입니다. |
| `DAST_SCOPE_EXCLUDE_HOSTS` | 문자열 목록 | `site.com,another.com` | 이 변수에 포함된 호스트 이름은 제외된 것으로 간주되며 연결이 강제로 끊어집니다. |
| `DAST_SCOPE_IGNORE_HOSTS` | 문자열 목록 | `site.com,another.com` | 이 변수에 포함된 호스트 이름에 액세스되지만 공격을 받지 않으며 보고되지 않습니다. |
| `DAST_TARGET_CHECK_SKIP` | 부울 | `true` | `true`으로 설정하여 DAST가 스캔 전에 대상을 사용할 수 있는지 확인하지 못하도록 합니다. 기본값: `false`. |
| `DAST_TARGET_CHECK_TIMEOUT` | 숫자 | `60` | 대상 가용성을 기다리는 시간 제한(초 단위)입니다. 기본값: `60s`. |
| `DAST_TARGET_PATHS_FILE` | 문자열 | `/builds/project/urls.txt` | 전체 사이트를 크롤링하는 대신 이러한 경로만 스캔합니다. `DAST_TARGET_URL`과 관련된 URL 경로 목록이 포함된 파일 경로로 설정합니다. 파일은 일반 텍스트이고 한 줄에 한 경로씩 있어야 합니다. 이것이 설정되면 `DAST_CRAWL_MAX_DEPTH`는 기본값이 1입니다. 이를 방지하려면 `DAST_OVERRIDE_MAX_DEPTH: false`을 설정합니다. |
| `DAST_TARGET_PATHS` | 문자열 | `/page1.html,/category1/page3.html` | 전체 사이트를 크롤링하는 대신 이러한 경로만 스캔합니다. `DAST_TARGET_URL`과 관련된 URL 경로의 쉼표로 구분된 목록으로 설정합니다. 이것이 설정되면 `DAST_CRAWL_MAX_DEPTH`는 기본값이 1입니다. 이를 방지하려면 `DAST_OVERRIDE_MAX_DEPTH: false`을 설정합니다. |
| `DAST_TARGET_URL` | URL | `https://site.com` | 스캔할 웹사이트의 URL입니다. |
| `DAST_USE_CACHE` | 부울 | `true` | `false`으로 설정하여 캐싱을 비활성화합니다. 기본값: `true`. **노트**: 캐시를 비활성화하면 OOM 이벤트 또는 DAST 작업 시간 초과가 발생할 수 있습니다. |
| `DAST_CRAWL_GROUPED_URLS` | 문자열 | `https://example.com/hello/*,https://example.com/world/*/details` | (실험) 최소 1개의 `*`이(가) 있는 와일드카드 URL 패턴의 쉼표로 구분된 목록으로 설정합니다. 스캔 시간을 줄이기 위해 스캐너는 패턴당 일치하는 URL 하나만 그룹화하고 분석합니다. |

### 인증 {#authentication}

이러한 변수는 스캐너에 애플리케이션으로 인증하는 방법을 알립니다.

| CI/CD 변수 | 형식 | 예제 | 설명 |
| :------------- | :--- | ------- | :---------- |
| `DAST_AUTH_AFTER_LOGIN_ACTIONS` | 문자열 | `select(option=id:accept-yes),click(on=css:.continue)` | 로그인 후 하지만 로그인 확인 전에 수행할 작업의 쉼표로 구분된 목록입니다. `click` 및 `select` 작업을 지원합니다. [로그인 양식 제출 후 추가 작업 수행](authentication.md#taking-additional-actions-after-submitting-the-login-form)을 참조하세요. |
| `DAST_AUTH_BEFORE_LOGIN_ACTIONS` | [선택자](authentication.md#finding-an-elements-selector) | `css:.user,id:show-login-form` | 로그인 양식에 DAST_AUTH_USERNAME 및 DAST_AUTH_PASSWORD를 입력하기 전에 클릭할 요소를 나타내는 선택자의 쉼표로 구분된 목록입니다. |
| `DAST_AUTH_CLEAR_INPUT_FIELDS` | 부울 | `true` | 수동 로그인을 시도하기 전에 사용자 이름 및 암호 필드의 지우기를 비활성화합니다. 기본값은 false입니다. |
| `DAST_AUTH_COOKIE_NAMES` | 문자열 | `sessionID,groupName` | 쿠키 이름의 쉼표로 구분된 목록으로 설정하여 인증에 사용되는 쿠키를 지정합니다. |
| `DAST_AUTH_FIRST_SUBMIT_FIELD` | [선택자](authentication.md#finding-an-elements-selector) | `css:input[type=submit]` | 다중 페이지 로그인 프로세스의 사용자 이름 양식을 제출하기 위해 클릭된 요소를 설명하는 선택자입니다. |
| `DAST_AUTH_NEGOTIATE_DELEGATION` | 문자열 | `*.example.com,example.com,*.EXAMPLE.COM,EXAMPLE.COM` | 통합 인증 및 위임을 위해 허용되어야 하는 서버입니다. 이 속성은 두 가지 Chromium 정책을 설정합니다: [AuthServerAllowlist](https://chromeenterprise.google/policies/#AuthServerAllowlist) 및 [AuthNegotiateDelegateAllowlist](https://chromeenterprise.google/policies/#AuthNegotiateDelegateAllowlist). GitLab 17.6에서 [도입](https://gitlab.com/gitlab-org/gitlab/-/issues/502476)되었습니다. |
| `DAST_AUTH_OTP_FIELD` | [선택자](authentication.md#finding-an-elements-selector) | `name:otp` | 로그인 양식에 일회용 암호를 입력하는 데 사용되는 요소를 설명하는 선택자입니다. |
| `DAST_AUTH_OTP_KEY` | 문자열 | `I5UXITDBMIQEIQKTKQFA====` | 웹사이트에 인증할 일회용 암호를 생성할 때 사용할 Base32로 인코딩된 비밀 키입니다. |
| `DAST_AUTH_OTP_SUBMIT_FIELD` | [선택자](authentication.md#finding-an-elements-selector) | `css:input[type=submit]` | 사용자 이름과 분리된 경우 OTP 양식을 제출하기 위해 클릭된 요소를 설명하는 선택자입니다. |
| `DAST_AUTH_PASSWORD` | 문자열 | `P@55w0rd!` | 웹사이트에 인증하기 위한 암호입니다. |
| `DAST_AUTH_PASSWORD_FIELD` | [선택자](authentication.md#finding-an-elements-selector) | `name:password` | 로그인 양식에 암호를 입력하는 데 사용되는 요소를 설명하는 선택자입니다. |

| `DAST_AUTH_SUCCESS_IF_ELEMENT_FOUND` | [선택자](authentication.md#finding-an-elements-selector) | `css:.user-avatar` | 로그인 양식이 제출된 후 인증이 성공했는지 확인하기 위해 존재 여부가 사용되는 요소를 설명하는 선택자입니다. |
| `DAST_AUTH_SUCCESS_IF_NO_LOGIN_FORM` | 부울 | `true` | 로그인 양식이 제출된 후 로그인 양식의 부재를 확인하여 성공적인 인증을 확인합니다. 이 성공 검사는 기본적으로 활성화됩니다. |

| `DAST_AUTH_REPORT` | 부울 | `true` | `true`으로 설정하여 인증 프로세스 중에 수행된 단계를 자세히 설명하는 보고서를 생성합니다. 생성된 보고서에 액세스하려면 `gl-dast-debug-auth-report.html`를 작업 아티팩트로도 정의해야 합니다. 보고서의 내용은 인증 실패를 디버깅할 때 도움이 됩니다. 기본값은 `false`입니다. |
