{{< history >}}

- [GitLab 18.5에서 도입됨](https://gitlab.com/gitlab-org/gitlab/-/issues/549914) [기능 플래그](../../../administration/feature_flags/_index.md) 이름은 `global_ai_catalog`입니다. GitLab.com에서 활성화됨.
- 그룹에서 사용 가능하도록 설정 [도입됨](https://gitlab.com/gitlab-org/gitlab/-/issues/580307) GitLab 18.7에서 [기능 플래그](../../../administration/feature_flags/_index.md) 이름은 `ai_catalog_agents`입니다. GitLab.com에서 활성화됨.
- GitLab 18.7에서 베타로 [변경됨](https://gitlab.com/gitlab-org/gitlab/-/issues/568176).
- GitLab 18.8에서 [일반적으로 사용 가능](https://gitlab.com/gitlab-org/gitlab/-/work_items/585273)합니다.
- GitLab 18.9에서 `ai_catalog_agents` 기능 플래그가 [제거](https://gitlab.com/gitlab-org/gitlab/-/merge_requests/217802)되었습니다.
- GitLab 18.10에서 기능 플래그 `global_ai_catalog`가 [제거됨](https://gitlab.com/gitlab-org/gitlab/-/merge_requests/223135).
- 유지보수자로 프로젝트에서 직접 활성화하기는 GitLab 18.10에서 [소개](https://gitlab.com/groups/gitlab-org/-/work_items/20743)되었으며 [기능 플래그](../../../administration/feature_flags/_index.md) `ai_catalog_project_level_enablement`를 사용합니다. GitLab.com, GitLab Self-Managed 및 GitLab Dedicated에서 기본적으로 활성화됨.
- GitLab 18.10부터 GitLab.com의 Free 티어에서 GitLab Credits를 사용하여 이용 가능합니다.
- 기능 플래그 `ai_catalog_project_level_enablement`은 GitLab 18.11에서 제거되었습니다.

{{< /history >}}

에이전트는 AI를 사용하여 작업을 수행하고 복잡한 질문에 답변합니다. 사용자 지정 에이전트를 생성하여 머지 리퀘스트 생성 또는 코드 검토와 같은 특정 작업을 완료합니다. AI 카탈로그를 사용하여 GitLab에서 생성한 에이전트를 검색합니다.

에이전트와 상호작용할 준비가 되면 에이전트를 사용 가능하도록 설정하고 GitLab UI, VS Code, JetBrains IDE에서 GitLab Duo Chat으로 사용을 시작합니다.

## 전제 조건 {#prerequisites}

- [GitLab Duo Agent Platform 전제 조건](../_index.md#prerequisites)을 충족해야 합니다.
- [커스텀 에이전트가 켜져 있습니다](#turn-custom-agents-on-or-off).

## 에이전트 가시성 {#agent-visibility}

{{< history >}}

- 비공개 에이전트를 볼 수 있는 역할이 GitLab 18.7에서 [확장되었습니다](https://gitlab.com/gitlab-org/gitlab/-/work_items/582507).

{{< /history >}}

사용자 지정 에이전트를 생성할 때 이를 관리할 프로젝트를 선택하고 에이전트가 공개인지 비공개인지 선택합니다.

공개 에이전트:

- 누구나 볼 수 있으며 전제 조건을 충족하는 모든 프로젝트에서 사용 가능하도록 설정할 수 있습니다.

비공개 에이전트:

- 게스트, 플래너, 보고자, 개발자, 유지보수자 또는 소유자 역할이 있는 관리 프로젝트의 멤버만 볼 수 있습니다.
- 관리 프로젝트 이외의 프로젝트에서는 사용 가능하도록 설정할 수 없습니다.

에이전트가 현재 사용 가능하도록 설정되어 있으면 공개 에이전트를 비공개로 변경할 수 없습니다.

## 프로젝트의 에이전트 보기 {#view-the-agents-for-your-project}

전제 조건:

- 프로젝트에 대해 Developer, Maintainer 또는 Owner 역할이 있어야 합니다.

프로젝트와 연결된 에이전트 목록을 보려면:

1. 상단 바에서 **검색 또는 이동**을 선택하고 프로젝트를 찾습니다.
1. 왼쪽 사이드바에서 **AI** > **에이전트**를 선택합니다.
   - 프로젝트에서 사용 가능하도록 설정된 에이전트를 보려면 **활성화** 탭을 선택합니다.
   - 프로젝트에서 관리하는 에이전트를 보려면 **관리됨** 탭을 선택합니다.

에이전트를 선택하여 세부 정보를 봅니다.

## 에이전트 생성 {#create-an-agent}

프로젝트에서 에이전트를 생성하거나 AI 카탈로그를 사용하여 에이전트를 생성할 수 있습니다.

전제 조건:

- 프로젝트에 대해 Maintainer 또는 Owner 역할이 필요합니다.

{{< tabs >}}

{{< tab title="프로젝트에서" >}}

에이전트를 생성하려면:

1. 상단 바에서 **검색 또는 이동**을 선택하고 프로젝트를 찾습니다.
1. 왼쪽 사이드바에서 **AI** > **에이전트**를 선택합니다.
1. **새 에이전트**를 선택합니다.
1. **기본 정보** 아래:
   1. **이름 표시**에서 에이전트의 이름을 입력합니다.
   1. **설명**에서 에이전트에 대한 설명을 입력합니다.
1. **공개범위 & 억세스** 아래에서 **공개범위**에 대해 **비공개** 또는 **공개**를 선택합니다.
1. **Prompts** 아래의 **시스템 프롬프트**에서 에이전트의 성격, 전문성 및 행동을 정의하는 프롬프트를 입력합니다.
1. 선택 사항. **Available tools** 아래의 **도구** 드롭다운 목록에서 에이전트가 액세스할 수 있는 도구를 선택합니다. 예를 들어 에이전트가 자동으로 이슈를 생성하려면 **이슈 생성**을 선택합니다.

   > [!note]
   > 일부 도구는 IDE 확장이 필요하며 Web UI에서 사용할 수 없습니다. 자세한 내용은 [에이전트 도구](tools.md) 목록을 참조하세요.
1. **에이전트 생성**을 선택합니다.

{{< /tab >}}

{{< tab title="AI 카탈로그에서" >}}

에이전트를 생성하려면:

1. 상단 표시줄에서 **검색 또는 이동** > **탐색**을 선택합니다.
1. **AI 카탈로그**를 선택한 다음 **에이전트** 탭을 선택합니다.
1. **새 에이전트**를 선택합니다.
1. **기본 정보** 아래:
   1. **이름 표시**에서 에이전트의 이름을 입력합니다.
   1. **설명**에서 에이전트에 대한 설명을 입력합니다.
1. **공개범위 & 억세스** 아래:
   1. **관리** 드롭다운 목록에서 에이전트의 프로젝트를 선택합니다.
   1. **공개범위**에 대해 **비공개** 또는 **공개**를 선택합니다.
1. **Prompts** 아래의 **시스템 프롬프트**에서 에이전트의 성격, 전문성 및 행동을 정의하는 프롬프트를 입력합니다.
1. 선택 사항. **Available tools** 아래의 **도구** 드롭다운 목록에서 에이전트가 액세스할 수 있는 도구를 선택합니다. 예를 들어 에이전트가 자동으로 이슈를 생성하려면 **이슈 생성**을 선택합니다.

   사용 가능한 도구 목록은 [기본 제공 도구 정의](https://gitlab.com/gitlab-org/gitlab/-/blob/master/ee/lib/ai/catalog/built_in_tool_definitions.rb)를 참조하세요.
1. **에이전트 생성**을 선택합니다.

{{< /tab >}}

{{< /tabs >}}

에이전트가 AI 카탈로그에 나타납니다. Chat에서 에이전트를 사용하려면 에이전트를 사용 가능하도록 설정해야 합니다.

## 에이전트 사용 가능하도록 설정 {#enable-an-agent}

{{< history >}}

- 여러 프로젝트에 대한 공개 에이전트를 사용 가능하도록 설정 [도입됨](https://gitlab.com/gitlab-org/gitlab/-/work_items/600526) GitLab 19.2에서 [기능 플래그](../../../administration/feature_flags/_index.md) 이름은 `ai_catalog_bulk_item_consumer_create`입니다. 기본적으로 활성화되었습니다.

{{< /history >}}

> [!flag]
> 이 기능의 사용 가능 여부는 기능 플래그에 의해 제어됩니다. 자세한 내용은 이력을 참조하세요.

Chat과 함께 사용할 에이전트를 사용 가능하도록 설정합니다.

프로젝트에서 에이전트를 사용 가능하도록 설정하면 동시에 해당 프로젝트의 최상위 그룹에서 사용 가능하도록 설정됩니다.

전제 조건:

- 프로젝트에 대해 Maintainer 또는 Owner 역할이 필요합니다.

{{< tabs >}}

{{< tab title="관리 프로젝트에서" >}}

에이전트를 사용 가능하도록 설정하려면:

1. 상단 바에서 **검색 또는 이동**을 선택하고 프로젝트를 찾습니다.
1. 왼쪽 사이드바에서 **AI** > **에이전트**를 선택합니다.
1. **관리됨** 탭을 선택한 다음 사용 가능하도록 설정할 에이전트를 선택합니다.
1. 오른쪽 위 모서리에서 **사용**을 선택합니다.
1. **프로젝트** 아래에서 에이전트를 사용 가능하도록 설정할 프로젝트를 선택합니다.
1. **사용**을 선택합니다.

{{< /tab >}}

{{< tab title="AI 카탈로그에서" >}}

에이전트를 사용 가능하도록 설정하려면:

1. 상단 표시줄에서 **검색 또는 이동** > **탐색**을 선택합니다.
1. **AI 카탈로그**를 선택한 다음 **에이전트** 탭을 선택합니다.
1. 사용 가능하도록 설정할 에이전트를 선택합니다.
1. 오른쪽 위 모서리에서 **사용**을 선택합니다.
1. **프로젝트** 아래에서 에이전트를 사용 가능하도록 설정할 프로젝트를 선택합니다.

   여러 프로젝트에 대한 공개 에이전트를 사용 가능하도록 설정하려면 **프로젝트** 드롭다운 목록에서 관련 프로젝트를 선택합니다. 최대 100개 프로젝트를 선택할 수 있습니다.

1. **사용**을 선택합니다.

{{< /tab >}}

{{< /tabs >}}

에이전트가 그룹 및 프로젝트 **AI** > **에이전트** 페이지에 나타납니다. 최상위 그룹의 모든 프로젝트의 멤버는 이제 자신의 프로젝트에서 에이전트를 사용 가능하도록 설정할 수 있습니다.

프로젝트에서 에이전트와의 새로운 채팅을 시작할 수 있습니다. 자세한 내용은 [에이전트 선택](../../gitlab_duo_chat/agentic_chat.md#select-an-agent)을 참조하세요.

### 프로젝트에서 활성화 {#enable-in-a-project}

에이전트가 이미 최상위 그룹에서 사용 가능하도록 설정된 경우 그룹의 프로젝트에서 사용 가능하도록 설정할 수 있습니다.

전제 조건:

- 프로젝트에 대해 Maintainer 또는 Owner 역할이 필요합니다.
- 에이전트가 프로젝트의 최상위 그룹에서 사용 가능하도록 설정되어 있어야 합니다.

프로젝트에서 에이전트를 사용 가능하도록 설정하려면:

1. 상단 바에서 **검색 또는 이동**을 선택하고 프로젝트를 찾습니다.
1. 왼쪽 사이드바에서 **AI** > **에이전트**를 선택합니다.
1. 오른쪽 위 모서리에서 **Enable agent from group**을 선택합니다.
1. 드롭다운 목록에서 사용 가능하도록 설정할 에이전트를 선택합니다.
1. **사용**을 선택합니다.

에이전트가 프로젝트의 **AI** > **에이전트** 페이지에 나타납니다.

프로젝트에서 에이전트와의 새로운 채팅을 시작할 수 있습니다.

## 에이전트 사용 {#use-an-agent}

사용자 지정 에이전트를 GitLab UI, VS Code, JetBrains IDE에서 사용할 수 있습니다.

### GitLab UI에서 {#in-the-gitlab-ui}

전제 조건:

- 사용하려는 프로젝트에서 에이전트를 사용 가능하도록 설정합니다.

GitLab UI에서 사용자 지정 에이전트를 사용하려면:

1. 상단 막대에서 **검색 또는 이동**을 선택하고 프로젝트 또는 그룹을 찾습니다.
1. 이슈, 에픽 또는 머지 리퀘스트를 엽니다.
1. GitLab Duo 사이드바에서 **새 채팅 추가**({{< icon name="pencil-square" >}})를 선택합니다.
1. 드롭다운 목록에서 사용자 지정 에이전트를 선택합니다.

   화면 오른쪽의 GitLab Duo 사이드바에서 Chat 대화창이 열립니다.
1. 질문 또는 요청을 입력합니다.

### VS Code에서 {#in-vs-code}

전제 조건:

- 사용하려는 프로젝트에서 에이전트를 사용 가능하도록 설정합니다.
- [GitLab for VS Code](../../../editor_extensions/visual_studio_code/setup.md) 버전 6.47.0 이상을 설치하고 구성합니다.
- [기본 GitLab Duo 네임스페이스](../../profile/preferences.md#set-a-default-gitlab-duo-namespace)를 설정해야 합니다.

VS Code에서 사용자 지정 에이전트를 사용하려면:

1. VS Code의 왼쪽 사이드바에서 **GitLab Duo 에이전트 플랫폼** ({{< icon name="duo-agentic-chat" >}})을 선택합니다.
1. **Chat** 탭을 선택합니다.
1. **새 채팅** ({{< icon name="duo-chat-new" >}}) 드롭다운 목록에서 사용자 지정 에이전트를 선택합니다.
1. 질문 또는 요청을 입력합니다.

### JetBrains IDE에서 {#in-jetbrains-ides}

전제 조건:

- 사용하려는 프로젝트에서 에이전트를 사용 가능하도록 설정합니다.
- [JetBrains IDE용 GitLab Duo 플러그인](../../../editor_extensions/jetbrains_ide/setup.md) 버전 3.19.0 이상을 설치하고 구성합니다.
- [기본 GitLab Duo 네임스페이스](../../profile/preferences.md#set-a-default-gitlab-duo-namespace)를 설정해야 합니다.

먼저 GitLab Duo 에이전트 플랫폼을 사용 가능하도록 설정합니다:

1. JetBrains IDE에서 **설정** > **도구** > **GitLab Duo**로 이동합니다.
1. **GitLab Duo Agent Platform** 아래에서 **GitLab Duo Agent Platform 활성화** 체크박스를 선택합니다.
1. 메시지가 표시되면 IDE를 다시 시작합니다.

그 다음 사용자 지정 에이전트를 사용하려면:

1. JetBrains IDE의 오른쪽 도구 창 막대에서 **GitLab Duo 에이전트 플랫폼** ({{< icon name="duo-agentic-chat" >}})을 선택합니다.
1. **Chat** 탭을 선택합니다.
1. **새 채팅** ({{< icon name="duo-chat-new" >}}) 드롭다운 목록에서 사용자 지정 에이전트를 선택합니다.
1. 질문 또는 요청을 입력합니다.

## 에이전트 사용 안 함 {#disable-an-agent}

전제 조건:

- 그룹의 경우 유지보수자 또는 소유자 역할이 필요합니다.
- 프로젝트의 경우 유지보수자 또는 소유자 역할이 필요합니다.

에이전트를 사용 안 함으로 설정하려면:

1. 상단 바에서 **검색 또는 이동**을 선택하고 그룹 또는 프로젝트를 찾습니다.
1. **AI** > **에이전트**를 선택합니다.
1. 제거할 에이전트를 찾아 **조치** ({{< icon name="ellipsis_v" >}}) > **사용 안 함**을 선택합니다.
1. 확인 대화에서 **사용 안 함**을 선택합니다.

에이전트는 더 이상 프로젝트에 나타나지 않으며 Chat에서 사용할 수 없습니다.

## 에이전트 복제 {#duplicate-an-agent}

원본을 덮어쓰지 않고 에이전트를 변경하려면 기존 에이전트의 복사본을 생성합니다.

전제 조건:

- 프로젝트에 대해 Maintainer 또는 Owner 역할이 필요합니다.

에이전트를 복제하려면:

1. 상단 표시줄에서 **검색 또는 이동** > **탐색**을 선택합니다.
1. **AI 카탈로그**를 선택한 다음 **에이전트** 탭을 선택합니다.
1. 복제하려는 에이전트를 선택합니다.
1. 오른쪽 위 모서리에서 **조치** ({{< icon name="ellipsis_v" >}}) > **복제**를 선택합니다.
1. 선택 사항. 변경할 필드를 편집합니다.
1. **에이전트 생성**을 선택합니다.

## 에이전트 편집 {#edit-an-agent}

에이전트를 편집하여 해당 구성을 변경합니다.

전제 조건:

- 관리 프로젝트의 멤버여야 하며 유지보수자 또는 소유자 역할이 필요합니다.

1. 상단 바에서 **검색 또는 이동**을 선택하고 그룹 또는 프로젝트를 찾습니다.
1. **AI** > **에이전트**를 선택합니다.
1. 편집할 에이전트를 선택합니다.
1. 오른쪽 위 모서리에서 **편집**을 선택합니다.
1. 변경할 필드를 편집한 다음 **변경사항 저장**을 선택합니다.

## 에이전트 숨김 {#hide-an-agent}

에이전트를 숨겨서 AI 카탈로그에서 제거합니다.

에이전트를 숨긴 후에는 사용자가 해당 에이전트를 사용 가능하도록 설정할 수 없습니다. 그러나 에이전트가 이미 사용 가능하도록 설정된 그룹 및 프로젝트에서는 에이전트와 상호작용할 수 있습니다.

전제 조건:

- 관리 프로젝트의 멤버여야 하며 유지보수자 또는 소유자 역할이 필요합니다.

에이전트를 숨기려면:

1. 상단 바에서 **검색 또는 이동**을 선택하고 그룹 또는 프로젝트를 찾습니다.
1. **AI** > **에이전트**를 선택합니다.
1. 숨길 에이전트를 찾아 **조치** ({{< icon name="ellipsis_v" >}}) > **숨김**을 선택합니다.
1. 확인 대화에서 **확인**을 선택합니다.

## 에이전트 삭제 {#delete-an-agent}

에이전트를 삭제하여 인스턴스에서 영구적으로 제거합니다.

전제 조건:

- 관리자여야 합니다.

1. 상단 바에서 **검색 또는 이동**을 선택하고 그룹 또는 프로젝트를 찾습니다.
1. **AI** > **에이전트**를 선택합니다.
1. 삭제할 에이전트를 찾아 **조치** ({{< icon name="ellipsis_v" >}}) > **삭제**를 선택합니다.
1. 확인 대화에서 **삭제**를 선택합니다.

## 커스텀 에이전트 켜기 또는 끄기 {#turn-custom-agents-on-or-off}

{{< history >}}

- GitLab 19.0에서 [도입](https://gitlab.com/gitlab-org/gitlab/-/work_items/594615)되었습니다.

{{< /history >}}

기본적으로 사용자 지정 에이전트는 켜져 있습니다. 최상위 그룹 또는 인스턴스에 대해 켜거나 끌 수 있습니다.

사용자 지정 에이전트가 꺼져 있을 때:

- 사용자는 사용자 지정 에이전트를 생성, 사용, 사용 안 함 또는 실행할 수 없습니다.
- 기존 사용자 지정 에이전트는 **AI** > **에이전트** > **활성화** 아래의 프로젝트에서 더 이상 표시되지 않습니다.
- 프로젝트에서 생성한 사용자 지정 에이전트는 **AI** > **에이전트** > **관리됨** 아래에 나타나지만 실행할 수 없습니다.
- [기본 에이전트](foundational_agents/_index.md)와 [외부 에이전트](external.md)는 계속 사용 가능합니다.

{{< tabs >}}

{{< tab title="GitLab.com" >}}

전제 조건:

- 그룹의 Owner 역할이 있어야 합니다.

1. 상단 바에서 **검색 또는 이동**을 선택하고 그룹을 찾습니다.
1. 왼쪽 사이드바에서 **설정** > **GitLab Duo**를 선택합니다.
1. **구성 변경**을 선택합니다.
1. **커스팀 외부 에이전트와 플로우** 아래에서 **커스텀 에이전트 허용** 체크박스를 선택하거나 선택 해제합니다.
1. **변경 사항 저장**을 선택합니다.

이 설정은 그룹의 모든 하위 그룹으로 계단식으로 진행됩니다.

{{< /tab >}}

{{< tab title="GitLab Self-Managed" >}}

전제 조건:

- 관리자여야 합니다.

1. 오른쪽 위 모서리에서 **Admin**을 선택합니다.
1. 왼쪽 사이드바에서 **GitLab Duo**를 선택합니다.
1. **구성 변경**을 선택합니다.
1. **커스팀 외부 에이전트와 플로우** 아래에서 **커스텀 에이전트 허용** 체크박스를 선택하거나 선택 해제합니다.
1. **변경 사항 저장**을 선택합니다.

인스턴스 수준 설정이 꺼져 있으면 그룹 수준 설정은 이를 재정의할 수 없습니다.
