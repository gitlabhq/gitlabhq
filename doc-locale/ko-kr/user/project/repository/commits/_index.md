**커밋** 목록은 리포지토리의 커밋 이력을 표시합니다. 이를 사용하여 코드 변경을 찾아보고, 커밋 세부 정보를 보고, 커밋 서명을 확인합니다. 커밋은 날짜별로 그룹화되며, 작성자, 커밋 메시지, 날짜 또는 Git 리비전으로 목록을 필터링할 수 있습니다.

목록에는 다음이 표시됩니다:

- 커밋 해시: 각 커밋의 고유 식별자(SHA)입니다.
- 커밋 메시지: 커밋의 제목과 설명입니다.
- 작성자: 커밋을 만든 사용자의 이름과 아바타입니다.
- 타임스탬프: 커밋을 생성한 시간입니다.
- 파이프라인 상태: CI/CD 파이프라인 결과(구성된 경우)입니다.
- 서명 확인: GPG, SSH 또는 X.509 서명 상태입니다.
- 태그: 이 커밋을 가리키는 모든 태그입니다.

![리포지토리의 커밋 목록 예시](img/repository_commits_list_v19_1.png)

## 커밋 보기 {#view-commits}

리포지토리의 커밋 이력을 보려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 프로젝트를 찾습니다.
1. 왼쪽 사이드바에서 **코드** > **커밋**을 선택합니다.

커밋의 전체 설명을 보려면 커밋의 오른쪽에 있는 확장 ({{< icon name="chevron-down" >}}) 아이콘을 선택합니다. 설명을 축소하려면 확장 ({{< icon name="chevron-down" >}}) 아이콘을 다시 선택합니다.

## 커밋 세부 정보 보기 {#view-commit-details}

모든 커밋에서 파일 수정, 추가 및 삭제를 포함한 특정 변경 사항을 검토합니다.

커밋의 세부 정보를 보려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 프로젝트를 찾습니다.
1. 왼쪽 사이드바에서 **코드** > **커밋**을 선택합니다.
1. 커밋을 선택하여 커밋의 세부 정보 페이지를 엽니다.

커밋의 세부 정보 페이지에는 다음이 표시됩니다:

- 커밋 정보: 커밋 해시, 작성자, 커미터, 상위 커밋 및 타임스탬프입니다.
- 커밋 메시지: 커밋의 제목과 설명입니다.
- 파일 변경: diff 보기가 있는 모든 수정된 파일입니다.
- 통계: 변경되고 추가되고 삭제된 줄의 수입니다.
- 파이프라인 세부 정보: 관련 CI/CD 파이프라인 상태 및 세부 정보입니다.
- 참조: 이 커밋을 포함하는 브랜치 및 태그입니다.
- 관련 머지 리퀘스트: 커밋과 관련된 머지 리퀘스트로의 링크입니다.

## Git 리비전별로 리포지토리 파일 찾아보기 {#browse-repository-files-by-git-revision}

커밋 SHA, 브랜치 이름 또는 태그 같은 특정 Git 리비전에서 모든 리포지토리 파일 및 폴더를 보려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 프로젝트를 찾습니다.
1. 왼쪽 사이드바에서 **코드** > **커밋**을 선택합니다.
1. 다음 옵션 중 하나를 선택합니다:
   - Git 리비전별로 필터링:
      1. 맨 위에서 **Git 리비전 선택** 드롭다운 목록을 열도록 선택합니다.
      1. Git 리비전을 선택하거나 검색합니다.
   - 커밋 목록에서 특정 커밋을 선택합니다.
1. 오른쪽 위에서 **파일 찾아보기**를 선택합니다.

해당 특정 리비전에서 [리포지토리](../_index.md) 페이지로 이동합니다.

## 커밋 필터링 및 검색 {#filter-and-search-commits}

검색 표시줄을 사용하여 작성자, 커밋 메시지 또는 날짜별로 커밋 이력을 필터링합니다. 여러 필터를 동시에 조합할 수 있습니다.

### 날짜별로 필터링 {#filter-by-date}

날짜별로 커밋을 필터링하려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 프로젝트를 찾습니다.
1. 왼쪽 사이드바에서 **코드** > **커밋**을 선택합니다.
1. 검색 표시줄에서 필터 드롭다운 목록의 **이후에 커밋됨** 또는 **이전에 커밋됨**을 선택합니다.
1. 날짜를 입력합니다.

특정 날짜 범위의 커밋을 보려면 두 필터를 함께 사용합니다.

### 작성자별로 필터링 {#filter-by-author}

하나 이상의 작성자별로 커밋을 필터링하려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 프로젝트를 찾습니다.
1. 왼쪽 사이드바에서 **코드** > **커밋**을 선택합니다.
1. 검색 표시줄에서 필터 드롭다운 목록의 **작성자**를 선택합니다.
1. 하나 이상의 작성자를 선택하거나 검색합니다.

목록이 업데이트되어 선택한 작성자의 커밋만 표시됩니다.

작성자 필터링이 특수 문자가 있는 이름에 대해 작동하지 않으면 URL 매개 변수 형식을 사용합니다. 예를 들어 URL에 `?author=Elliot%20Stevens`를 추가합니다.

### Git 리비전별로 필터링 {#filter-by-git-revision}

브랜치, 태그 또는 커밋 SHA 같은 Git 리비전별로 커밋을 필터링하려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 프로젝트를 찾습니다.
1. 왼쪽 사이드바에서 **코드** > **커밋**을 선택합니다.
1. 맨 위의 드롭다운 목록에서 Git 리비전을 선택하거나 검색합니다. 예를 들어 브랜치 이름, 태그 또는 커밋 SHA입니다.
1. Git 리비전을 선택하여 필터링된 커밋 목록을 봅니다.

### 커밋 메시지로 검색 {#search-by-commit-message}

메시지 내용으로 커밋을 검색하려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 프로젝트를 찾습니다.
1. 왼쪽 사이드바에서 **코드** > **커밋**을 선택합니다.
1. 검색 표시줄에서 필터 드롭다운 목록의 **메시지**를 선택합니다.
1. 검색 용어를 입력합니다.

커밋 SHA(전체 또는 부분)로 검색하여 특정 커밋을 직접 찾을 수도 있습니다.

### 필터링된 보기 공유 및 북마크 {#share-and-bookmark-filtered-views}

{{< history >}}

- GitLab 19.1에서 [도입](https://gitlab.com/gitlab-org/gitlab/-/issues/599000)되었습니다.

{{< /history >}}

커밋 목록을 필터링하거나 페이지 크기를 변경하면 URL이 업데이트되어 현재 보기를 반영합니다. 다음을 수행할 수 있습니다.

- URL을 복사하여 필터링된 보기를 공유합니다.
- URL을 북마크하여 필터 조합을 저장합니다.
- 브라우저의 뒤로 가기 및 앞으로 가기 버튼을 사용하여 필터 상태 간에 이동합니다.

URL은 다음 매개 변수를 사용합니다:

| 매개 변수          | 설명 |
|--------------------|-------------|
| `author`           | 커밋 작성자의 사용자명입니다. |
| `message`          | 커밋 메시지에서 일치시킬 텍스트입니다. |
| `committed_after`  | `YYYY-MM-DD` 형식의 가장 초기 커밋 날짜입니다. |
| `committed_before` | `YYYY-MM-DD` 형식의 가장 최신 커밋 날짜입니다. |
| `page_size`        | 페이지당 커밋 수입니다. 기본값은 `20`입니다. |

## 커밋 페이지 간 이동 {#navigate-between-pages-of-commits}

커밋 목록은 커서 기반 페이지 매김을 사용합니다. 페이지 간에 이동하려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 프로젝트를 찾습니다.
1. 왼쪽 사이드바에서 **코드** > **커밋**을 선택합니다.
1. 목록의 맨 아래에서 **이전** 또는 **다음**을 선택하여 페이지 간에 이동합니다.

## 커밋 목록 작업 액세스 {#access-commit-list-actions}

커밋 페이지에는 현재 Git 리비전에 대한 빠른 링크가 있는 작업 메뉴가 포함됩니다.

작업 메뉴에 액세스하려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 프로젝트를 찾습니다.
1. 왼쪽 사이드바에서 **코드** > **커밋**을 선택합니다.
1. 오른쪽 위 모서리에서 수직 줄임표({{< icon name="ellipsis_v" >}}) 를 선택하여 작업 메뉴를 엽니다.

작업 메뉴에는 다음이 포함됩니다:

- **파일 찾아보기**: 선택한 Git 리비전에서 모든 리포지토리 파일을 봅니다.
- **Subscribe to commits RSS feed**: 현재 리비전의 커밋에 대한 RSS 피드를 구독합니다.

## 커밋 Cherry-pick {#cherry-pick-a-commit}

특정 커밋의 변경 사항을 다른 커밋에 적용합니다.

전제 조건:

- 프로젝트에 대해 Developer, Maintainer 또는 Owner 역할이 있어야 합니다.
- 대상 브랜치가 있어야 합니다.

커밋을 cherry-pick하려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 프로젝트를 찾습니다.
1. 왼쪽 사이드바에서 **코드** > **커밋**을 선택합니다.
1. cherry-pick할 커밋을 선택합니다.
1. 오른쪽 위 모서리에서 **옵션**을 선택한 후 **Cherry-pick**을 선택합니다.
1. 대화상자에서:
   - 드롭다운 목록에서 대상 프로젝트 및 브랜치를 선택합니다.
   - 선택 사항. **Start a new merge request**을 선택하여 변경 사항이 포함된 머지 리퀘스트를 생성합니다.
   - **Cherry-pick**을 선택합니다.

GitLab은 cherry-picked된 변경 사항이 있는 대상 브랜치에서 새로운 커밋을 생성합니다. 브랜치가 [보호](../branches/protected.md)되어 있거나 올바른 권한이 없으면 GitLab에서 [새로운 머지 리퀘스트 생성](../../merge_requests/_index.md#create-a-merge-request)을 수행하라는 메시지를 표시합니다.

## 커밋 되돌리기 {#revert-a-commit}

이전 커밋의 변경 사항을 취소하는 새로운 커밋을 생성합니다.

전제 조건:

- 프로젝트에 대해 Developer, Maintainer 또는 Owner 역할이 있어야 합니다.

커밋을 되돌리려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 프로젝트를 찾습니다.
1. 왼쪽 사이드바에서 **코드** > **커밋**을 선택합니다.
1. 되돌릴 커밋을 선택합니다.
1. 오른쪽 위 모서리에서 **옵션**을 선택한 후 **Revert**를 선택합니다.
1. 대화상자에서:
   - 되돌릴 커밋의 대상 브랜치를 선택합니다.
   - 선택 사항. **Start a new merge request**을 선택하여 머지 리퀘스트를 생성합니다.
   - **Revert**를 선택합니다.

GitLab은 선택한 커밋의 변경 사항을 반대로 하는 새로운 커밋을 생성합니다. 브랜치가 [보호](../branches/protected.md)되어 있거나 올바른 권한이 없으면 GitLab에서 [새로운 머지 리퀘스트 생성](../../merge_requests/_index.md#create-a-merge-request)을 수행하라는 메시지를 표시합니다.

## 커밋 내용 다운로드 {#download-commit-contents}

커밋의 diff 내용을 다운로드하려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 프로젝트를 찾습니다.
1. 왼쪽 사이드바에서 **코드** > **커밋**을 선택합니다.
1. 다운로드할 커밋을 선택합니다.
1. 오른쪽 위 모서리에서 **옵션**을 선택합니다.
1. **다운로드**에서 **Plain Diff**를 선택합니다.

## 커밋 서명 확인 {#verify-commit-signatures}

GitLab은 GPG, SSH 및 X.509 서명을 확인하여 커밋 진정성을 보장합니다. 확인된 커밋은 **검증됨** 배지를 표시합니다.

자세한 내용은 [서명된 커밋](../signed_commits/_index.md)을 참조합니다.

### 서명 세부 정보 보기 {#view-signature-details}

서명 정보를 보려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 프로젝트를 찾습니다.
1. 왼쪽 사이드바에서 **코드** > **커밋**을 선택합니다.
1. **검증됨** 또는 **미인증** 배지가 있는 커밋을 찾습니다.
1. 배지를 선택하여 다음을 포함한 서명 세부 정보를 봅니다:
   - 서명 유형(GPG, SSH 또는 X.509)
   - 키 지문
   - 확인 상태
   - 서명자 ID

## 파이프라인 상태 및 세부 정보 보기 {#view-pipeline-status-and-details}

커밋 목록에는 각 커밋 옆에 CI/CD 파이프라인 상태 아이콘이 포함됩니다. 파이프라인 세부 정보를 보려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 프로젝트를 찾습니다.
1. 왼쪽 사이드바에서 **코드** > **커밋**을 선택합니다.
1. 모든 커밋 옆의 파이프라인 상태 아이콘을 선택합니다.
