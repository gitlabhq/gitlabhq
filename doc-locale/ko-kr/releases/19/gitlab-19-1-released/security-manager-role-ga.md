보안 관리자 역할을 이제 일반적으로 사용할 수 있으며, 취약성 관리, 보안 대시보드, 정책 구성, 규정 준수 도구를 포함한 보안 기능에 대한 포괄적인 액세스를 제공합니다. 보안 팀은 더 이상 보안 기능에 액세스하기 위해 개발자 역할이나 유지 관리자 역할이 필요하지 않으므로 과도한 권한 부여 문제를 제거하면서 업무 분리를 유지합니다.

보안 관리자 역할을 가진 사용자는 다음 액세스 권한을 갖습니다:

- 취약성 관리: 그룹 및 프로젝트 전반에서 취약성을 보고, 분류하고, 관리합니다.
- 보안 정책: 그룹 수준에서 보안 정책을 보고 관리하며, 프로젝트 수준에서 정책 YAML에 기여합니다.
- 보안 인벤토리: 그룹의 모든 프로젝트 전반에서 스캐너 범위를 봅니다.
- 보안 구성 프로필: 그룹 및 프로젝트의 보안 구성 프로필을 봅니다.
- 규정 준수 도구: 그룹 및 프로젝트 수준 모두에서 감사 이벤트, 규정 준수 센터, 규정 준수 프레임워크, 규정 준수 상태 보고서 및 종속성 목록을 보고 관리합니다.
- 보안 암호 푸시 보호: 그룹 및 프로젝트에 대해 보안 암호 푸시 보호를 활성화합니다.
- 온디맨드 DAST: 프로젝트에 대해 온디맨드 DAST 스캔을 만들고 실행합니다.
- 러너 가시성: 그룹 및 프로젝트의 러너를 봅니다.

시작하려면 그룹으로 이동하고 **관리 > 멤버**를 선택하여 보안 관리자 역할에 멤버를 초대하고 할당합니다.
