이제 GitLab.com의 신규 GitLab Duo 평가판 고객을 위해 Code Review 플로우의 자동 검토 기능이 기본적으로 활성화되므로, 수동 설정 없이 첫날부터 머지 리퀘스트에 대한 AI 기반 피드백을 받을 수 있습니다.

새로운 정액제 가격 모델을 통해 추가 설정 없이 더 스마트하고 빠른 코드 검토의 즉각적인 가치를 얻을 수 있습니다. 필요한 경우 그룹 설정에서 옵트아웃할 수 있습니다.
