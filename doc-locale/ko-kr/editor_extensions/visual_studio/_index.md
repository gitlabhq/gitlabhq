[Visual Studio용 GitLab 확장](https://marketplace.visualstudio.com/items?itemName=GitLab.GitLabExtensionForVisualStudio)은 GitLab을 Windows의 Visual Studio와 통합합니다.

Visual Studio용 GitLab은 다음을 지원합니다:

- [GitLab Duo Agent Platform](../../user/duo_agent_platform/_index.md)(GitLab Duo Agentic Chat, Software Development 플로우 및 GitLab Duo Code Suggestions 포함).
- [GitLab Duo](../../user/gitlab_duo/feature_summary.md)(GitLab Duo Non-Agentic Chat 및 Code Suggestions 포함).

확장을 설치하고 구성하려면 [설치 및 설정](setup.md)을 참조하세요.

[`gitlab-visual-studio-extension` 이슈 추적기](https://gitlab.com/gitlab-org/editor-extensions/gitlab-visual-studio-extension/-/issues)에서 문제, 버그 또는 기능 요청을 보고합니다.

## 확장 업데이트 {#update-the-extension}

확장을 최신 버전으로 업데이트하려면:

1. Visual Studio에서 **Extensions** > **Manage Extensions...**로 이동합니다.
1. **Updates** 탭을 선택합니다.
1. **GitLab for Visual Studio**을 **GitLab(`gitlab.com`)**에서 발행한 것으로 검색합니다.
1. 확장에서 **업데이트**를 선택하여 최신 버전으로 업데이트합니다.
