Use this API to upload and download the files attached to a version of a machine learning model in
the [model registry](../../../../doc/user/project/ml/model_registry/_index.md). To create models and model
versions, use an [MLflow client](../../../../doc/user/project/ml/experiment_tracking/mlflow_client.md).
