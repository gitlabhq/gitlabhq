---
name: Runner controller tokens
external_docs: https://docs.gitlab.com/api/runner_controller_tokens/
---
Use this API to create, list, rotate, and revoke the authentication tokens that runner controllers
use to authenticate with a GitLab instance and manage runners.

These endpoints require administrator access to the instance.

> [!note]
> The availability of these endpoints is controlled by a feature flag. They are available for
> testing, but not ready for production use.
