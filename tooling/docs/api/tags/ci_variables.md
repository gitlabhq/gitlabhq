Use this API to manage CI/CD variables for a [project](../../../../doc/ci/variables/_index.md#for-a-project),
a [group](../../../../doc/ci/variables/_index.md#for-a-group), or an
[instance](../../../../doc/ci/variables/_index.md#for-an-instance).

Managing project variables requires the Maintainer role for the project.
Managing group variables requires the Owner role for the group.
Managing instance variables requires administrator access.
