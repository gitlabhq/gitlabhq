Use this API to manage the Maven and npm
[virtual registries](../../../../doc/user/packages/virtual_registry/_index.md) of a group, along with
the [upstream registries](../../../../doc/user/packages/virtual_registry/_index.md#manage-upstream-registries)
they proxy. You can test the connection to an upstream, inspect its
[cache](../../../../doc/user/packages/virtual_registry/_index.md#caching-system) entries, and purge
the cache of a registry or an upstream.
