Use this API to manage [emoji reactions](../../../../doc/user/emoji_reactions.md).

GitLab objects that accept emoji reactions are called awardables.
You can react with emoji on the following resources:

- [Epics](../../../../doc/user/group/epics/_index.md)
- [Issues](../../../../doc/user/project/issues/_index.md)
- [Merge requests](../../../../doc/user/project/merge_requests/_index.md)
- [Snippets](../../../../doc/user/snippets.md)
- [Comments](../../../../doc/user/emoji_reactions.md#emoji-reactions-for-comments)
