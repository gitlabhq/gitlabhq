Use this API to interact with the [npm package manager client](../../../../doc/user/packages/npm_registry/_index.md).

> [!warning]
> This API is used by the [npm package manager client](https://docs.npmjs.com/)
> and is not meant for manual consumption.

These endpoints do not adhere to the standard API authentication methods.
See the [npm package registry documentation](../../../../doc/user/packages/npm_registry/_index.md)
for details on which headers and token types are supported. Undocumented authentication methods might be removed in the future.
