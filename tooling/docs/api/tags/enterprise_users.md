Use this API to manage the [enterprise users](../../../../doc/user/enterprise_user/_index.md) of a
top-level group, including disabling two-factor authentication for them.

These endpoints work only for top-level groups, and require the Owner role for that group. The users
themselves do not have to be members of the group.
