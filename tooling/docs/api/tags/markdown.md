Use this API to render [Markdown](../../../../doc/user/markdown.md) content as HTML.

All requests to this API must be [authenticated](../../../../doc/api/rest/authentication.md).

> [!note]
> The availability of this feature is controlled by a feature flag.
> This feature is available for testing, but not ready for production use.
