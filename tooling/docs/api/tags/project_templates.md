Use this API to retrieve project-specific templates, in addition to the templates common to the
entire instance:

- [Dockerfile templates](../../../../doc/api/templates/dockerfiles.md)
- [Gitignore templates](../../../../doc/api/templates/gitignores.md)
- [GitLab CI/CD configuration templates](../../../../doc/api/templates/gitlab_ci_ymls.md)
- [Open source license templates](../../../../doc/api/templates/licenses.md)
- [Issue and merge request templates](../../../../doc/user/project/description_templates.md)

These endpoints supersede the instance template endpoints, which are scheduled for removal
in API version 5. [File templates for groups](../../../../doc/user/group/manage.md#group-file-templates)
are also supported.
