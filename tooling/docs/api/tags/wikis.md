Use this API to manage [group wikis](../../../../doc/user/project/wiki/group.md).
An API for [project wikis](../../../../doc/api/wikis.md) is also available.

Comments on a wiki page are called `notes`. To interact with them, use the [notes API](../../../../doc/api/notes.md#group-wikis).
