Use this API to manage the [runners](../../../../doc/ci/runners/_index.md) already registered to an
instance, group, or project.

To create a runner, use the
[`POST /user/runners`](../../../../doc/api/users.md#create-a-runner-linked-to-a-user) endpoint
instead.
