Use this API to interact with user accounts on GitLab. These endpoints can help manage
[your account](../../../../doc/user/profile/_index.md), manage
[accounts for other users](../../../../doc/administration/administer_users.md),
[moderate user accounts](../../../../doc/administration/moderate_users.md),
[perform follower actions](../../../../doc/user/profile/_index.md#follow-users), and
[interact with email addresses for user accounts](../../../../doc/user/profile/_index.md).
