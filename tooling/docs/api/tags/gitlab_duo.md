Use this API to generate responses for [GitLab Duo Chat](../../../../doc/user/gitlab_duo_chat/_index.md)
and other GitLab Duo features.

On GitLab.com, these endpoints are for internal use only. On GitLab Self-Managed, you can enable them
[with a feature flag](../../../../doc/administration/feature_flags/_index.md) named `access_rest_chat`.
You must be a [GitLab team member](https://gitlab.com/groups/gitlab-com/-/group_members) to use these endpoints.
