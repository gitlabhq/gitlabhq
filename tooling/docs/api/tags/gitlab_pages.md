Use this API to [administer](../../../../doc/administration/pages/_index.md) and
[use](../../../../doc/user/project/pages/_index.md) GitLab Pages, including managing
[custom domains](../../../../doc/user/project/pages/custom_domains_ssl_tls_certification/_index.md).

GitLab Pages must be enabled to use these endpoints.
