Use this API to interact with [CI/CD job token](../../../../doc/ci/jobs/ci_job_token.md) scopes.

> [!note]
> All requests to the CI/CD job token scope API endpoint must be [authenticated](../../../../doc/api/rest/authentication.md).
> The authenticated user must have the Maintainer or Owner role for the project.
