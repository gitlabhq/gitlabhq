A scalar is a simple GraphQL type with no fields.

GraphQL has a standard set of scalars: [`Boolean`](#boolean), [`Float`](#float), [`ID`](#id), [`Int`](#int), and [`String`](#string).

GitLab extends the default set with custom scalars. Many of these
are [Global IDs](https://graphql.org/learn/global-object-identification),
which is an object identifier in the format of `"gid://gitlab/Issue/123"`.
Others like [`Time`](#time) provide a strict format for how our GraphQL
API displays and accepts time values.
