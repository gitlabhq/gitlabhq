In previous versions of GitLab, to find information in a large Markdown table,
you had to scan every row or copy the table into a spreadsheet.

Now you can sort rendered Markdown tables by any column, in both view mode and preview.
In a column header, select the sort button to sort rows in ascending or descending
order, then reset to restore the original order. You can also sort with a keyboard.
