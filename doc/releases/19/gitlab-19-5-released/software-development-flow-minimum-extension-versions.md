The Software Development Flow now runs on the GitLab Duo Agent Platform flow registry, the same
foundation as other flows.
The flow works the same way in your IDE, and new fixes and improvements go to this version.

To keep using the Software Development Flow, update your editor extension to one of these versions
or later:

- GitLab for VS Code 6.85.0
- GitLab Duo plugin for JetBrains IDEs 3.40.0
- GitLab for Visual Studio 0.79.0
