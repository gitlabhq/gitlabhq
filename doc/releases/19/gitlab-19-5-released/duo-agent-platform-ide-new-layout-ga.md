The redesigned GitLab Duo Agentic Chat UI in VS Code and JetBrains IDEs, introduced as a beta in
GitLab 19.3, is now generally available and is the default layout.
You no longer need to turn on beta and experimental features to use it.

The new layout has no tabs. You start conversations, view your chat history, and select an agent
and model in the same view.

The new layout is the default in:

- GitLab for VS Code 7.2.0 and later
- GitLab Duo plugin for JetBrains IDEs 3.50.0 and later

To use the Software Development Flow or view the flows you have run, switch to the classic layout
from the panel.
