In previous versions of GitLab, when you scrolled through a long table, the header
row scrolled out of view, so it was hard to tell what each column contained.

Now, table headers stay visible at the top of the table as you scroll, in view mode,
preview, and the rich text editor. Sticky headers are always on, so you don't need
to change any settings.
