You can now start a custom flow directly from GitLab Duo Agentic Chat, without needing to configure a trigger first.
Previously, running a custom flow required setting up a trigger event — a mention, an assignment, or similar — which made flows difficult to test and iterate on. Now, you can launch any AI Catalog flow enabled in your project by sending a message in GitLab Duo Agentic Chat. Your message becomes the goal for the flow. If you send no goal, the flow falls back to its own description.
Chat links to the resulting agent session so you can follow along.
