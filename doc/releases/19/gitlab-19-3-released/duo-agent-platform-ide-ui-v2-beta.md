The GitLab Duo Agentic Chat interface in the GitLab for VS Code extension has a redesigned UI, now available as a
beta. The new interface is a rebuilt version of the existing Agentic Chat panel,
with the same underlying capabilities: AI models, agents, slash commands, and tool approvals.

The redesigned UI is available in GitLab 19.3 with GitLab for VS Code extension 6.87.0 and later.

To use the new UI, [turn on beta and experimental features](../../../user/gitlab_duo/turn_on_off.md#turn-on-beta-and-experimental-features) for your top-level group or instance, then reload the extension. 

You can switch between the new and classic UI at any
time from the panel. The beta is available for VS Code only.
