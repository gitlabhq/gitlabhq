Use the GitLab plugin for OpenAI to connect GitLab to ChatGPT and Codex.
With this plugin, you can inspect a GitLab project, file, merge request, issue,
or pipeline directly from ChatGPT and Codex and request an allowed action.

ChatGPT and Codex can access only the GitLab projects and groups you can access.
